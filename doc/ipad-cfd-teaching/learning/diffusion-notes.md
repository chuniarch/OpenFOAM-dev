# 扩散专题归纳总结（稳态 → 显式瞬态 → 隐式瞬态）

> 这是「墨水在水里扩散」学习阶梯（砖块 1–9）的闭环复盘。涵盖：物理、公式、推导、变量含义、边界处理、代码易错点、显式/隐式权衡、以及到 OpenFOAM 的对应。
> 公式一律用纯文本记号（终端友好），不用 LaTeX。

---

## 0. 记号约定

```
C_P        当前盒子的浓度（未知数）；C_P_old / C_P_new 表示时间层
C_n        某个邻居的浓度
V          盒子体积      = Δx·Δy·深度（2D 取深度=1）
A_face     一道墙的面积  = 边长·深度
Δx         盒子边长（=Δy，均匀网格）
Δt         时间步长
D          扩散系数
k          内部墙流量常数 = D·A_face/Δx （均匀网格下四方向相等）
2k         边界墙流量常数（中心到边界只有 Δx/2，故翻倍）
a          时间项系数 = V/Δt
```

---

## 1. 一条主线（整套方法的骨架）

所有情形都走同一条流水线：

```
PDE → 在控制体上积分守恒 → 化成"各个面的通量之和"
    → 用邻居中心值近似面上的量 → 每个盒子一条代数方程
    → 组装成线性方程组（矩阵）→ 解（直接法或迭代法）
```

两个招牌动作：
- **守恒**：对每个有限体积（盒子）强制「物质不凭空增减」。
- **通量近似**：面上的量用相邻盒子中心值估计（离散格式 scheme）。

---

## 2. 通量定律（三种情形共用）

相邻两点之间，穿过它们之间那道墙的扩散流量（Fick / Fourier 同形）：

```
流量 = (D · A_face / 距离) · (浓的浓度 − 淡的浓度)
     = 常数 · 浓度差
```

- 两盒子中心相距 Δx → 常数 = k = D·A_face/Δx
- 盒子中心到边界相距 Δx/2 → 常数 = 2k

「距离」决定常数，是后面所有边界处理的根。

---

## 3. 稳态扩散（砖块 1–7）

### 3.1 物理
稳态 = 盒子里浓度不再变 = **流进 = 流出**（净流入 = 0）。

### 3.2 每个盒子的方程（推导）
对盒子 P，四个邻居净流入为 0：

```
Σ_n  w_n · (C_n − C_P) = 0
```

解出 C_P（把含 C_P 的项收一起）：

```
          Σ_n w_n · C_n        （邻居们的 w×C 之和）
C_P  =  ───────────────────
          Σ_n w_n             （邻居们的 w 之和）
```

即「**C_P = 邻居的加权平均**」。均匀网格内部盒子退化成「= 四邻居算术平均」。

### 3.3 解法：联立方程组 → 迭代
各盒子互相依赖、成环，**不能单独算、也不能递归**（递归会无限循环），必须**一起解**。
最简解法 = 高斯-塞德尔迭代：先全部猜一个值，反复「每盒 ← 邻居加权平均、就地写回最新值」，直到 maxChange < tolerance。

### 3.4 边界
- `fixedValue`（墙上钉死浓度）：分子加 `2k·C_边界`，分母加 `2k`。
- `zeroGradient`（无通量、砌死）：**什么都不加**（跳过该方向）。
- 全 zeroGradient 的稳态是奇异的（解只定到一个常数），需钉一个参考点。

### 3.5 验收尺子
- 1D 无源两端定值：解是**直线**（盒子中心在 x=(i+0.5)Δx 取样）。
- 2D：把边界设成有对称性，解必须有同样的**对称性**。

## 4. 显式瞬态扩散（砖块 8A）

### 4.1 物理（新增「堆积」项）
不再稳态，盒子里会积墨：**每秒变化量 = 进 − 出**

```
V · (C_P_new − C_P_old)/Δt = Σ_n w_n · (C_n − C_P)
```

左边 `V·(new−old)/Δt` 就是 ∂C/∂t 离散后的样子（对应 OpenFOAM 的 fvm::ddt）。

### 4.2 显式更新公式（右边全取旧值）
```
C_P_new = C_P_old + (Δt/V) · Σ_n w_n · (C_n_old − C_P_old)
```
右边全已知 → 直接代入算，**一遍扫描出新场，无需迭代**。

### 4.3 稳定性（致命限制）
```
Δt ≤ Δx² / (4D)      （2D 均匀网格）
```
超过就发散（出现极大值/NaN）。注意上限正比于 **Δx²**：网格加密一倍，Δt 要砍 1/4。

### 4.4 代码结构与易错点
- **双缓冲**：新值写入独立的 `cNew`，整张算完再 `c = cNew`。不能就地写回（否则混入半新半旧，破坏显式语义、不守恒）。
- 边界 zeroGradient = 跳过该方向（别当成 C=0 的 fixedValue）。
- 显式没有「除以 weightTotal」这一步（它是绝对增量，不是加权平均）。

### 4.5 验收尺子
- **总质量守恒**：封闭（全 zeroGradient）时 Σ C·V 应几乎不变（显式靠构造守恒，精度达机器级 ~1e-16）。
- 居中滴墨 + 对称壁 → 场四重对称；中心峰值随时间单调下降。

## 5. 隐式瞬态扩散（砖块 9）

### 5.1 物理（只改一处：邻居取新值）
```
V · (C_P_new − C_P_old)/Δt = Σ_n w_n · (C_n_new − C_P_new)
```
右边的 C_n_new 是未知数、互相依赖 → 回到联立方程组。

### 5.2 更新公式（推导）
记 a = V/Δt。把新值项收一起：

```
a·C_P_new − a·C_P_old = Σ w_n·C_n_new − (Σ w_n)·C_P_new
(a + Σ w_n)·C_P_new = a·C_P_old + Σ w_n·C_n_new
```

```
          a·C_P_old + Σ_n w_n·C_n_new
C_P_new = ────────────────────────────      a = V/Δt
              a + Σ_n w_n
```

### 5.3 关键解读：稳态公式 + 一个「虚拟邻居」
对比稳态 `C_P = Σw·C_n / Σw`，隐式只是分子多 `a·C_P_old`、分母多 `a`。
即「**自己的旧值就像第 5 个邻居，权重 a=V/Δt，把盒子往上一刻的位置拉**」。
- Δt→∞：a→0，虚拟邻居消失 → 退回稳态（= 砖块 7）。
- Δt→0：a→∞，C_P_new ≈ C_P_old（一瞬间几乎不变）。

### 5.4 代码结构：双层循环
```
for 每个时间步 {           // 外层：时间推进（marching），不"收敛"，跑固定步数
    cOld = c               // 这一帧的快照（= 上一帧求解结果）
    while 内层没收敛 {       // 内层：解这一帧的方程组（= 砖块7 的高斯-塞德尔）
        for 每个盒子 {
            分子 = a·cOld[P]; 分母 = a            // 虚拟邻居起步
            每个内部邻居: 分子 += k·c[邻居]; 分母 += k   // 读数组当前值，不递归
            fixedValue 边界: 分子 += 2k·C_边界; 分母 += 2k
            zeroGradient 边界: 跳过
            c[P] = 分子/分母      // 就地写回（内层要就地写回，和显式相反）
        }
    }
}
```

要点：
- 内层迭代收敛到的是**这一帧（前进一个 Δt）的场**，不是稳态。
- **每帧锚在前一帧**：这一帧结果 → 下一帧 cOld，时间靠接力前进。
- Δt 藏在 `a = V/Δt` 里，没有单独的 `t += Δt`。

### 5.5 稳定性与精度
- **无条件稳定**：任意 Δt 都不爆炸（虚拟邻居 a 让矩阵对角占优、良态，连全 zeroGradient 都不再奇异）。
- **但大 Δt 精度差**：稳定 ≠ 准确。Δt 越大，时间离散误差越大（场被"抹平"）。

### 5.6 易错点
- `cOld = c` 在每个时间步**开头**存一次；内层迭代里分子用的是这份固定的 cOld，不是上一次内层迭代值。
- 别用递归求 C_n_new（无限循环）；用迭代读数组当前值。
- 分母 `a + Σw` 的 Σw 要**逐格累加**（边界少邻居，不是恒定 4k）。
- 内层要就地写回（高斯-塞德尔）；外层时间步之间靠 c 接力。
- 内层未收敛就用完 maxIteration → 直接进下一帧、带误差。maxIteration 是保险丝，正常出口是 maxChange<tolerance；建议加未收敛警告。
- **质量守恒只到内层容差精度**：停在 tolerance=1e-6 → 每步漏 ~1e-6。收紧容差可减小漂移。

## 6. 显式 vs 隐式：诚实的权衡

| | 显式 | 隐式 |
|---|---|---|
| 每个时间步 | 1 遍扫描 | 迭代到收敛（几十~上百遍） |
| Δt 限制 | 必须 ≤ Δx²/(4D) | 无限制（任意大） |
| 每步代价 | 便宜 | 贵 |
| 稳定性 | 条件稳定 | 无条件稳定 |
| 实现 | 双缓冲，简单 | 双层循环 + 线性求解 |
| 守恒 | 机器精度 | 仅到内层容差 |

**没有"谁更好"，只有"什么场景下更好"：**
- **小网格 / 要时间细节** → 显式（又快又准）。
- **细网格 / 想跨大步到很晚时刻** → 隐式。关键：显式 Δt 上限 ∝ Δx²，细网格上会被压到要跑几百万步而不可行；隐式 Δt 不受此限。这才是 OpenFOAM 默认隐式的原因。

> 教训：一次「没爆炸」的运行只证明**稳定**，不证明**更快**；要比快慢得数总工作量。

## 7. 到 OpenFOAM 的对应

| 本笔记 | OpenFOAM |
|---|---|
| 控制体 + 面 owner/neighbour | fvMesh / polyMesh |
| 「进=出」组装每盒方程 → 矩阵 | fvMatrix（lduMatrix） |
| `V·(new−old)/Δt` 时间项（隐式） | fvm::ddt |
| `Σ w(C_n − C_P)` 扩散项（隐式） | fvm::laplacian(D, C) |
| 高斯-塞德尔 / 共轭梯度解方程组 | smoothSolver / PCG / GAMG |
| fixedValue 边界（半距离 2k） | fvPatchField: fixedValue |
| zeroGradient 边界（跳过） | fvPatchField: zeroGradient |
| 验收靠守恒/对称 | 残差 + 物理检验 |

## 8. 验收尺子速查（写完代码先用这些查）

1. **没爆炸**：无 NaN / 极大值。
2. **总质量守恒**：封闭系统 Σ C·V 不变（最强尺子）。
3. **单调性**：尖峰扩散时中心值单调下降。
4. **对称性**：对称边界 → 对称解。
5. **直线**（1D 稳态无源）/ **趋于均匀**（封闭长时间）。
6. 这些是**强必要条件**，不是终极证明；能跑就要跑，并和解析解/更细网格比收敛。
