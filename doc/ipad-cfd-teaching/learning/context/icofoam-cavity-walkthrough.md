## 2. 理论-A · 物理场景：cavity 顶盖驱动方腔 ✅ 已完整讲解

**大白话**：一个**方盒子装满流体**（当成一小缸油/水）。**顶盖像传送带一样匀速向右滑**；左、右、底**三面墙不动**。顶盖靠**粘性**把紧贴它的那层流体拖着走，这层再拖下一层，一层带一层，**整缸被带着转起来，形成一个大漩涡（主涡）**。

**核心类比** ☕：**拿勺子贴着咖啡表面匀速划一下**——整杯跟着转、杯底回流。cavity 就是把这件事装进方盒子、再取一个**二维切片**来研究。

**为什么拿它当教学例子**：它是 CFD 的 "Hello World"——几何最简（就一个方盒），物理却丰富（主涡、贴墙的边界层、角落小角涡），且有公认参考解。

**贴给学习者的示意图**：
```
            顶盖向右滑 (速度 U=1)
          ════════════════════════►
        ┌────────────────────────────┐
        │  →  →  →  →  →  →  →  ↘     │ ← 贴顶盖的流体被"粘"着拖向右
        │  ↗                     ↓    │
   墙    │  │      ⟲  主漩涡       │   │   墙   整缸被带动,绕圈打转
  不动   │  ↑    (整缸绕圈转)      ↓    │  不动
        │  ↖                     ↙    │
        │  ↖  ←  ←  ←  ←  ←  ←  ↙     │ ← 到底部又回流向左
        └────────────────────────────┘
              底面墙不动 (流体到这儿回流)
```

**学习者复述（判据通过）**：
> "一个二维盒子，顶边可沿直线运动，其余三边固定；紧贴顶部的流体随顶边动，带动下方、下方再带动下方，整缸转起来形成大漩涡。"

——完全正确，尤其把"**一层带一层**（下方的下方）"这条核心机制抓得很准。

**当场补给他的两点**（非纠错，是埋钩子）：
1. 顶盖在 cavity 里具体是**匀速向右**（对应后面输入数据里的 `(1,0,0)`）；
2. 他描述的那股"**拖拽/带动**"劲儿，physics 里叫**粘性 viscosity**（对应变量 ν，理论-C 讲）。

**交叉引用**：学习阶梯 README 砖块 5 / 砖块 11 也在讲这个场景，落点是"顶盖拖动、求水自己的速度和压力（PISO）"。

## 3. 理论-B · 控制方程：不可压缩 Navier–Stokes ✅ 已完整讲解（并深挖）

> 整个 cavity 的流动只被**两条物理定律**管着：动量方程（§3.1）+ 连续性方程（§3.2）。学习者在此处连环追问，逼出了 §3.3–§3.5 的深挖内容。

### 3.1 动量方程 = 流体版牛顿第二定律 F=ma

摆出的方程（这是**守恒/散度形式**，也是代码里的形式）：
```
   ∂U/∂t  +  ∇·(UU)   =   −∇p   +   ν∇²U
```

**一句话抓住它**：这就是牛顿第二定律 `F = ma`（受力 = 质量 × 加速度），用在"流体里一个想象出来的小方块（流体微团）"上。把方程从中间"对折"看成两边：
- **左边** = 小方块的"**加速度**"侧（速度在怎么变）；
- **右边** = 作用在它身上的"**力**"侧（谁在推它、谁在磨它）。

**万能钥匙（先讲清）**：`∇`（读 nabla）**不是一个数，是一个"操作符"**——想成"装着求导指令的向量"。二维下 `∇ = (∂/∂x, ∂/∂y)`，是"两个求导槽"，等着作用到右边的东西上。**所以 ∇ 摆左摆右、和谁点乘，意义完全不同**（这条是 §3.3 的伏笔）。

**逐项翻译（符号只求会意，不求会算）**：

| 项 | 名称 | 大白话 | 类比 |
|---|---|---|---|
| `∂U/∂t` | 本地时间变化 | 某个**固定点**上，速度随时间变多快（不为零=不稳态） | 站在河里某点不动，看流速一会儿快一会儿慢 |
| `∇·(UU)` | 对流项 | 流体流动时，把自己的"运动量"顺水流**搬运**到别处 | 河水把一片油花从上游带到下游 |
| `−∇p` | 压力梯度力 | 流体被从**高压推向低压**（负号见 §4.3） | 挤牙膏：管尾高压 → 牙膏往管口低压挤 |
| `ν∇²U` | 粘性扩散力 | 内摩擦把快慢不均处**抹平**（=理论-A 那股"拖拽"！） | 一排手拉手跑步的人，快的被慢的拽住、慢的被快的拉着，速度被抹匀 |

> 顶盖能把动量一层层往下传，靠的正是 `ν∇²U` 这一项。`∇²`（拉普拉斯）理解成"某点和它四周邻居差多少"。

**对折着看的整体图**：
```
   ∂U/∂t   +   ∇·(UU)      =      −∇p      +     ν∇²U
 └──────────────────────┘       └────────────────────┘
   速度怎么变(= 加速度侧)    =    压力推 + 粘性磨(= 受力侧)
   本地随时间变 + 被流动搬运          从高压→低压    把速度差抹平
```

**剧透（当时明确说"现在不用管"）**：这四项后面在代码里**一一对应** `fvm::ddt` / `fvm::div` / `fvm::laplacian` / `fvc::grad`（见 §5 的 icoFoam.C L77–79、L84）。

### 3.2 连续性方程 `∇·U = 0`

- **物理**：质量守恒；不可压缩 = 体积守恒 = "流进多少就得流出多少，不凭空多/少"。
- **`∇·U` 是什么**：一个**数**（标量），衡量某点流体"**往外散开还是往里聚拢**"的程度。不可压缩 → 它恒等于 0。
- **说明**：本会话没有把连续性单独成块细讲——它是在学习者深挖动量方程/守恒形式的过程中**反复出现并讲清**的（见 §3.3–§3.4，`∇·U=0` 在那里当了一路主角）。下个会话若需要，可正式补一小段收口。

### 3.3 符号答疑：`∇·U` vs `U·∇`、`∇·(UU)` 展开、乘法顺序

> 学习者问了三个很尖锐的问题：① `∇·U` 和 `U·∇` 有什么区别？② `∇·(UU)` 不该是 `(∇·U)U` / `U(∇·U)` / `(U·∇)U` / `U(U·∇)` 里的某个吗？③ `(∇·U)U` 和 `U(∇·U)` 会不会因乘法顺序不同而出错？

**答 ①：一个是"数"，一个是"操作符"。**
```
∇·U = ∂Ux/∂x + ∂Uy/∂y     ← ∇ 在左、和 U 点乘 → 一个数(标量)=散度
                             物理:这点流体"往外散/往里聚"的程度;不可压=0
U·∇ = Ux ∂/∂x + Uy ∂/∂y   ← ∇ 在右 → 还是一个操作符(求导槽还空着)
                             物理:"跟着流走时,某个量变化多快"(对流的数学化)
```
所以 `∇·U`（数）≠ `U·∇`（操作符），根本不是一类东西。

**答 ②：`∇·(UU)` 里 `UU` 是"外积"（2×2 表格/张量），不是普通乘法。**
```
UU = | Ux·Ux  Ux·Uy |     再让 ∇· 作用上去,结果是个向量。
     | Uy·Ux  Uy·Uy |
展开(乘积法则): ∇·(UU) = (U·∇)U + (∇·U)U
不可压缩 ∇·U=0  ⇒  ∇·(UU) = (U·∇)U
```
**学习者自己列的候选里 `(U·∇)U` 正是对的** ✅。其余：`(∇·U)U` = `U(∇·U)`（见答 ③，此处 =0）；`U(U·∇)` 把操作符晾在最后、没东西给它求导，是"没收尾的半成品"，不成立。

**答 ③：完全相等，没有顺序问题。** 因为 `∇·U` **已经是一个算好的数（标量）**，而"数 × 向量"可交换（`3×U = U×3`），故 `(∇·U)U = U(∇·U)`。学习者真正嗅到的"顺序敏感"**不在普通乘法，而在 `∇` 这个操作符的位置**——∇ 是"对右边求导"的动作，`∇·U`（求 U 的导）和 `U·∇`（拿 U 当系数、导还没作用）天差地别。这个警觉非常对。

**为什么代码用 `∇·(UU)` 形式**：有限体积法按"穿过面的通量"记账 → 写成散度形式才能精确守恒 → 代码里是 `fvm::div(phi, U)`，`phi` 就是面通量 φ。

### 3.4 ★深挖★ 守恒形式 vs 非守恒形式：`(∇·U)U` 到底哪来的？

> 学习者的关键质疑（很到位）：物理上的加速度（物质导数）`DU/Dt = ∂U/∂t + (U·∇)U`，里头**根本没有 `(∇·U)U`**；那 `(∇·U)U` 到底哪来的？

**核心答案**：它不是"加速度"的一部分。它**只在方程被写成守恒形式 `∇·(UU)` 时才冒出来**——是对"两个 U 的乘积"求导时、乘积法则吐出的"另一半"，而它被连续性 `∇·U=0` 杀成 0。是个"**乔装成项的 0**"，无独立物理含义。

**两条推导路线（同一条动量方程的两种写法）**：
- **路线 A（拉格朗日 / 追着一团流体，F=ma）**：加速度 = 物质导数 `DU/Dt = ∂U/∂t + (U·∇)U` ⇒ `∂U/∂t + (U·∇)U = −∇p + ν∇²U`（**非守恒/对流形式**，干净，无尾巴）。**这正是学习者心算的那条。**
- **路线 B（欧拉 / 盯住一个固定盒子，记动量进出账）**：`∂(ρU)/∂t + ∇·(ρUU) = 合力`（**守恒/散度形式**）。这里 `∇·(ρUU)` 是"动量随流穿过盒壁的净通量"，**不是"加速度"**。我给学习者的方程出自路线 B，他心算的是路线 A，所以长得不一样。

> **诚实纠偏（当场向学习者承认）**：我上一条把 `∇·(UU)` 归到"加速度侧"，是教学化偷懒；严格讲它是"守恒形式的对流项"，**要靠连续性才等于加速度里的 `(U·∇)U`**。

**常密度清爽版（我们的不可压情形，忘掉 ρ）**：`∇·(UU)` 是对"两个 U 的乘积"求导，乘积法则必然裂成两半：
```
∇·(UU) = (U·∇)U + (∇·U)U        ← 分量级:∂_j(U_i U_j)=(∂_j U_i)U_j + U_i(∂_j U_j)
                                             =   (U·∇)U_i   +   U_i(∇·U)
DU/Dt  = ∂U/∂t  + (U·∇)U         ← 没有"两个U相乘再求导",不裂,就一项
∴ ∇·(UU) ≠ DU/Dt;差的那块 (∇·U)U 被 ∇·U=0 杀成 0
```

**变密度一般情形的主恒等式（这套 ρ 是当时"讲复杂了"的部分，慎用；见 §3.5 教训）**：
```
∂(ρU)/∂t + ∇·(ρUU) = ρ[∂U/∂t + (U·∇)U] + U[∂ρ/∂t + ∇·(ρU)]
                    = ρ·DU/Dt            + U·(连续性 = 0)
                    = ρ·DU/Dt
```

**为什么代码坚持守恒形式 `∇·(UU)`**：有限体积法对 cell 积分 + 散度定理
`∫_cell ∇·(UU) dV = ∮_faces (UU)·n dS = Σ 每个面上的动量通量`
→ 一个 cell 流出的动量 = 相邻 cell 流入的动量，**离散意义下动量精确守恒**；`(U·∇)U` 没有"穿过面"的结构，离散后不严格守恒。代码里就是 `fvm::div(phi, U)`。补充：离散世界里 `∇·U` 只是**近似** 0（要等压力步逼到 0），所以两种写法在数值上确有微小差别，守恒形式更稳更准。

**物质导数 & 雷诺输运定理各是做什么的**（学习者追问）：
```
① 物理定律 —— 对"一团跟着流走的物质"成立(拉格朗日/追粒子):
      质量:  D(质量)/Dt = 0          (这团东西质量不变)
      动量:  ρ · DU/Dt  = 合力        (牛顿 F=ma 用在这团流体上)
                  ↑
        【物质导数 D/Dt】= "一个流体粒子被流带着走时,自己速度变多快"
         = 物理意义上的"加速度",天然是 F=ma 的左边。
                  │
                  │【② 雷诺输运定理(RTT)= 一座"翻译桥"】
                  │  把"追着一团物质算的变化率" 翻成
                  │  "盯住固定盒子:盒内变化率 + 穿过盒壁的通量"
                  ▼
③ 我们真正求解的形式 —— 对"空间里固定的盒子"成立(欧拉/盯格子):
      质量:  ∂ρ/∂t + ∇·(ρU)   = 0        (连续性)
      动量:  ∂(ρU)/∂t + ∇·(ρUU) = 合力     (守恒/散度形式 = 你看到的那条)
```
- **物质导数 `D/Dt`**：物理那侧的"加速度"，`F=ma` 的天然左边（拉格朗日）。
- **雷诺输运定理**：把①（追物质）翻成③（盯盒子）的**定理**，是 NS 守恒形式 `∂(…)/∂t + ∇·(通量)` 的**出处**。
- **③ 守恒形式**：翻译的成品，也是数值上真正离散、求解的对象。
- 上面那段主恒等式，其实就是"把盯盒子与追粒子两种看法连起来的微分恒等式"（RTT 落到微分形式的对应）；`U·连续性 = 0` 正是"两种看法不打架"的数学体现。

### 3.5 教学插曲 + 学习者收进口袋的"够用结论"

学习者到此说"**非常跳跃 / 完全没搞明白**"。我**道歉并重构**：坦白这是流体力学里**偏进阶**的一关（守恒 ↔ 非守恒形式互换），**不在读 icoFoam 代码的必经路上**；物理预备只要直觉，不要求会做这个推导。给了两条路：

- **A 路**：把推导彻底搞懂——但推倒重来、**极慢、只用一维、纯乘积法则**、一步一停。
- **B 路**：记住结论就走，进理论-C。

学习者**先选 A**。我讲了 **A 路第 ① 步 = 乘积法则**（后 ②③④ 步未讲，见下）：
```
记号: f′ = f 的导数(变化率)
规则: (f·g)′ = f′·g + f·g′   ("导前面×后面" 加 "前面×导后面")

数字验证: f=x², g=x³ → 直接 x⁵ 求导=5x⁴;规则 (2x)(x³)+(x²)(3x²)=5x⁴ ✓
```

## 4. 理论-C · 四个变量 U / p / ν / φ（U、p ✅ 已讲；ν、φ ⬜ 未讲）

### 4.1 变量身份框架（先框住四个，好记）
- **U、p** = icoFoam 要**解出来的两个未知数**（速度、压力）；
- **ν** = 一个**给定的常数**（流体多粘）；
- **φ** = 从 U **算出来的**派生量（面上的流量账）。

### 4.2 U · 速度场（矢量场）✅
- **是什么**：盒子里**每一个点**都挂一个**箭头**，告诉你那点流体**朝哪个方向、流多快**。所有点的箭头合起来 = 速度场 U。
- **"场（field）"**：就是"**每个点都挂一个值**"。速度场 = 每点挂一个箭头。
- **现实直觉** 🌬️：天气图上密密麻麻的**风向箭头**，每处一个，指出风往哪吹、多大。U 就是这个，只不过画的是缸里流体。
- **二维下**：每个箭头拆成两个数——`Ux`（朝右多快）、`Uy`（朝上多快）。
- **单位**：m/s。

### 4.3 p · 压力场（标量场）✅
- **是什么**：盒子里**每一个点**挂**一个数**，表示那点流体被"**挤 / 推**"的程度。
- **与 U 的关键区别**：U 每点挂一个**箭头**（有方向，叫**矢量场**）；p 每点挂一个**数**（没方向，叫**标量场**）。学习者复述时正确点出了这条。
- **它干嘛用**：**压力差是流动的推手**——流体从"压力高（挤得紧）"处被推向"压力低（松）"处（对应动量方程 `−∇p`）。
- **现实直觉** 💧：挤海绵 / 水管——一头挤（高压），水往另一头（低压）跑。

**⚠️ 两个出名的小坑（当场讲了，代码里会撞见）**：
1. **icoFoam 里的 `p` 不是帕斯卡（Pa）**！它是"**运动学压力**" `p = 真压力 P / 密度 ρ`，单位是 `m²/s²`。为什么这么搞见"追问 1"。
2. **只有压力的"差"有意义，绝对值无所谓**。方程只出现 `∇p`，全场压力统统加常数 → 流动一模一样 → 方程"答案不唯一" → 求解时要**钉一个基准**（代码里叫 `setReference`，见 §5 的 L114）。

**学习者复述（判据通过）**：U 是速度、矢量、矢量场；p 是压力、标量、标量场、且是"单位密度压力"。全对。随后他又追问两点（我上一条没讲透的）：

**追问 1：为什么"一定要除以密度"？**（他不接受"更好看"这个理由）
```
真实(带单位)动量方程:  ρ × 加速度 = −∇P + μ·∇²U
                       (P=真压力/Pa, μ=动力粘度, ρ=密度)
整条 ÷ ρ:              加速度 = −∇(P/ρ) + (μ/ρ)·∇²U
命名 p≡P/ρ、ν≡μ/ρ:    加速度 = −∇p + ν·∇²U      ← 你看到的那条
```
**关键**：除完之后 **ρ 消失了**，只"藏"在 `p`(=P/ρ) 和 `ν`(=μ/ρ) 里，**再也不单独出现**。深意：不可压缩流动里，物理只关心 `μ/ρ` 和 `P/ρ` 这两个组合，**从不单独用 ρ**；流场形状只由 `ν` 决定，只有想把压力换算回帕斯卡时才需乘回 ρ。**最硬的证据**：icoFoam 的输入里**压根没有"密度"这一项**——cavity 只给一个 `nu = 0.01`。所以不是"为了好看"，是 ρ 在这类问题里本来就是多余信息。

**追问 2：`−∇p` 那个负号怎么来的？**
- `∇p`（压力梯度）是个**箭头**，指向**压力升得最快**的方向（=上坡），越长越陡。
- 但流体被从高压推向低压（往**下坡**走），方向**正好和 ∇p 相反** → 力写成 `−∇p`，**负号把"上坡方向"翻成"下坡方向"**。
- 类比 ⛰️：小球在山坡，`∇(高度)` 指上坡，重力把球往**下坡**推 = `−∇(高度)`。压力同理。
- 一维具体：左边压力低、右边压力高 → `∇p` 指向右（指向高压）→ `−∇p` 指向左 = 流体真实被推的方向。
- 顺带：`p` 本身正负**不重要**（基准随便钉、只有差值有意义），真正起作用的是"某点比邻居高还是低"，`−∇p` 看的就是这个高低差。

## 6. 会话停止点、ν/φ 原定讲法、后续路线

### 停止点
讲完 U、p（含"除以 ρ""负号"两轮追问）后，我在对话里问学习者"**这两点通了的话，我们就上最后两个变量 ν 和 φ……要不要继续？**"——就在此处被本归档任务打断。**ν、φ 一个字都还没讲。**

### ν（运动粘度）原定讲法
- **身份**：**给定的常数**（不是要解的未知数）。
- **是什么**：流体的"**粘稠 / 拖拽**"程度（÷密度后叫运动学粘度）。就是理论-A 那股"一层拖一层"劲儿的**量化**，也是追问 1 里的 `μ/ρ`。
- **在方程里**：就是 `ν∇²U` 那项的 `ν`——内摩擦强度。
- **类比** 🍯：**蜂蜜 vs 水**——蜂蜜 ν 大、难搅、漩涡温吞；水 ν 小、易转。
- **单位/量纲**：`m²/s`，量纲 `[0 2 -1 …]`；**cavity 取 `ν = 0.01`**。

### φ（phi，面通量）原定讲法
- **身份**：从 U **算出来的派生量**（不是独立未知数）。
- **是什么**：**面通量**——每条"小窗口"（cell 之间的面）每秒**穿过多少体积流量**（= U 在该面上的投影 `U·Sf`）。
- **活在哪**：在**面**上，**不在 cell 中心**（这点和 U、p 不同，要强调）。
- **类比**：量"相邻两房间之间的窗口，每秒过多少升水"。
- **为什么单独有 φ**：有限体积法天然按"穿过面的流量"记账（对流、连续性都是**面上**的事）。φ 就是这本"窗口流量账"，由 U 推出。
- **呼应**：= 学习阶梯 README **砖块 10** 的"面通量 `F = u·A_face`，这就是 OpenFOAM 的 `phi`"；= 代码 `fvm::div(phi, U)` 里的那个 `phi`。
