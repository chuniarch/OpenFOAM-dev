第 10 课里没有扩散，墨却摊开了：5 个盒子、水从左往右、进水口浓度 0、初值 0、0、10、0、0、CFL = 0.5，走两步得 0、0、2.5、5、2.5，真实答案是 0、0、0、10、0。这一课算出它摊开得有多快，再把真正的扩散加回来。

读约 15 分钟 + 写代码前置：第 8 课（扩散，显式）、第 10 课（对流，迎风）产出：ConvectionDiffusion1D.ts

一 · 先定验收尺子

这一课的例子都用一根长管，免得墨跑到两头：

40 个盒子，水从左往右流，进水口浓度 0
初值：10 号盒子是 10，其余全是 0
显式；CFL = u × Δt / Δx；r = D × Δt / Δx²（第 8 课）
走 10 步（墨离两头都还很远）

先定义两个数，用来量墨"在哪"和"摊得多开"：

重心 = Σ (盒号 × 浓度) / Σ 浓度
方差 = Σ [ 浓度 × (盒号 − 重心)² ] / Σ 浓度              单位：格²

拿第 10 课那组数算一遍：3、4、5 号分别是 2.5、5、2.5，其余是 0。

重心 = (3 × 2.5 + 4 × 5 + 5 × 2.5) / 10 = (7.5 + 20 + 12.5) / 10 = 4
方差 = [2.5 × (3 − 4)² + 5 × (4 − 4)² + 2.5 × (5 − 4)²] / 10 = (2.5 + 0 + 2.5) / 10 = 0.5

尺子（第二到四节推出来；我这边实跑，全部吻合）：

  • 总和一直是 10。
  • 重心每步右移 CFL 格：10 步后是 10 + 10 × CFL。CFL = 0.5 时是 15。
  • 方差每步增加 CFL × (1 − CFL) + 2r 格²： CFL = 0.5、r = 0 时 10 步后 10 × 0.25 = 2.5； CFL = 1、r = 0 时是 0； CFL = 0.5、r = 0.1 时 10 × (0.25 + 0.2) = 4.5。

二 · 一步里，每个盒子的墨分成两份

第 10 课的迎风更新式（c 就是 CFL）：

C_新(i) = (1 − c) × C_旧(i) + c × C_旧(i − 1)

换个方向读：i 号盒子里原来的墨，下一步有 1 − c 留在 i 号，有 c 到了 i + 1 号。拿 c = 0.5、墨全在 3 号（10）走两步：

第 1 步：3 号的 10 → 留下 0.5 × 10 = 5，往右 0.5 × 10 = 5 到 4 号
         得 3 号 5、4 号 5
第 2 步：3 号的 5 → 留下 2.5，往右 2.5 到 4 号
         4 号的 5 → 留下 2.5，往右 2.5 到 5 号
         3 号 = 2.5；4 号 = 2.5 + 2.5 = 5；5 号 = 2.5

这就是第 10 课的 0、0、2.5、5、2.5。墨像掷硬币一样每步被分成"不动"和"右移一格"两份，比例是 1 − c 和 c。走 n 步，右移了 k 格的那一份是 10 × (n 选 k) × c^k × (1 − c)^(n − k)：n = 2 时 k = 0、1、2 分别是 10 × 1 × 0.25 = 2.5、10 × 2 × 0.25 = 5、10 × 1 × 0.25 = 2.5。

三 · 每步：重心移 c 格，方差多 c × (1 − c)

看一份墨这一步移了多少格：比例 1 − c 移 0 格，比例 c 移 1 格。

平均移动 = (1 − c) × 0 + c × 1 = c                         格
移动平方的平均 = (1 − c) × 0² + c × 1² = c
这一步新增的方差 = 移动平方的平均 − 平均移动² = c − c² = c × (1 − c)   格²

c = 0.5：每步重心右移 0.5 格、方差多 0.25 格²；两步后重心 3 + 1 = 4、方差 0.5，和第一节直接算的一样。

  • 重心对：每步右移 c 格 = u × Δt / Δx 格，正好是水在 Δt 里走的距离。速度没算错。
  • 方差不对：真实的纯对流是整块平移，方差永远是 0。迎风每步凭空多出 c × (1 − c)。这就是数值扩散。
  • c = 1 时 1 × 0 = 0，不摊开（第 10 课：每步原样右移一格）；c = 0 时也是 0（根本不动）；c = 0.5 时最大，0.25。

四 · 换算成一个扩散系数

真正的扩散也让方差变大。第 8 课的显式扩散 C_新 = (1 − 2r) × C_旧 + r × C_左 + r × C_右，同样换个方向读：一份墨有 1 − 2r 不动，r 往左一格，r 往右一格。

平均移动 = r × (−1) + r × (+1) = 0
移动平方的平均 = r × 1 + r × 1 = 2r
每步新增方差 = 2r 格² = 2r × Δx² 米² = 2 × (D × Δt / Δx²) × Δx² = 2 × D × Δt   米²

每秒方差增加 2D，t 秒后方差 2 × D × t，标准差 sqrt(2 × D × t)：就是第 4 课的扩散距离 L ≈ sqrt(2 × D × t)。

把迎风多出来的方差也写成这个样子，就能看出它相当于多大的扩散系数 D_num：

每步多出的方差：c × (1 − c) 格² = c × (1 − c) × Δx² 米²
令它等于 2 × D_num × Δt：
D_num = c × (1 − c) × Δx² / (2 × Δt)
      = (u × Δx / 2) × (1 − c)                  用了 c = u × Δt / Δx，即 Δx² / Δt = u × Δx / c

代真实的数：水速 u = 0.001 m/s，Δx = 0.02 m，c = 0.5：

D_num = (0.001 × 0.02 / 2) × (1 − 0.5) = 0.00001 × 0.5 = 5 × 10⁻⁶ m²/s
墨在水里真实的 D = 1 × 10⁻⁹ m²/s
D_num / D = 5000

算法偷偷加进去的扩散，是墨水真实扩散的 5000 倍。这样算出来的"墨怎么散开"，几乎全是算法的效果，不是墨的。

五 · 把真正的扩散加回来

净流入 = 水带进带出的 + 扩散进出的，两项直接相加（每一项都按第 8、10 课的样子乘 Δt / V）：

C_新 = C_旧 + c × (C_左 − C_旧) + r × [ (C_左 − C_旧) + (C_右 − C_旧) ]
     = (1 − c − 2r) × C_旧 + (c + r) × C_左 + r × C_右

c = 0.5、r = 0.1，墨全在 10 号（10），走第 1 步：

9 号  = r × C_右(10 号)                 = 0.1 × 10 = 1
10 号 = (1 − 0.5 − 0.2) × 10            = 0.3 × 10 = 3
11 号 = (c + r) × C_左(10 号)           = 0.6 × 10 = 6
总和 = 1 + 3 + 6 = 10
重心 = (9 × 1 + 10 × 3 + 11 × 6) / 10 = (9 + 30 + 66) / 10 = 10.5          右移 0.5 格 = c
方差 = [1 × (9 − 10.5)² + 3 × (10 − 10.5)² + 6 × (11 − 10.5)²] / 10
     = (2.25 + 0.75 + 1.5) / 10 = 0.45                                   = c × (1 − c) + 2r = 0.25 + 0.2

方差的 0.45 里，0.2 来自真正的扩散，0.25 来自迎风。

上限：三个系数加起来是 1，自己那份 1 − c − 2r 不能是负的，所以 c + 2r ≤ 1。第 8 课是 2r ≤ 1（内部盒子），第 10 课是 c ≤ 1，两项一起就是两者加起来不超过 1。

六 · 怎么让数值扩散变小

从 D_num = (u × Δx / 2) × (1 − c) 直接看：

  • 格子变细：Δx 从 0.02 m 减到 0.01 m，c 仍取 0.5，D_num = (0.001 × 0.01 / 2) × 0.5 = 2.5 × 10⁻⁶，减半。代价：格子多一倍，Δt 也减半（c 不变），步数多一倍。
  • 让 c 接近 1：c = 1 时 D_num = 0。只在一维、水速处处一样时管用；真实的流动各处速度不同，没法处处 c = 1。
  • 面上的值取得更好：迎风只用上游一个盒子的值。OpenFOAM 的 linearUpwind 用上游再往前推一点的值，本仓库 tutorials/incompressibleFluid/pitzDailyScalarTransport/system/fvSchemes 里就是 div(phi,T) Gauss linearUpwind grad(T);。中心差分（Gauss linear）完全没有这一项数值扩散，但第 10 课算过它会出负值；什么时候能放心用它（cavity 就用它），下一课讲。

七 · 对照 Stable Fluids 第 2 课

那边第 2 课给的数值粘性是 ν_num = h² × f × (1 − f) / (2 × dt)，h 是格宽，f 是一步里回溯的格数（CFL ≤ 1 时就是 c）。把 h 换成 Δx、f 换成 c，就是第四节第三行 c × (1 − c) × Δx² / (2 × Δt)，同一个式子。

结论却相反：那边说数值粘性比水的真粘性大几个数量级，所以干脆不加真粘性；我们要算的是流体本身，必须让数值的部分远小于真实的部分（第四节那个 5000 倍就是反面例子）。这个结论不能借过来。

九 · 易错点

  1. 方差没减重心（写成 Σ 浓度 × 盒号² / Σ 浓度）→ 得到的数会随重心一起变大，CFL = 1 时也不是 0。
  2. 扩散项用了 CFL、或对流项用了 r → 第五节第 1 步 9 号不是 1。
  3. 扩散只写了一边（只有 r × (C_左 − C_旧)）→ 更新式变成 (1 − c − r) × C_旧 + (c + r) × C_左，墨只往右走：第五节第 1 步 9 号是 0，重心每步右移 c + r 格（c = 0.5、r = 0.1 时 0.6 格），比水还快。
  4. CFL + 2r > 1 → 例：CFL = 0.6、r = 0.25，自己那份 1 − 0.6 − 0.5 = −0.1，出负值。

// ============================================================
// ConvectionDiffusion1D.ts  —— 砖块 10B：一维对流 + 扩散，显式；量出数值扩散
//
// 物理：一根管等分成 N 个盒子，水从左往右流（速度 u），墨既被水带走，也在扩散。
//       左端是进水口（流进来的水浓度 C_进），右端是出水口。
// 数学：C_新 = C_旧 + CFL × (C_左 − C_旧) + r × [ (C_左 − C_旧) + (C_右 − C_旧) ]
//            = (1 − CFL − 2r) × C_旧 + (CFL + r) × C_左 + r × C_右
//       CFL = u × Δt / Δx（对流，迎风取上游）；r = D × Δt / Δx²（扩散）
//       自己那份 1 − CFL − 2r 不能是负的：CFL + 2r ≤ 1
// 两头：对流照第 10 课（1 号的上游是进水口，出水口不用给）；
//       扩散项在两头先不写——这一课的墨离两头很远，碰不到。
// 每一步量两个数：
//       重心 = Σ(盒号 × 浓度) / Σ浓度            公式：每步右移 CFL 格
//       方差 = Σ[浓度 × (盒号 − 重心)²] / Σ浓度   公式：每步增加 CFL × (1 − CFL) + 2r 格²
// 运行：贴进 TypeScript Playground 点 Run；或 node ConvectionDiffusion1D.ts（Node 22.18 起）。
// ============================================================

// ===== 1. 走一步：只读 c，只写 cNew =====
function step(c: number[], cfl: number, r: number, cIn: number): number[] {
  const n = c.length;
  const cNew: number[] = new Array(n).fill(0);
  for (let i = 0; i < n; i++) {
    // 对流：上游是左邻；1 号的上游是进水口
    const upstream = i > 0 ? c[i - 1] : cIn;
    const convection = cfl * (upstream - c[i]);

    // 扩散：看左、看右两个独立判断；两头先不写
    let diffusion = 0;
    if (i > 0) diffusion += c[i - 1] - c[i];
    if (i < n - 1) diffusion += c[i + 1] - c[i];

    cNew[i] = c[i] + convection + r * diffusion;
  }
  return cNew;
}

// ===== 2. 量：总和、重心、方差（盒号从 1 数） =====
function measure(c: number[]): { total: number; mean: number; variance: number } {
  let total = 0;
  let weighted = 0;
  for (let i = 0; i < c.length; i++) {
    total += c[i];
    weighted += (i + 1) * c[i];
  }
  const mean = weighted / total;
  let spread = 0;
  for (let i = 0; i < c.length; i++) {
    spread += c[i] * (i + 1 - mean) ** 2; // 一定要先减重心
  }
  return { total: total, mean: mean, variance: spread / total };
}

// ===== 3. 跑一种设定，每一步和公式对照 =====
function run(cfl: number, r: number, steps: number): void {
  const n = 40;
  const start = 10;                      // 墨全在 10 号
  const self = 1 - cfl - 2 * r;          // 自己留下的系数
  console.log(`CFL = ${cfl}，r = ${r}（自己留下 1 − CFL − 2r = ${self.toFixed(2)}${self < 0 ? "，是负的！" : ""}）`);

  let c: number[] = new Array(n).fill(0);
  c[start - 1] = 10;

  const perStep = cfl * (1 - cfl) + 2 * r; // 公式：每步新增方差
  for (let s = 1; s <= steps; s++) {
    c = step(c, cfl, r, 0);
    const m = measure(c);
    const meanFormula = start + s * cfl;
    const varFormula = s * perStep;
    console.log(
      `  第 ${String(s).padStart(2)} 步：总和 ${m.total.toFixed(3)}` +
      `  重心 ${m.mean.toFixed(3)}（公式 ${meanFormula.toFixed(3)}）` +
      `  方差 ${m.variance.toFixed(3)}（公式 ${varFormula.toFixed(3)}）`,
    );
  }
}

// ===== 4. 第 10B 课的三种设定 =====
run(0.5, 0, 10);   // 只有对流：方差每步 + 0.25，全是数值扩散
run(1, 0, 10);     // 只有对流、CFL = 1：原样平移，方差一直是 0
run(0.5, 0.1, 10); // 对流 + 扩散：方差每步 + 0.25（数值）+ 0.2（真实）= 0.45

// 换成真实单位：D_num = (u × Δx / 2) × (1 − CFL)
const u = 0.001;   // 水速 [m/s]
const dx = 0.02;   // 格宽 [m]
const D = 1e-9;    // 墨在水里真实的扩散系数 [m²/s]
const dNum = (u * dx / 2) * (1 - 0.5);
console.log(`CFL = 0.5 时 D_num = ${dNum.toExponential(1)} m²/s，是真实 D 的 ${(dNum / D).toFixed(0)} 倍`);
