大步也不散架

第 8 课右边用旧值，Δt 一大就出负的墨。这一课只改一处：右边用新值。Δt 从此没有上限，代价是每一步都要像第 6 课那样一遍遍扫。

读约 15 分钟 + 写代码前置：第 6 课、第 8 课产出：Diffusion1DImplicit.ts

一 · 先定验收尺子

条件和第 8 课一样：一根细管等分成 5 个盒子，内部墙权重 k，钉死浓度的边界墙 2k，不透水的墙不写；r = D × Δt / Δx²。每一步里面用高斯-塞德尔扫到最大改动 < 1e-6。

二 · 只改一处：右边用新值

第 8 课的式子，右边全用这一步开头的值：

显式：V × (C_新 − C_旧) / Δt = Σ w × (C_对面,旧 − C_旧)

这一课右边全用这一步结束时的值：自己用 C_新，邻居用 C_对面,新（钉死的墙值不变，还是墙值）：

隐式：V × (C_新 − C_旧) / Δt = Σ w × (C_对面,新 − C_新)

这种做法叫隐式（英文 implicit：新值藏在方程两边，不能直接写出来，要解）。两种都是近似：Δt 秒里流量一直在变，显式按开头那一刻算，隐式按结尾那一刻算。

移项，把含 C_新 的放一边。两边乘 Δt / V，和第 8 课一样 (Δt / V) × k = r，钉死的墙 2r；记 m = w / k，这面墙的权重是内部墙的几倍（内部墙 1，钉死的墙 2，不透水 0；每一项系数 (Δt / V) × w = m × r，第 8 课第二节）：

C_新 − C_旧 = r × Σ m × (C_对面,新 − C_新)
C_新 − C_旧 = r × Σ m × C_对面,新 − r × Σm × C_新
C_新 + r × Σm × C_新 = C_旧 + r × Σ m × C_对面,新
C_新 = (C_旧 + r × Σ m × C_对面,新) / (1 + r × Σm)

分子分母都除以 r：

C_新 = ( (1/r) × C_旧 + Σ m × C_对面,新 ) / ( 1/r + Σm )

拿第 6 课的稳态更新式对照（也除以 k）：

第 6 课：C_P = Σ m × C_对面 / Σm             邻居（和墙）按权重 m 取平均

只多了一项：自己的旧值，像多出来的一个邻居，权重 1/r。它把这个盒子往"这一步开头的样子"拉。

麻烦也在这里：右边的 C_对面,新 也是这一步要求的数，五个盒子的新值互相要对方，只能联立。办法就是第 6 课的高斯-塞德尔：先拿旧值当猜测，用上面的更新式一个个重算、立刻写回，扫到最大改动 < 1e-6。扫的时候 C_旧 一直不动，它是题目给的（或上一步算完的）。

三 · 手算第 1 步：墨滴在中间、两面不透水、r = 0.25

条件：5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号），r = 0.25（1/r = 4），走第 1 步。旧值就是 0、0、10、0、0。

为什么可以先认定新值左右对称。把五个盒子左右对调（1 ↔ 5，2 ↔ 4，3 不动），题目一点没变：两面墙都不透水，旧值倒过来读还是 0、0、10、0、0。所以对调后的五个新值也满足同样五条方程。再加上这五条方程只有一组解（理由：假如有两组，逐格相减，旧值那一项相减抵掉，差满足 差_P = Σ m × 差_对面 / (1/r + Σm)；取差的绝对值最大的盒子，右边最多是 Σm / (1/r + Σm) 乘这个最大值，比它本身小，除非它是 0，所以差处处是 0），对调后的解就是原来的解：1 号 = 5 号，2 号 = 4 号。

于是记 1 号 = 5 号 = a，2 号 = 4 号 = b，3 号 = c，五个未知数变成三个。三条方程：

1 号：左墙不透水，右邻 2 号      a = (4 × 0 + b) / (4 + 1)          ⇒ a = b / 5
2 号：左邻 1 号，右邻 3 号       b = (4 × 0 + a + c) / (4 + 2)      ⇒ 6b = a + c
3 号：左右都是 b                c = (4 × 10 + b + b) / (4 + 2)     ⇒ 6c = 40 + 2b

把 a = b/5 代进第二条：6b = b/5 + c  ⇒  c = 6b − b/5 = 29b/5
代进第三条：6 × 29b/5 = 40 + 2b  ⇒  174b = 200 + 10b  ⇒  164b = 200
b = 200/164 = 1.220      a = b/5 = 0.244      c = 29b/5 = 7.073

代回更新式核对，每个盒子都算回自己：

1 号：(4 × 0 + 1.220) / 5          = 1.220 / 5  = 0.244
2 号：(4 × 0 + 0.244 + 7.073) / 6  = 7.317 / 6  = 1.220
3 号：(4 × 10 + 1.220 + 1.220) / 6 = 42.439 / 6 = 7.073
总和：0.244 + 1.220 + 7.073 + 1.220 + 0.244 = 10.001（四舍五入；精确值 10/41 × 2 + 50/41 × 2 + 290/41 = 410/41 = 10）

程序里不用解方程组，高斯-塞德尔从旧值出发扫 8 遍就到这里。和显式第 1 步 0 2.5 5 2.5 0 比：隐式一步之内墨就到了 1 号（0.244），因为 1 号的方程里直接用了 2 号的新值。

四 · 为什么 Δt 没有上限

看更新式 C_新 = ( (1/r) × C_旧 + Σ m × C_对面,新 ) / ( 1/r + Σm )：分子里每一项的权重是 1/r 或 m，不管 r 多大都是正的，分母正好是权重之和。换句话说，各项的系数 (1/r) / (1/r + Σm) 和 m / (1/r + Σm) 都不小于 0，加起来等于 1。例：3 号两边都是内部墙，r = 0.25：4/6 + 1/6 + 1/6 = 1。所以新值永远是"自己的旧值、邻居的新值、钉死的墙值"的加权平均，不会比它们中最大的还大、最小的还小，不会出负的墨。

对比第 8 课：显式整理成 C_新 = (1 − r × Σm) × C_旧 + r × Σ m × C_对面,旧，自己那份 1 − r × Σm 在 r 大时变负，所以才有上限。例：5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号），r = 0.6，第 1 步的 3 号：

显式：(1 − 2 × 0.6) × 10 + 0.6 × 0 + 0.6 × 0 = −0.2 × 10 = −2
隐式：(10/0.6 + 1.655 + 1.655) / (1/0.6 + 2) = (16.667 + 3.310) / 3.667 = 5.448

总量照样守恒：每一道内部墙两边算的都是同一组新值，r × (C_b,新 − C_a,新) 进了 a，同样的量出了 b，一进一出抵消。

五 · 两个极端

先说 r 和 Δt 的关系。能调的是 Δt（多久算一次）；D 由墨和水定，Δx 由网格定。r = D × Δt / Δx²，所以 Δt 一变，r 按比例跟着变，再通过 1/r 进入更新式。把它写成 r = Δt / (Δx² / D)，r 就是"一步 Δt 相当于几个 Δx² / D"。Δx² / D 为什么是一个时间： 

Δx² / D = (A × Δx) / (D × A / Δx) = V / k        一个盒子的体积 ÷ 一道内部墙的权重
单位：m³ ÷ (m³/s) = 秒

意思是：一个盒子和隔壁差 ΔC 时，这道墙每秒流过 k × ΔC；要把这个盒子的浓度改变 ΔC，需要 V × ΔC 的墨；照开头那个流量，要 V × ΔC / (k × ΔC) = V / k 秒。所以它是"一道墙抹平一个盒子的浓度差"的时间尺度。这里 0.02² / 1e-9 = 400000 秒，约 4.6 天。它只是量级：第 4 课的 L ≈ sqrt(2 × D × t) 反过来是 t ≈ L² / (2D)，取 L = Δx 得 200000 秒，差一个因子 2，同一个量级。r = 100 就是一步走 100 × 400000 秒，约 463 天。

r 很大（Δt 很长）：1/r 趋于 0，旧值那一项没了，更新式变成 Σ m × C_对面 / Σm，正是第 6 课的稳态方程。一步就跳到稳态。例：5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号），r = 100，第 1 步就是 1.980 2.000 2.040 2.000 1.980。

r 很小（Δt 很短）：1/r 很大，旧值那一项占绝大部分，新值几乎等于旧值：一眨眼，墨来不及动。

所以第 6 课的稳态求解器，就是隐式取 Δt 无穷大的特例。

六 · 代价：每步要扫，大步不准

每步要扫。先说清两个词。一步：时间从 t 走到 t + Δt，算出这一刻五个盒子的新值。扫一遍：在一步之内，从 1 号到 5 号，每个盒子用更新式重算一次、算完立刻写回（就是第 6 课的高斯-塞德尔）。因为更新式右边要用邻居的新值，而新值还没算出来，只能先拿旧值当猜测，扫一遍得到更好的猜测，再扫，直到这一遍的最大改动 < 1e-6。例：5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号），r = 0.25，第 1 步之内：

猜测（旧值）    0      0      10     0      0
第 1 遍        0.000  1.667  6.944  1.157  0.231
               1 号 (4×0 + 2 号的猜测 0)/5 = 0           2 号还没扫到，用它现在手上的值：猜测 0
               2 号 (4×0 + 1 号刚算的 0 + 3 号的猜测 10)/6 = 1.667

所以扫的时候，更新式里的 C_对面,新 读的是"这个邻居现在手上最新的值"：已经扫过的用刚算的，还没扫到的用上一遍的结果（第 1 遍就是猜测，也就是旧值）。它们一开始都不是真正的新值，所以算出来的也不对；每扫一遍更接近一点，直到再扫也不变，这时五个数同时满足五条方程，才是真正的新值。第 6 课找稳态也是这样，只是那里的猜测是全 0。

扫的时候用了旧值，那和显式有什么区别

用最小的例子算一遍：2 个盒子，两面墙都不透水，旧值 a = 10、b = 0，r = 0.5（1/r = 2）。两个盒子之间一道内部墙（m = 1）。

显式（第 8 课）：右边用开头的值。

a_新 = 10 + 0.5 × (0 − 10) = 5
b_新 = 0  + 0.5 × (10 − 0) = 5
这一步流过墙的墨 = 0.5 × 开头的浓度差 (10 − 0) = 5

隐式（这一课）：右边用结尾的值。两条方程：

a = (2 × 10 + b) / (2 + 1) = (20 + b) / 3
b = (2 × 0  + a) / (2 + 1) = a / 3

两个未知数、两条方程，可以直接解：把第二条代进第一条，

a = (20 + a/3) / 3   ⇒   9a = 60 + a   ⇒   8a = 60   ⇒   a = 7.5
b = 7.5 / 3 = 2.5
这一步流过墙的墨 = 0.5 × 结尾的浓度差 (7.5 − 2.5) = 2.5       a 从 10 变成 7.5，正好少 2.5

区别就在这一行：显式按开头的浓度差 10 算流量，隐式按结尾的浓度差 5 算流量。答案一个是 5、5，一个是 7.5、2.5。

扫是干什么的：两个盒子能代入消元，5 个、500 个就不好手解了。扫是另一种解法：先随便猜一对 a、b，代进两条方程算出新的一对，再代，直到代进去算出来的就是它自己。拿旧值 10、0 当起点：

第 1 遍：a = (20 + 0) / 3 = 6.667        b 还没算，用猜的 0
         b = 6.667 / 3 = 2.222
         检查：(20 + 2.222) / 3 = 7.407，不等于 6.667，不是解，继续
第 2 遍：a = (20 + 2.222) / 3 = 7.407
         b = 7.407 / 3 = 2.469
第 3 遍：a = (20 + 2.469) / 3 = 7.490，b = 7.490 / 3 = 2.497
第 4 遍：a = 7.499，b = 2.500
第 5 遍：a = 7.500，b = 2.500
         检查：(20 + 2.5) / 3 = 7.5 ✓，7.5 / 3 = 2.5 ✓ —— 和上面代入消元解出来的一样

第 1 遍用到的那个 0 只是起点，扫完就被换掉了；停下时的 7.5、2.5 满足的是隐式那两条方程。显式的答案 5、5 代进隐式的第一条：(20 + 5) / 3 = 8.333，不等于 5，它不是隐式的解。

这 8 遍的结果就是第 1 步的新值。然后第 2 步：把它们当旧值，再从头扫。显式一步算一遍就完。隐式每一步里面都是一个"第 6 课"，r 越大，旧值那个"邻居"越弱，扫的遍数越多（5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号）：r = 0.25 每步约 8 遍，r = 2 约 20 遍，r = 100 第 1 步 702 遍）。

大步不准。不出负值不等于算得对。拿5 个盒子、两面墙都不透水、初值 0、0、10、0、0（墨滴在 3 号）的管比较"同一个真实时刻"：4 × 100000 秒（r = 0.25 走 4 步，或 r = 1 走 1 步）。"参考"用显式 r = 0.001 走 1000 步算出（步子极小，当作真实答案）：

                              1 号    2 号    3 号
参考（显式 r = 0.001，1000 步）  1.221   2.224   3.110
显式 r = 0.25，4 步             1.406   2.227   2.734      3 号差 0.376
隐式 r = 1，1 步                0.909   1.818   4.545      3 号差 1.435

隐式一大步没有散架，但差得更多。隐式买到的是"不会散架"，不是"更准"。它的用处是：格子很细时显式的 Δt 上限（Δx² / (3D)）小得没法用，隐式可以按想看的时间精度挑 Δt；要看最终稳态时，可以放心迈大步。

另外，r 很大时内层"最大改动 < 1e-6"停得太早（插页 B：最大改动小于容差 ≠ 误差小于容差）：r = 100 时总和漂成 10.0004；容差改成 1e-10 就回到 10.0000。

七 · 程序的设计

从第 8 课的程序改起：墙的描述、看左看右两个独立判断都留着。两层循环：

外层：走 nSteps 步（或走到一步之内的最大改动 < 1e-6）
    cOld ← c 的复制品                         ← 这一步开头的值，整个内层都不许改
    cNew ← c 的复制品                         ← 猜测：先拿旧值当新值
    内层：重复，直到这一遍最大改动 < 容差（或扫满保险丝）
        对每个盒子 i：
            分子 ← (1/r) × cOld[i]，分母 ← 1/r
            看左：邻居 → 分子 += cNew[i−1]，分母 += 1
                  钉死 → 分子 += 2 × 墙值，分母 += 2
                  不透水 → 不加
            看右：同理
            新值 ← 分子 / 分母
            记下 |新值 − cNew[i]|，cNew[i] ← 新值      ← 内层就地写回，是高斯-塞德尔
    c ← cNew；打印这一步、总和、内层扫了几遍

注意两种"写回"：内层写回 cNew 是对的（在解同一时刻的方程，和第 6 课一样）；cOld 绝不能动（第 8 课的教训：旧值是这一步的已知条件）。

八 · 易错点

  1. 分母忘了加 1/r，或分子忘了 (1/r) × C_旧 → 就成了第 6 课的稳态，一步跳到底，看不到"散开"。
  2. 内层改了 cOld（比如 const cOld = c; const cNew = c;，三个名字是同一个数组）→ 旧值跟着变，每一遍的方程都不一样。
  3. 右边邻居用了 cOld → 就退回了显式，只是多扫了几遍；r = 0.6 时又会出负值。
  4. r 很大时内层容差不够 → 总和慢慢漂（r = 100、容差 1e-6 时 10.0004）。

十 · 参考答案：Diffusion1DImplicit.ts

你要求直接给出全文（2026-10-05）。对应第七节的设计：implicitStep 是内层（解这一步的五条方程，cOld 不动、cNew 就地写回），run 是外层（一步步往前走）。

三层循环各是什么：

run 里的 for (s = 1, 2, …)              外层：时间。第 s 步，时间从 (s − 1) × Δt 走到 s × Δt
  implicitStep 里的 while (sweeps < …)   中层：解这一步的方程，扫第几遍。不是时间
    for (i = 0 … n − 1)                  内层：一遍之内，从 1 号扫到 5 号

sweeps 是"这一步里扫了几遍"，maxSweeps 是它的保险丝；"步"是外层的 s，maxSteps 是它的上限。

时间在哪里：程序里只有 r，因为 Δt 只通过 r 进入更新式。时间的推进是外层循环的计数：第 s 步结束时 t = s × Δt，Δt = r × Δx² / D。打印时把它换算成天，例如两面不透水、墨滴在 3 号、r = 0.25 时，一步 100000 秒，第 48 步约 55.6 天。

// ============================================================
// Diffusion1DImplicit.ts  —— 砖块 9：一维非稳态扩散，隐式时间推进
//
// 物理：一排 N 个盒子，水静止，墨只靠扩散移动；看它一步一步怎么变。
// 数学：V × (C_新 − C_旧) / Δt = Σ w × (C_对面,新 − C_新)      右边全用这一步结束时的值
//       ⇒ C_新 = ( (1/r) × C_旧 + Σ m × C_对面,新 ) / ( 1/r + Σm )
//       r = D × Δt / Δx²；m = w / k：内部墙 1，钉死浓度的墙 2（对面是墙值），不透水的墙 0
// 解法：两层循环。
//       外层 = 时间：一步走 Δt，第 s 步结束时的真实时间是 s × Δt。
//       内层 = 解这一步的方程：高斯-塞德尔，从旧值出发一遍遍扫，扫到最大改动 < 容差。
// Δt 只通过 r 进入更新式，所以程序里算的是 r；真实时间用 Δt = r × Δx² / D 换算出来打印。
// 运行：贴进 TypeScript Playground 点 Run；或 node Diffusion1DImplicit.ts（Node 22.18 起）。
// ============================================================

// ===== 1. 墙的描述（和第 6、8 课一样） =====
type Wall =
  | { kind: "fixed"; value: number } // 钉死浓度的墙 [kg/m³]
  | { kind: "closed" };              // 不透水的墙

function fixedWall(value: number): Wall {
  return { kind: "fixed", value: value };
}
const closedWall: Wall = { kind: "closed" };

// ===== 2. 走一步：解 5 条联立方程（内层高斯-塞德尔） =====
// cOld：这一步开头的值，整个内层都不改。返回这一步结束时的值，以及内层扫了几遍。
function implicitStep(
  cOld: number[],
  r: number,
  left: Wall,
  right: Wall,
  tolerance = 1e-10,      // 内层容差取得比外层严，r 大时总量才不漂
  maxSweeps = 100_000,    // 保险丝
): { c: number[]; sweeps: number } {
  const n = cOld.length;
  const cNew = cOld.slice(); // 猜测：先拿旧值当新值（复制一份，不能和 cOld 是同一个数组）
  const inv = 1 / r;         // 旧值这个「邻居」的权重 1/r

  let sweeps = 0;
  while (sweeps < maxSweeps) {
    sweeps += 1;
    let maxChange = 0;

    for (let i = 0; i < n; i++) {
      let numerator = inv * cOld[i];  // (1/r) × C_旧
      let denominator = inv;          // 1/r

      // 看左：邻居用 cNew 里当前最新的值（还没扫到的，就是猜测）
      if (i > 0) {
        numerator += 1 * cNew[i - 1];
        denominator += 1;
      } else if (left.kind === "fixed") {
        numerator += 2 * left.value;
        denominator += 2;
      }
      // 看右（和看左是两个独立的判断）
      if (i < n - 1) {
        numerator += 1 * cNew[i + 1];
        denominator += 1;
      } else if (right.kind === "fixed") {
        numerator += 2 * right.value;
        denominator += 2;
      }

      const value = numerator / denominator;
      maxChange = Math.max(maxChange, Math.abs(value - cNew[i]));
      cNew[i] = value;                // 内层就地写回：这是在解同一时刻的方程（第 6 课的做法）
    }

    if (maxChange < tolerance) break;
  }
  return { c: cNew, sweeps: sweeps };
}

// ===== 3. 外层：一步步往前走 =====
function sum(c: number[]): number {
  let s = 0;
  for (const v of c) s += v;
  return s;
}

function run(
  title: string,
  initial: number[],
  r: number,
  left: Wall,
  right: Wall,
  secondsPerUnitR: number, // Δx² / D：r = 1 时一步是多少秒
  showSteps: number[],
  maxSteps: number,
  stopTolerance = 1e-6,    // 一步之内最大改动 < 它，就报告停住
): void {
  const dt = r * secondsPerUnitR; // Δt = r × Δx² / D
  console.log(`${title}（r = ${r}，Δt = ${dt.toFixed(0)} 秒 ≈ ${(dt / 86400).toFixed(2)} 天）`);
  console.log(`  第 0 步（t = 0）：${initial.map((v) => v.toFixed(3)).join(" ")}   总和 ${sum(initial).toFixed(3)}`);

  let c = initial.slice();
  for (let s = 1; s <= maxSteps; s++) {
    const result = implicitStep(c, r, left, right);
    let maxChange = 0;
    for (let i = 0; i < c.length; i++) maxChange = Math.max(maxChange, Math.abs(result.c[i] - c[i]));
    c = result.c;

    const days = (s * dt / 86400).toFixed(1); // 时间在外层计数：第 s 步结束时 t = s × Δt
    if (showSteps.includes(s)) {
      console.log(`  第 ${s} 步（t ≈ ${days} 天）：${c.map((v) => v.toFixed(3)).join(" ")}   总和 ${sum(c).toFixed(3)}   内层扫了 ${result.sweeps} 遍`);
    }
    if (maxChange < stopTolerance) {
      console.log(`  第 ${s} 步（t ≈ ${days} 天）最大改动 < ${stopTolerance}，停住：${c.map((v) => v.toFixed(3)).join(" ")}`);
      return;
    }
  }
  console.log(`  走满 ${maxSteps} 步还没停`);
}

// ===== 4. 第 9 课验收表里的三道题 =====
const D = 1e-9;                  // 墨在水里的扩散系数 [m²/s]
const dx = 0.1 / 5;              // 管长 0.1 m，5 个盒子 [m]
const unit = dx * dx / D;        // Δx² / D = 400000 秒
const drop = [0, 0, 10, 0, 0];   // 墨滴在 3 号

run("两面不透水，墨滴在 3 号", drop, 0.25, closedWall, closedWall, unit, [1, 2, 3], 100000);
run("两面不透水，墨滴在 3 号，Δt 加大", drop, 0.6, closedWall, closedWall, unit, [1, 2], 100000);
run("左钉死 10，右钉死 0，初值全 0", [0, 0, 0, 0, 0], 5, fixedWall(10), fixedWall(0), unit, [1], 100000);
