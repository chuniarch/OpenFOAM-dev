一滴墨散开

前七课只问"最后停在哪"。这一课问"每一刻在哪"：往管子中间滴一滴墨，看它一步一步散开。方程只多一项——盒子里墨的增加。

读约 15 分钟 + 写代码前置：第 6 课的一维程序产出：Diffusion1DTransient.ts

第 1 条的最后值、第 3 条的最后值不用算就知道：

  • 第 3 条：时间够长，盒子里的墨不再变，就回到了第 6 课的稳态：5 个盒子、左墙钉死 10、右墙钉死 0、内部墙 k、边界墙 2k，答案 9、7、5、3、1（代回核对：1 号 (2k × 10 + k × 7) / 3k = 9，2 号 (k × 9 + k × 5) / 2k = 7，3 号 (k × 7 + k × 3) / 2k = 5，4 号 (k × 5 + k × 1) / 2k = 3，5 号 (k × 3 + 2k × 0) / 3k = 1）。

我这边跑出来：第 1 条第 35 步最大改动小于 1e-6，第 3 条第 134 步。和稳态时一样，只作对照，差一两步不算错。

二 · 从"进 = 出"到"进 − 出 = 增加"

砖块 2 的稳态：盒子里的墨不再变，所以净流入 = 0。净流入的算法照旧：每一面墙算 w × (对面的值 − 自己的值)，加起来（内部墙 w = k，钉死的墙 w = 2k、对面是钉死的浓度，不透水的墙不写）。

现在墨在变。盒子里的墨量 = 浓度 × 体积 = C × V。一秒钟里墨量的增加，就等于这一秒的净流入：

V × (C_新 − C_旧) / Δt  =  Σ w × (C_对面 − C_P)
  左边：这 Δt 秒里墨量增加多少，除以 Δt，单位 kg/s
  右边：净流入，单位 kg/s

式子里四个浓度：C_新 是这一步结束时（Δt 秒之后）这个盒子的浓度；C_旧 是这一步开头这个盒子的浓度（第 1 步的开头就是第 0 步，题目给的；第 2 步的开头是第 1 步算出来的，依此类推）。右边的 C_P（自己）和 C_对面（邻居，或钉死的墙值）在这 Δt 秒里其实一直在变，流量也一直在变。

右边的浓度用哪一刻的？这一课两个都用这一步开头的值：C_P 换成自己的旧值 C_旧，C_对面 换成邻居的旧值 C_对面,旧（钉死的墙值不随时间变，就是它本身）。这样右边全是已知数，每个盒子单独一算就出新值，不用联立、不用一遍遍扫。这种做法叫显式（英文 explicit：新值可以直接用旧值写出来）。它是个近似：Δt 秒里浓度一直在变，流量其实也在变，我们按开头那一刻的流量算了整个 Δt。

"已知"是怎么被知道的

第 0 步的值是题目给的：我们往 3 号滴了一滴墨，那一刻管里就是 0、0、10、0、0。这是一个物理事实，就像"左墙钉死 10"一样是题目的条件，不是猜的。第 1 步的值用第 0 步算出来，算完就知道了；第 2 步再用第 1 步算。每一步右边用的，都是上一步已经算完的数。

第 6 课的"初值全 0"不一样，它是猜的。那里要找的是稳态，方程 C_P = Σ(w × C_对面) / Σw 右边的 C_对面 应该是邻居的答案，而答案正是我们不知道的。猜 0 代进去，算出来的数不对：5 个盒子、左墙钉死 10、右墙钉死 0，第一遍 1 号 = (2k × 10 + k × 0) / 3k = 6.667，答案是 9。所以要拿新数再代、再算，扫 37 遍才停。从全 100 出发也停在同一组数上，说明初值是多少不影响答案。

这里不同：第 1 步 3 号 = 10 + 0.25 × [(0 − 10) + (0 − 10)] = 5，算一次就是第 1 步的值，不用再改。初值换了，后面每一步都跟着变，因为初值本身就是题目的一部分。

两边乘 Δt / V，移项：

C_新 = C_旧 + (Δt / V) × Σ w × (C_对面,旧 − C_旧)

内部墙：(Δt / V) × k = Δt × (D × A / Δx) / (A × Δx) = D × Δt / Δx² = r
钉死的墙：(Δt / V) × 2k = 2r
（V = A × Δx：一个盒子的体积是墙面积乘格宽）

r 只装进了一种墙的权重：内部墙的 k。可一个盒子的几面墙权重不一样（内部墙 k，钉死的墙 2k，不透水的墙 0）。所以把每面墙的权重写成"几个 k"：

m = w / k        这面墙的权重是内部墙的几倍
内部墙：   w = k   ⇒ m = 1
钉死的墙： w = 2k  ⇒ m = 2
不透水：   w = 0   ⇒ m = 0

每一项的系数：(Δt / V) × w = (Δt / V) × m × k = m × [(Δt / V) × k] = m × r

r 是全管共用的那部分（D、Δt、Δx），m 是每面墙自己的那部分（几个 k）。例：尺子 3 的 1 号，左边是钉死 10 的墙（m = 2），右边是内部墙（m = 1），r = 0.25：

C_新 = C_旧 + 0.25 × [ 2 × (10 − C_旧) + 1 × (C_2,旧 − C_旧) ]
第 1 步：0 + 0.25 × [ 2 × (10 − 0) + 1 × (0 − 0) ] = 5

所以每一步只用这一条：

C_新 = C_旧 + r × Σ m × (C_对面,旧 − C_旧)
     = C_旧 + r × [ 每面墙：内部墙 1 ×(对面 − 自己)，钉死的墙 2 ×(墙值 − 自己)，不透水的墙 0 ]

r = D × Δt / Δx² 没有单位（m²/s × s ÷ m²）。D、Δt、Δx 怎么变都只通过它起作用。

w 和 k 是什么关系，为什么内部墙都是同一个 r

w 是一般写法：每一道墙自己的权重，w = D × A / d（第 4 课：d 是墙两侧"浓度所在点"之间的距离）。k 只是内部墙在这道题里的 w：管子等分（每道内部墙 d 都是 Δx）、一根管（每道墙面积都是 A）、同一种水（D 处处一样），三个条件一凑，每道内部墙都是 D × A / Δx = k。钉死的墙 d 只有 Δx/2，所以 w = 2k。

三个条件少一个，就要一道墙一道墙算。一般式是每一项乘 Δt × w / V_P（V_P 是这个盒子的体积）。例：若 2 号盒子宽 2Δx、其余宽 Δx，那么 1、2 号之间 d = (Δx + 2Δx)/2 = 1.5Δx，w = k / 1.5；2 号的体积是 2AΔx，它从这道墙得到的系数是 Δt × (k/1.5) / (2AΔx) = r / 3，1 号从同一道墙得到的是 Δt × (k/1.5) / (AΔx) = 2r/3。墙还是一道，流量 w × 浓度差 还是同一个数，只是分给体积不同的盒子，浓度变化不一样。

手算尺子 1 的前两步

两面不透水，r = 0.25，旧值 0、0、10、0、0。每个盒子都只用旧值：

第 1 步（旧值 0, 0, 10, 0, 0）
1 号：0  + 0.25 × (0 − 0)                    = 0        左墙不透水，只有右邻
2 号：0  + 0.25 × [(0 − 0) + (10 − 0)]       = 2.5
3 号：10 + 0.25 × [(0 − 10) + (0 − 10)]      = 10 − 5 = 5
4 号：0  + 0.25 × [(10 − 0) + (0 − 0)]       = 2.5
5 号：0  + 0.25 × (0 − 0)                    = 0        右墙不透水，只有左邻
加起来：0 + 2.5 + 5 + 2.5 + 0 = 10

第 2 步（旧值 0, 2.5, 5, 2.5, 0）
1 号：0   + 0.25 × (2.5 − 0)                 = 0.625
2 号：2.5 + 0.25 × [(0 − 2.5) + (5 − 2.5)]   = 2.5 + 0 = 2.5
3 号：5   + 0.25 × [(2.5 − 5) + (2.5 − 5)]   = 5 − 1.25 = 3.75
4 号：2.5 + 0.25 × [(5 − 2.5) + (0 − 2.5)]   = 2.5
5 号：0   + 0.25 × (2.5 − 0)                 = 0.625
加起来：0.625 + 2.5 + 3.75 + 2.5 + 0.625 = 10

换成真实的墨：D = 1e-9 m²/s，管长 0.1 m，5 个盒子 Δx = 0.02 m，r = 0.25 对应 Δt = r × Δx² / D = 0.25 × 0.0004 / 1e-9 = 100000 秒，约 28 小时一步。

先定 r 还是先定 Δt？D 和 Δx 是题目和网格定死的，r 和 Δt 就绑在一起，定一个就定了另一个。物理上该先想 Δt：想多久看一次。这里先写 r = 0.25，是为了让手算的数整齐，再换算出 Δt。两种都要满足第五节的上限 r ≤ 1/3，即 Δt ≤ 0.02² / (3 × 1e-9) = 133333 秒。例：想每天看一次，Δt = 86400 秒，r = 1e-9 × 86400 / 0.0004 = 0.216，没超。

第 35 步散匀，约 35 × 28 ≈ 970 小时，40 天。墨水在静水里就是这么慢。

三 · 为什么总量不变

看 2 号和 3 号之间那道墙。第 1 步里，2 号从这道墙得到 0.25 × (10 − 0) = 2.5；3 号从同一道墙得到 0.25 × (0 − 10) = −2.5。同一道墙、同一组旧值，两边一正一负，加起来是 0。每一道内部墙都这样；不透水的墙流量是 0。所以五个盒子的改动加起来是 0：第 1 步的改动 0、+2.5、−5、+2.5、0，和为 0。

（盒子体积都一样，所以"墨量的总和不变"就是"浓度的总和不变"。）

尺子 3 的总和会变：钉死的墙外是一缸浓度不变的墨水，它那道墙只算在一个盒子里，没有另一边来抵消。第 1 步 1 号得到 2 × 0.25 × (10 − 0) = 5，总和从 0 变成 5。所以"总量守恒"这把尺子只用在两面都不透水的题上。

四 · 必须全用旧值：两个数组

第 6 课的高斯-塞德尔是算完一个盒子立刻写回，后面的盒子马上用上新值。那里对，因为大家在找同一个稳态，早用新值只是走得快。这里不行：每一步要算的是"这一步开头那一刻"各道墙的流量，一道墙两边必须用同一组值，否则一进一出对不上。

就地写回会怎样（尺子 1 第 1 步，算到 3 号时 2 号已经是新值 2.5）：

1 号：0                                          = 0
2 号：0  + 0.25 × [(0 − 0) + (10 − 0)]           = 2.5
3 号：10 + 0.25 × [(2.5 − 10) + (0 − 10)]        = 10 − 4.375 = 5.625    左邻已是新值
4 号：0  + 0.25 × [(5.625 − 0) + (0 − 0)]        = 1.406                 左邻已是新值
5 号：0  + 0.25 × (1.406 − 0)                    = 0.352
加起来：0 + 2.5 + 5.625 + 1.406 + 0.352 = 9.883     少了 0.117

少掉的 0.117 出在哪道墙：

2–3 号之间：2 号按 3 号 = 10 算，得到 +2.5；3 号按 2 号 = 2.5 算，得到 0.25 × (2.5 − 10) = −1.875；合计 +0.625
3–4 号之间：3 号按 4 号 = 0 算，得到 −2.5；4 号按 3 号 = 5.625 算，得到 +1.406；合计 −1.094
4–5 号之间：4 号按 5 号 = 0 算，得到 0；5 号按 4 号 = 1.406 算，得到 +0.352；合计 +0.352
三道墙合计：0.625 − 1.094 + 0.352 = −0.117

我照这样跑到底：最后五个盒子都是 1.875，总和 9.375，不是 10。"总量守恒"这把尺子一眼就能抓住它。

为什么两种写法都散匀了，平的高度却不一样？两面不透水时，"每个盒子等于邻居的平均"这组稳态方程，任何一个平的高度都满足：全 2 满足，全 1.875 也满足（第 6 课参考答案里那句"两面墙都不透水时方程没有唯一解"就是这个）。墙不替你定高度，定高度的只有墨的总量：总量 ÷ 5。正确写法每一步总量都是 10，所以停在 2；就地写回每一步都在内部墙上凭空少一点墨（第 1 步少 0.117），到散匀时只剩 9.375，9.375 ÷ 5 = 1.875；散匀以后所有浓度差为 0，流量为 0，就不再少了。

第 6 课两面钉死，答案由墙值定死（9、7、5、3、1 是唯一解），走哪条路都停在那里，所以就地写回没关系。

TypeScript 里最容易这样犯

写 const cOld = c; 不是复制，cOld 和 c 是同一个数组（第 7 课 fill 那个坑是同一回事）。改了 c[2]，cOld[2] 跟着变，结果就是上面的就地写回。要另一个数组，写 const cNew = c.slice();（复制一份）或者每一步 new Array(n).fill(0) 新建一个，算完再 c = cNew;（这时 c 要用 let 声明）。

五 · Δt 不能太大：自己留下的那份不能是负的

把更新式按"旧的自己"和"旧的对面"整理。以 3 号（两边都是内部墙）为例：

C_新 = C_旧 + r × [(C_左 − C_旧) + (C_右 − C_旧)]
     = (1 − 2r) × C_旧 + r × C_左 + r × C_右

三个系数加起来 (1 − 2r) + r + r = 1。只要每个系数都不小于 0，新值就是旧值们的加权平均，不会比它们最大的还大、最小的还小：不会出现负的墨，也不会冲过头。要求 1 − 2r ≥ 0，即 r ≤ 1/2。

每种盒子自己留下的系数（m 是那面墙的倍数：内部墙 1，钉死的墙 2，不透水的墙 0）：

两边都是内部墙：          1 − (1 + 1) r = 1 − 2r     ⇒ r ≤ 1/2
一边内部墙、一边钉死的墙：1 − (1 + 2) r = 1 − 3r     ⇒ r ≤ 1/3
一边内部墙、一边不透水：  1 − (1 + 0) r = 1 − r      ⇒ r ≤ 1

整根管要取最严的那个：尺子 1（两面不透水）是 r ≤ 1/2，尺子 3（两面钉死）是 r ≤ 1/3。

超了会怎样：尺子 2，r = 0.6，3 号自己留下 1 − 2 × 0.6 = −0.2：

3 号第 1 步：−0.2 × 10 + 0.6 × 0 + 0.6 × 0 = −2

一个盒子的墨比零还少，物理上不可能。我照这样跑下去：第 2 步 3.6 −2.4 7.6 −2.4 3.6，第 20 步 3 号已经是 95.727，第 87 步超过一百万。总和每一步都还是 10（第三节的抵消照样成立），所以守恒抓不住它，有界抓得住。

只超一点点也不对劲。尺子 3 取 r = 0.4（大于 1/3，小于 1/2），1 号贴着钉死的墙，自己留下 1 − 3 × 0.4 = −0.2：

1 号第 1 步：0 + 0.4 × [2 × (10 − 0) + (0 − 0)]     = 8
1 号第 2 步：8 + 0.4 × [2 × (10 − 8) + (0 − 8)]     = 8 − 1.6 = 6.4

它要去的地方是 9，却从 8 退回 6.4：现在越浓，下一步反而越淡。这次没有越跳越大，最后还是停在 9、7、5、3、1，但中间这样来回跳不是真实的扩散。

换回真实单位：r = D × Δt / Δx² ≤ 1/3 ⇒ Δt ≤ Δx² / (3D)。格子减半，Δx² 变成四分之一，Δt 上限也变成四分之一：同样走到 40 天，要多走 4 倍的步数，每一步还要多算一倍的盒子。这是砖块 9（隐式）要解决的事。

六 · 程序的设计

还是四层翻译，代码你来写。从第 6 课的 Diffusion1D.ts 改起：墙的描述（fixedWall、closedWall）和"看左、看右，两个独立判断"都留着；"一遍遍扫到最大改动小于容差"换成"一步步往前走"。

准备：Δx = L / N，r = D × Δt / Δx²（或者直接给 r）；数组 c 填初值

重复，走 nSteps 步（尺子 3 也可以走到最大改动 < 1e-6 为止）：
    新建 cNew（和 c 一样长）
    对每个盒子 i：
        净 ← 0
        看左：是邻居 → 净 += 1 × (c[i−1] − c[i])
              钉死的墙 → 净 += 2 × (墙值 − c[i])
              不透水 → 不加
        看右：同理（两个独立判断）
        cNew[i] ← c[i] + r × 净             ← 右边只读 c，只写 cNew
    c ← cNew
    打印：第几步、五个值、总和

打印前先检查：r 有没有超过最严的那个上限

和第 6 课的三处不同：没有分母，不用除；没有"扫到不变为止"，一步就是一遍；读和写分在两个数组。

七 · 易错点

  1. 就地写回（或者 const cOld = c 以为复制了）→ 两面不透水时总和变少：尺子 1 第 1 步是 9.883，不是 10。
  2. 钉死的墙用了 1 而不是 2 → 尺子 3 第 1 步 1 号是 0.25 × 10 = 2.5，应该是 5。
  3. 把不透水当成钉死成 0 → 尺子 1 的墨从两头漏出去，总和越来越少，最后全是 0。
  4. 符号写反（写成 自己 − 对面）→ 墨往浓的地方流，3 号第 1 步变成 15，越来越大。
  5. Δt 只按内部墙的 1/2 定 → 两面钉死时贴墙的盒子来回跳（r = 0.4 的例子），上限是 1/3。

展开 Diffusion1DTransient.ts 全文 
// ============================================================
// Diffusion1DTransient.ts  —— 砖块 8：一维非稳态扩散，显式时间推进
//
// 物理：一排 N 个盒子，水静止，墨只靠扩散移动；看它一步一步怎么变。
// 数学：V × (C_新 − C_旧) / Δt = Σ w × (C_对面,旧 − C_旧)      右边全用这一步开头的值
//       ⇒ C_新 = C_旧 + r × Σ m × (C_对面,旧 − C_旧)，   r = D × Δt / Δx²
//       m：内部墙 1，钉死浓度的墙 2（对面是墙值），不透水的墙 0（不写）
// 读写分开：右边只读 c，只写 cNew；一步算完再 c = cNew。
// 运行：贴进 TypeScript Playground 点 Run；或 node Diffusion1DTransient.ts（Node 22.18 起）。
// ============================================================

// ===== 1. 墙的描述（和第 6 课一样） =====
type Wall =
  | { kind: "fixed"; value: number } // 钉死浓度的墙 [kg/m³]
  | { kind: "closed" };              // 不透水的墙

function fixedWall(value: number): Wall {
  return { kind: "fixed", value: value };
}
const closedWall: Wall = { kind: "closed" };

// 一面边界墙的贡献：m × (墙值 − 自己)，钉死的 m = 2，不透水的不写
function wallTerm(wall: Wall, self: number): number {
  switch (wall.kind) {
    case "fixed":
      return 2 * (wall.value - self);
    case "closed":
      return 0;
  }
}

// ===== 2. Δt 的上限：每个盒子自己留下的系数 1 − r × Σm 不能小于 0 =====
// 均匀的一维管只有三种盒子：最左一个、最右一个、中间的（n ≥ 3 才有），不用逐个循环。
//   最左：左墙 mL + 右邻 1      最右：左邻 1 + 右墙 mR      中间：1 + 1 = 2
//   只有 1 个盒子：两边都是墙，mL + mR
function maxR(n: number, left: Wall, right: Wall): number {
  const mL = left.kind === "fixed" ? 2 : 0;
  const mR = right.kind === "fixed" ? 2 : 0;
  const worst = n === 1 ? mL + mR : Math.max(mL + 1, mR + 1, n >= 3 ? 2 : 0); // 最大的 Σm
  // worst = 0 只有一种情况：1 个盒子、两面都不透水，它永远不变，r 取多大都行
  return worst > 0 ? 1 / worst : Infinity;
}

// ===== 3. 走一步：只读 c，只写 cNew =====
function step(c: number[], r: number, left: Wall, right: Wall): number[] {
  const n = c.length;
  const cNew: number[] = new Array(n).fill(0); // 新数组；不能写 const cNew = c（那是同一个数组）
  for (let i = 0; i < n; i++) {
    let net = 0;
    // 看左
    if (i > 0) {
      net += c[i - 1] - c[i];
    } else {
      net += wallTerm(left, c[i]);
    }
    // 看右（和看左是两个独立的判断）
    if (i < n - 1) {
      net += c[i + 1] - c[i];
    } else {
      net += wallTerm(right, c[i]);
    }
    cNew[i] = c[i] + r * net;
  }
  return cNew;
}

// ===== 4. 走很多步，打印指定的几步 =====
function sum(c: number[]): number {
  let s = 0;
  for (const v of c) s += v;
  return s;
}

function run(
  title: string,
  initial: number[],
  r: number,
  left: Wall,
  right: Wall,
  showSteps: number[],   // 要打印的步数
  maxSteps: number,      // 最多走几步
  tolerance = 1e-6,      // 最大改动小于它就报告「停住了」并结束
): void {
  const limit = maxR(initial.length, left, right);
  console.log(`${title}（r = ${r}，自留系数不为负的上限 r ≤ ${limit.toFixed(4)}${r > limit ? "，超了！" : ""}）`);
  console.log(`  第 0 步：${initial.map((v) => v.toFixed(3)).join(" ")}   总和 ${sum(initial).toFixed(3)}`);

  let c = initial.slice(); // 复制一份，不改调用者的数组
  for (let s = 1; s <= maxSteps; s++) {
    const cNew = step(c, r, left, right);
    let maxChange = 0;
    for (let i = 0; i < c.length; i++) maxChange = Math.max(maxChange, Math.abs(cNew[i] - c[i]));
    c = cNew;

    if (showSteps.includes(s)) {
      console.log(`  第 ${s} 步：${c.map((v) => v.toFixed(3)).join(" ")}   总和 ${sum(c).toFixed(3)}`);
    }
    if (maxChange < tolerance) {
      console.log(`  第 ${s} 步最大改动 < ${tolerance}，停住：${c.map((v) => v.toFixed(3)).join(" ")}   总和 ${sum(c).toFixed(3)}`);
      return;
    }
  }
  console.log(`  走满 ${maxSteps} 步还没停`);
}

// ===== 5. 第 8 课的三把尺子 =====
const drop = [0, 0, 10, 0, 0]; // 墨滴在 3 号

run("尺子 1 · 两面不透水，墨滴在中间", drop, 0.25, closedWall, closedWall, [1, 2, 3], 100000);
run("尺子 2 · 同上，Δt 太大", drop, 0.6, closedWall, closedWall, [1, 2, 3, 20], 20);
run("尺子 3 · 左钉死 10，右钉死 0，初值全 0", [0, 0, 0, 0, 0], 0.25, fixedWall(10), fixedWall(0), [1, 2], 100000);

// 换成真实单位：r = D × Δt / Δx²
const D = 1e-9;          // 墨在水里的扩散系数 [m²/s]
const dx = 0.1 / 5;      // 管长 0.1 m，5 个盒子 [m]
const dt = 0.25 * dx * dx / D;
console.log(`r = 0.25 时一步 Δt = ${dt.toFixed(0)} 秒，约 ${(dt / 3600).toFixed(1)} 小时`);
