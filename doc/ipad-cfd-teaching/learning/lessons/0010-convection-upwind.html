第 10 课 · 砖块 10 · Convection1D.ts

水流推着墨走

前面几课水是静止的，墨只靠扩散慢慢散。现在让水流起来：水流过一道墙，就把墨一起带过去。这一课只讲这一件事——被水带走的墨怎么算，暂时把扩散关掉。

读约 15 分钟 + 写代码前置：第 8 课（显式、两个数组）产出：Convection1D.ts

零 · 为什么非讲对流不可

一根管，5 个盒子，每格 Δx = 0.02 m。第 9 课算过：只靠扩散，墨抹平一个格子的浓度差要 Δx² / D = 0.02² / 1e-9 = 400000 秒，约 4.6 天。如果水以 u = 1 mm/s 流动，水走过一个格子只要 Δx / u = 0.02 / 0.001 = 20 秒。快了两万倍。现实里墨水靠水流（搅拌）散开，扩散只是零头。

  • C_进 = 0、初值 0、0、10、0、0、CFL = 1：一步里水正好走一个格子，每个盒子的水整个换成它上游那个盒子的水，墨原样往右挪一格。两步后挪到 5 号，第三步流出管子。

二 · 水把墨带过一道墙

每秒带过去多少墨

水以速度 u 穿过一道面积为 A 的墙，每秒穿过的水的体积是

F = u × A          单位 m/s × m² = m³/s

这些水里每立方米含墨 C_面 千克，所以每秒被水带过这道墙的墨是 F × C_面（kg/s）。和扩散的 w × (对面 − 自己) 不同：扩散靠浓度差，水不流也有；这里靠水流，浓度差为 0 也照样带。

C_面 取多少：取上游

穿过 2、3 号之间这道墙的水，是从哪来的？水从左往右流，它们刚才还在 2 号里。所以它们的浓度就是 2 号的浓度：

C_面 = 上游那个盒子的浓度

这叫迎风（英文 upwind：风从哪边来，就取哪边的值）。

看起来更"公平"的做法是取两边的平均（叫中心差分）。它会出错，拿 C_进 = 0、初值 0、0、10、0、0、CFL = 0.5 算第 1 步的 2 号：

中心差分：2 号左墙的 C_面 = (1 号 + 2 号)/2 = 0，右墙的 C_面 = (2 号 + 3 号)/2 = (0 + 10)/2 = 5
          2 号新值 = 0 + 0.5 × (0 − 5) = −2.5            负的墨
迎风：    2 号左墙的 C_面 = 1 号 = 0，右墙的 C_面 = 2 号自己 = 0
          2 号新值 = 0 + 0.5 × (0 − 0) = 0

中心差分说"从 2 号流出去的水浓度是 5"，可 2 号里一点墨都没有。它让 2 号送出了自己没有的墨，所以变成负的。迎风不会：流出去的水就是这个盒子自己的水。我把中心差分接着跑下去：第 20 步 2 号是 −16.914，越来越大。

一个盒子的账

和第 8 课一样，盒子里墨的增加 = 净流入，右边全用这一步开头的值（显式）。以 i 号为例，左墙进、右墙出：

V × (C_新 − C_旧) / Δt = F × C_左邻,旧 − F × C_旧
                          左墙流进（上游是左邻）   右墙流出（上游是自己）

两边乘 Δt / V：
C_新 = C_旧 + (F × Δt / V) × (C_左邻,旧 − C_旧)

F × Δt / V = u × A × Δt / (A × Δx) = u × Δt / Δx = CFL

C_新 = C_旧 + CFL × (C_左邻,旧 − C_旧)
     = (1 − CFL) × C_旧 + CFL × C_左邻,旧

CFL 的意思：一步里水走了 u × Δt，占一个格子 Δx 的 u × Δt / Δx。也就是这个盒子里有 CFL 那么大比例的水流走了，换进来同样多上游的水。最后一行就是这句话：自己剩下 1 − CFL，上游来了 CFL，混匀。（CFL 是三个人名 Courant、Friedrichs、Lewy 的首字母，不用记。）

两头

  • 1 号：上游是进水口，C_左邻 = C_进（题目给的）。
  • 5 号：右墙流出的水就是 5 号自己的水，带走 F × C_5。不需要知道管子外面是什么，所以出水口什么都不用给。

手算尺子：C_进 = 0、初值 0、0、10、0、0、CFL = 0.5

第 1 步（旧值 0, 0, 10, 0, 0）
1 号：0.5 × 0  + 0.5 × C_进 0 = 0
2 号：0.5 × 0  + 0.5 × 0      = 0
3 号：0.5 × 10 + 0.5 × 0      = 5
4 号：0.5 × 0  + 0.5 × 10     = 5
5 号：0.5 × 0  + 0.5 × 0      = 0

第 2 步（旧值 0, 0, 5, 5, 0）
3 号：0.5 × 5 + 0.5 × 0 = 2.5
4 号：0.5 × 5 + 0.5 × 5 = 5
5 号：0.5 × 0 + 0.5 × 5 = 2.5          1、2 号还是 0

三 · CFL 不能超过 1

更新式 C_新 = (1 − CFL) × C_旧 + CFL × C_左邻,旧 的两个系数加起来是 1。和第 8 课一样，只要两个都不是负的，新值就是旧值的加权平均，不会冲过头、不会出负值。要求 1 − CFL ≥ 0，即 CFL ≤ 1。

物理上更直接：一步里流走的水不能比盒子里有的水还多。CFL = 1.5 等于说"这个盒子一步送走了一个半盒子的水"，不可能。算出来是这样（C_进 = 0、初值 0、0、10、0、0）：

3 号：(1 − 1.5) × 10 + 1.5 × 0  = −0.5 × 10 = −5
4 号：(1 − 1.5) × 0  + 1.5 × 10 = 15

第 2 步 4 号 −15、5 号 22.5，第 3 步 5 号 −33.75，越跳越大。换成真实单位：u × Δt / Δx ≤ 1 ⇒ Δt ≤ Δx / u = 0.02 / 0.001 = 20 秒。

这和第 8 课扩散的上限是同一个道理：那里自己留下 1 − r × Σm，这里自己留下 1 − CFL，都不能是负的。

四 · 总量记账

每一道内部墙，上游那个盒子少了 CFL × C_上游，下游那个盒子多了同样的量，一进一出抵消。剩下的只有两头：进水口带进 CFL × C_进，出水口带走 CFL × C_5（这里按"每个盒子体积一样"把墨量写成浓度）。所以每一步：

五个盒子浓度之和的变化 = CFL × (C_进 − C_5,旧)

核对 C_进 = 0、初值 0、0、10、0、0、CFL = 0.5：第 3 步开头 5 号是 2.5，变化 = 0.5 × (0 − 2.5) = −1.25；第 2 步和是 10，第 3 步和是 1.25 + 3.75 + 3.75 = 8.75，正好少了 1.25。C_进 = 10、初值全 0、CFL = 0.5 的前几步，5 号还是 0，每步多 0.5 × 10 = 5：和依次是 5、10、15、20。

这把尺子在有进出口时代替了第 8 课的"总量不变"。

五 · 峰值去哪了

同样是 C_进 = 0、初值 0、0、10、0、0，比较两种 CFL 走过的同一段时间（水走了一个格子）：

真实答案（水把墨原样推走一格）       0  0  0    10   0
CFL = 1，走 1 步                    0  0  0    10   0       一样
CFL = 0.5，走 2 步                  0  0  2.5  5    2.5     峰值从 10 掉到 5，摊开了

这一课根本没有扩散，墨却摊开了。原因在第二节最后那句"混匀"：每个盒子只存一个数。半步时墨的前沿停在 4 号中间，可 4 号只能存一个浓度，只好把前沿抹成整个盒子的平均。每一步都这样抹一次。这叫数值扩散：不是墨在扩散，是算法在抹。它有多大、怎么减小，是下一课的事。

六 · OpenFOAM 里

F 就是 OpenFOAM 的 phi：每个面上的体积流量（m³/s）。方程里的 div(phi,T) 就是"每个面上 F × C_面 加起来"。C_面 怎么取，写在 system/fvSchemes 的 divSchemes 里，例如 div(phi,T) Gauss upwind;。

OpenFOAM 的迎风，源码（src/finiteVolume/interpolation/surfaceInterpolation/limitedSchemes/upwind/upwind.H）里决定权重的就一行：

return pos0(this->faceFlux_);

pos0(x) 是"x ≥ 0 时为 1，否则为 0"：面上的流量往哪边走，面上的值就全取流出来的那一边，正是"取上游"。cavity 的速度用的却是 div(phi,U) Gauss linear;（中心差分，见本仓库 tutorials/legacy/incompressible/icoFoam/cavity/cavity/system/fvSchemes）。它在那里为什么不出事，和下一课有关。

七 · 程序的设计

从第 8 课的 Diffusion1DTransient.ts 改起：两个数组、一步步往前走、打印总和，都留着。只换掉"净流入"那一段：

准备：CFL = u × Δt / Δx（或直接给 CFL）；检查 CFL ≤ 1；数组 c 填初值

重复，走 nSteps 步：
    新建 cNew
    对每个盒子 i：
        上游值 ← i 是第一个盒子？ C_进 ： c[i−1]          ← 只读 c
        cNew[i] ← c[i] + CFL × (上游值 − c[i])
    打印：第几步、五个值、总和，以及 CFL × (C_进 − c[最后一个]) 这一步该变多少
    c ← cNew

和第 8 课相比：每个盒子只看一个邻居（上游），出水口不用写任何东西。

八 · 易错点

  1. 取了下游的值（c[i+1]）→ 墨往上游跑。C_进 = 0、初值 0、0、10、0、0、CFL = 1 时，第 1 步墨跑到 2 号，而不是 4 号。
  2. 就地写回（只用一个数组，从左往右算，2 号用到的 1 号已经是新值）→ 墨一步就穿过整根管：C_进 = 0、初值 0、0、10、0、0、CFL = 1，第 1 步就全是 0，墨凭空没了。
  3. 出水口写成"钉死 0"（5 号流出的水按浓度 0 算）→ 墨出不去：同样的初值、CFL = 0.5，总和一直是 10，第 40 步全堆在 5 号，是 10。
  4. 用平均值当 C_面（中心差分）→ 上游出现负值：第 1 步 2 号 −2.5。
  5. CFL 超过 1 → 第 1 步就出现负值和冲过头的值（−5、15）。

// ============================================================
// Convection1D.ts  —— 砖块 10：一维纯对流，显式迎风
//
// 物理：一根管等分成 N 个盒子，水从左往右以速度 u 流动，把墨一起带走；这一课没有扩散。
//       左端是进水口，流进来的水浓度 C_进 是题目给的；右端是出水口。
// 数学：V × (C_新 − C_旧) / Δt = F × C_上游,旧 − F × C_旧        F = u × A（每秒穿过一道墙的水的体积）
//       ⇒ C_新 = (1 − CFL) × C_旧 + CFL × C_上游,旧               CFL = u × Δt / Δx
//       迎风：穿过墙的水来自上游那个盒子，所以墙上的浓度取上游的值。
//       1 号的上游是进水口（C_进）；出水口流出的就是最后一个盒子自己的水，什么都不用给。
// 读写分开：右边只读 c，只写 cNew；一步算完再 c = cNew（第 8 课的两个数组）。
// 运行：贴进 TypeScript Playground 点 Run；或 node Convection1D.ts（Node 22.18 起）。
// ============================================================

// ===== 1. 走一步 =====
function step(c: number[], cfl: number, cIn: number): number[] {
  const n = c.length;
  const cNew: number[] = new Array(n).fill(0); // 新数组，不能写 const cNew = c
  for (let i = 0; i < n; i++) {
    const upstream = i > 0 ? c[i - 1] : cIn;    // 上游：左邻；1 号的上游是进水口
    cNew[i] = (1 - cfl) * c[i] + cfl * upstream; // 自己剩 1 − CFL，上游来 CFL
  }
  return cNew;
}

// ===== 2. 打印用的小工具 =====
function sum(c: number[]): number {
  let s = 0;
  for (const v of c) s += v;
  return s;
}
function show(c: number[]): string {
  return c.map((v) => v.toFixed(3).padStart(7)).join(" ");
}

// ===== 3. 一步步往前走 =====
function run(
  title: string,
  initial: number[],
  cfl: number,
  cIn: number,
  showSteps: number[],  // 要打印的步数
  maxSteps: number,     // 最多走几步
  tolerance = 1e-6,     // 一步里最大改动小于它，就报告停住
): void {
  console.log(`${title}（C_进 = ${cIn}，CFL = ${cfl}${cfl > 1 ? "，超过 1 了！" : ""}）`);
  console.log(`  第 0 步：${show(initial)}   总和 ${sum(initial).toFixed(3)}`);

  let c = initial.slice();
  for (let s = 1; s <= maxSteps; s++) {
    // 总量记账：内部墙一进一出抵消，只剩进水口带进、出水口带走
    const expected = cfl * (cIn - c[c.length - 1]);
    const cNew = step(c, cfl, cIn);

    let maxChange = 0;
    for (let i = 0; i < c.length; i++) maxChange = Math.max(maxChange, Math.abs(cNew[i] - c[i]));
    const actual = sum(cNew) - sum(c);
    c = cNew;

    if (showSteps.includes(s)) {
      console.log(`  第 ${s} 步：${show(c)}   总和 ${sum(c).toFixed(3)}   总和变化 ${actual.toFixed(3)}（记账算出 ${expected.toFixed(3)}）`);
    }
    if (maxChange < tolerance) {
      console.log(`  第 ${s} 步最大改动 < ${tolerance}，停住：${show(c)}`);
      return;
    }
  }
}
