一 · 先定验收尺子（写代码之前）

写第一行代码之前，先定好"什么输出算对"。下面每一条都是你已经会推的东西，数字我都用同样的规则算过一遍。六条共同的条件：一根管等分成 N 个盒子，内部墙权重 k，边界墙权重 2k，初值全 0，容差 1e-6，高斯-塞德尔。

#设定期望输出抓什么错
15 个盒子：左墙钉死 10，右墙钉死 09.000 7.000 5.000 3.000 1.000，约 37 遍方程、2k、写回
25 个盒子：左墙钉死 10，右墙不透水全是 10.000把不透水写成了钉死成 0
3平场：5 个盒子，两面墙都钉死 5全是 5.000分母漏加
45 个盒子，左墙钉死 10，右墙钉死 0，扩散系数 D 放大 100 倍和第 1 条一个数字都不差权重没有统一用 k
5只有 1 个盒子，左墙钉死 10，右墙钉死 05.000一个盒子两面都是边界墙时的判断
610 个盒子，左墙钉死 10，右墙钉死 09.5 8.5 7.5 … 1.5 0.5下标、循环的起止

遍数差一两遍不算错——取决于你把"是否该停"的判断写在循环的哪个位置。差得多才要查。

第 4 条为什么成立

稳态方程里每一项都乘着同一个 k，而 k = D·A/Δx 里有 D。算 分子 / 分母 时，k 上下约掉，D 也就跟着没了。

物理意思

D 决定墨水多快到达稳态，不决定稳态在哪。现在我们只算"最后停在哪"，所以 D 不起作用。到砖块 8 算"随时间怎么变"时，它就要起作用了。

那门图形课的做法是"先写测试、看它红、再写代码让它变绿"。上面这张表就是同一个思路，只是不用测试框架——你自己对照输出。

二 · 四层翻译

写任何求解器都按这四层走，不许跳级：碰键盘之前，前三层要先想清楚。

第一层 · 物理

一排 N 个盒子，两面墙，稳态，墨从浓流向淡。你已经会了。

第二层 · 数学

每个盒子一条方程：C_P = 分子 / 分母。内部墙贡献 k·C_邻居 和 k；钉死浓度的墙贡献 2k·C_墙 和 2k；不透水的墙什么都不贡献（砖块 2、5）。然后高斯-塞德尔扫到最大改动小于容差（插页 A）。你也已经会了。

第三层 · 数据结构：要存哪些东西

先自己想一下再往下看。

  • 一个长度 N 的数组，存每个盒子的浓度
  • 左墙、右墙各一个"墙的描述"：哪种墙？如果是钉死的，值是多少？
  • 内部墙的权重 k，由 D、A、Δx = L / N 算出来
  • 容差，以及"最多扫几遍"——一根保险丝

第四层 · 代码结构（用话说，TypeScript 你来写）

准备：算出 Δx 和 k；数组填上初始猜测

重复，直到「最大改动 < 容差」或「扫满保险丝上限」：
    最大改动 ← 0                              ← 每一遍开头清零
    对每个盒子 i，从第一个到最后一个：
        分子 ← 0，分母 ← 0
        看左边：i 是第一个盒子吗？
            不是 → 左边是邻居，按内部墙算
            是   → 左边是边界墙，按墙的种类算
        看右边：i 是最后一个盒子吗？（同理）
        新值 ← 分子 / 分母
        最大改动 ← max(最大改动, |新值 − 旧值|)
        把新值写回数组                          ← 别忘了

打印：每个盒子的值、一共扫了几遍

注意"看左边"和"看右边"是两个独立的判断，不是 if/else 二选一。只有一个盒子时，它两边都是边界墙——尺子 5 专门查这个。

墙的描述：推荐用联合类型

联合类型（英文 union type）的意思是「这几种形状之一」。每种形状带一个 kind 字段说明自己是哪一种：

type Wall =
  | { kind: "fixed"; value: number }   // 钉死浓度的墙：带着墙上的值
  | { kind: "closed" };                // 不透水的墙：什么都不带

function describe(wall: Wall): void {
  switch (wall.kind) {
    case "fixed":                      // 是钉死的墙，只有在这里才能读 wall.value
      console.log("钉死在", wall.value);
      break;                           // 别漏 break，否则会接着执行下一个 case
    case "closed":                     // 是不透水的墙
      console.log("不透水");
      break;
  }
}

describe({ kind: "fixed", value: 10 });   // 打印：钉死在 10
describe({ kind: "closed" });             // 打印：不透水

在 case "fixed" 外面写 wall.value，TypeScript 会标红：它不能确定这面墙有值。漏掉第一个 break 的后果我试过：第一次调用会连打两行「钉死在 10」「不透水」。

推荐它的理由是：数据的形状和物理一致——只有钉死的墙才有一个值，不透水的墙根本没有值，联合类型能把这件事写进类型里。TypeScript 也有 enum，但它的每一项带不了值；而且用 Node 直接跑 .ts 文件时，enum 会报错。所以这里不用。用一个 boolean 加一个 number 也能写，先跑起来最重要。

四 · 易错点

  1. 算出新值却没写回数组 → 永远是初始猜测。你上一轮写二维版时就踩过这个（记在 README 砖块 7 条目里）。
  2. "最大改动"每一遍开头没清零 → 它一直记着第一遍的大数，永远停不下来。
  3. 把第一个盒子的值当成墙上的值 → 第一个盒子输出 10，应该是 9。墙上的值是已知的，盒子的值要按方程算。
  4. 边界墙用了 k 而不是 2k → 仍是一条直线，但 5 个盒子、左墙钉死 10、右墙钉死 0 时得到 8.333 6.667 5.000 3.333 1.667，不是 9 7 5 3 1：等于把两面墙各往外挪了半格。
  5. 数组只写了 new Array(n)，没有 .fill(0) → 数组里是空位，一参与计算就得到 NaN（英文 Not a Number，「不是一个数」）。NaN < 容差 永远不成立，所以停不下来，打出来全是 NaN。TypeScript 不会替你报这个错。
  6. 用 for (const i in c) 数下标 → 这样拿到的 i 是字符串 "0"、"1"……，i + 1 得到的是 "01"、"11"，不是 1、2。数下标一律写 for (let i = 0; i < n; i++)。
  7. 最外层的变量起名叫 closed、top、name → 在网页里的 Playground 上会标红「Cannot redeclare block-scoped variable」（不能重复声明）：浏览器已经有同名的全局变量。换个名字就好，参考答案里用的是 closedWall。
  8. 没有保险丝 → 只要哪里写错，程序就永远转下去，iPad 上的 App 会卡住。

// ============================================================
// Diffusion1D.ts  —— 砖块 6：一维稳态扩散 + 高斯-塞德尔
//
// 物理：一排 N 个盒子，水静止，墨只靠扩散在盒子之间移动。
//       两端各一面边界墙：钉死浓度的墙，或不透水的墙。求稳态。
// 数学：每个盒子一条方程  C_P = 分子 / 分母
//       内部墙：        分子 += k·C_邻居    分母 += k      k = D·A/Δx
//       钉死浓度的墙：  分子 += 2k·C_墙     分母 += 2k     （盒心到墙只有半格）
//       不透水的墙：    什么都不加
//       解法：高斯-塞德尔，算出新值立刻写回；最大改动 < 容差 就停。
// 运行：贴进 TypeScript Playground 点 Run；或在电脑上 node Diffusion1D.ts
//       （Node 22.18 或更新的版本能直接跑 .ts 文件）。
// ============================================================

// ===== 1. 墙的描述 =====
// 联合类型：一面墙要么是「钉死的，带一个值」，要么是「不透水的，什么都不带」。
type Wall =
  | { kind: "fixed"; value: number } // 钉死浓度的墙，带着墙上的浓度 [kg/m³]
  | { kind: "closed" };              // 不透水的墙

function fixedWall(value: number): Wall {
  return { kind: "fixed", value: value };
}
const closedWall: Wall = { kind: "closed" };

// ===== 2. 求解器 =====
// 返回：每个盒子的浓度 [kg/m³]，以及一共扫了几遍。
// 两面墙都不透水时方程没有唯一解，本程序不处理这种设定。
function solveDiffusion1D(
  n: number,             // 盒子个数
  length: number,        // 全长 L [m]
  diffusivity: number,   // 扩散系数 D [m²/s]
  area: number,          // 墙的面积 A [m²]
  left: Wall,
  right: Wall,
  initialGuess = 0.0,
  tolerance = 1e-6,
  maxSweeps = 100_000,   // 保险丝：写错时不至于永远转下去
): { c: number[]; sweeps: number } {

  if (!Number.isInteger(n) || n < 1) {
    throw new Error("至少要有一个盒子");
  }

  const dx = length / n;                 // 格宽 Δx [m]
  const k = diffusivity * area / dx;     // 内部墙权重 [m³/s]

  const c: number[] = new Array(n).fill(initialGuess);
  let sweeps = 0;

  while (sweeps < maxSweeps) {
    sweeps += 1;
    let maxChange = 0.0;                 // 每一遍开头清零

    for (let i = 0; i < n; i++) {
      let numerator = 0.0;               // 分子
      let denominator = 0.0;             // 分母

      // 看左边：是邻居还是边界墙
      if (i > 0) {
        numerator += k * c[i - 1];
        denominator += k;
      } else {
        switch (left.kind) {
          case "fixed":
            numerator += 2.0 * k * left.value;
            denominator += 2.0 * k;
            break;
          case "closed":
            break;
        }
      }

      // 看右边：和看左边是两个独立的判断（只有一个盒子时，两边都是墙）
      if (i < n - 1) {
        numerator += k * c[i + 1];
        denominator += k;
      } else {
        switch (right.kind) {
          case "fixed":
            numerator += 2.0 * k * right.value;
            denominator += 2.0 * k;
            break;
          case "closed":
            break;
        }
      }

      const newValue = numerator / denominator;
      maxChange = Math.max(maxChange, Math.abs(newValue - c[i]));
      c[i] = newValue;                   // 就地写回：后面的盒子马上用上新值
    }

    if (maxChange < tolerance) {
      break;
    }
  }

  return { c: c, sweeps: sweeps };
}

// ===== 3. 打印 =====
function report(title: string, result: { c: number[]; sweeps: number }): void {
  const values = result.c.map((v) => v.toFixed(3)).join(" ");
  console.log(`${title}：${values}   （扫了 ${result.sweeps} 遍）`);
}

// ===== 4. 第 6 课的六把验收尺子 =====
const L = 0.1;     // 全长 [m]
const D = 1e-9;    // 墨在水里的扩散系数 [m²/s]
const A = 1e-4;    // 墙面积 1 cm² [m²]

// 参数顺序：盒子数, 全长, 扩散系数, 墙面积, 左墙, 右墙
report("尺子 1 · N=5  左钉死 10 右钉死 0", solveDiffusion1D(5,  L, D,       A, fixedWall(10), fixedWall(0)));
report("尺子 2 · N=5  左钉死 10 右不透水", solveDiffusion1D(5,  L, D,       A, fixedWall(10), closedWall));
report("尺子 3 · N=5  两面都钉死 5     ", solveDiffusion1D(5,  L, D,       A, fixedWall(5),  fixedWall(5)));
report("尺子 4 · 同尺子 1，D 放大百倍  ", solveDiffusion1D(5,  L, 100 * D, A, fixedWall(10), fixedWall(0)));
report("尺子 5 · N=1  左钉死 10 右钉死 0", solveDiffusion1D(1,  L, D,       A, fixedWall(10), fixedWall(0)));
report("尺子 6 · N=10 左钉死 10 右钉死 0", solveDiffusion1D(10, L, D,       A, fixedWall(10), fixedWall(0)));

// ===== 5. 给插页 B：盒子数与遍数 =====
console.log("");
console.log("左钉死 10、右钉死 0，盒子数与遍数：");
for (const n of [5, 10, 20, 40]) {
  const r = solveDiffusion1D(n, L, D, A, fixedWall(10), fixedWall(0));
  console.log(`N = ${n}：${r.sweeps} 遍`);
}
