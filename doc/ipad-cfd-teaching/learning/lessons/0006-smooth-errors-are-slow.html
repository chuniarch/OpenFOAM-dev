盒子数每翻一倍，遍数多三倍半左右。第四节会推出：每遍能磨掉的比例，随 N 翻倍正好变成四分之一，所以遍数的量级跟 N² 走。实测比 4 小一点、而且在慢慢变小，原因在第四节末尾，也要推出来。

每一遍本身要算 N 个盒子，所以总工作量的量级跟 N³ 走。

二 · 换个角度：看"离答案还差多少"

把每个盒子的误差定义成：现在的值 − 答案。解方程，就是把误差一遍遍磨成 0。

先从原始等式把更新式推一遍

原始等式是砖块 2 的"进 = 出"：一个盒子所有透墨的墙，流进的量加起来为 0。每一面墙的流进量可以拆成两股：

流进 P 的量 = w × (C_对面 − C_P)
           = w × C_对面    −    w × C_P
             从对面穿过来的      从 P 穿过去的

墨水微团各自乱走，每个微团单位时间穿过这面墙的机会一样大。所以穿过来的量跟对面的浓度成正比，穿过去的量跟 P 自己的浓度成正比。

"对面"是什么：内部墙的对面是邻居盒子；钉死的墙的对面是第 5 课那一大缸浓度不变的水，浓度就是墙上钉死的值，权重 2k。不透水的墙，两股都是 0。

所有墙加起来等于 0，把含 C_P 的项移到右边：

Σ(w × C_对面) = Σ(w × C_P) = C_P × Σw

C_P = Σ(w × C_对面) / Σw        ← 分子：所有穿过来的；分母：所有穿过去的系数

求和对象是所有透墨的墙，墙外那缸水也算一个邻居。分母就是所有邻居的权重和，每个权重除以它，加起来正好是 1，所以这是加权平均。

钉死成 0 的墙：分子里得 0，分母里照样得 2k

情形甲的 5 号盒子，右墙钉死 0，就是第 5 课第四节那条式子：

k × (C_4 − C_5) + 2k × (0 − C_5) = 0

展开：  k × C_4 − k × C_5 + 2k × 0 − 2k × C_5 = 0
移项：  k × C_4 + 2k × 0 = k × C_5 + 2k × C_5 = (k + 2k) × C_5

        C_5 = (k × C_4 + 2k × 0) / (k + 2k) = C_4 / 3

右墙那一项拆成了两块：2k × 0 不含 C_5，留在左边进了分子，是 0；−2k × C_5 含 C_5，移到右边进了分母，是 2k。墙外是清水，没有墨穿过来；可 5 号里的墨照样穿过去。代入答案 C_4 = 3、C_5 = 1：

穿过来：  从 4 号 k × 3 = 3k，   从墙外 2k × 0 = 0     合计 3k
穿过去：  到 4 号 k × 1 = k，    到墙外 2k × 1 = 2k    合计 3k      ✓ 进 = 出

如果分母里没有这个 2k，式子就成了 C_5 = C_4——那是不透水墙（情形乙）的式子。

误差满足同一个形状

情形甲 1 号盒子的第 2 遍，此时 C_2 = 3.333（答案 7）。新值是让 1 号"进 = 出"的那个值，答案也满足"进 = 出"。两条原始等式并排：

新值：  2k × (10 − 新值) + k × (3.333 − 新值) = 0
答案：  2k × (10 − 9)    + k × (7     − 9)    = 0

相减，同一面墙的两个括号放在一起（误差 = 值 − 答案）：
左墙：  (10 − 新值) − (10 − 9)    = (10 − 10) − (新值 − 9)    = 0 − 新误差
右墙：  (3.333 − 新值) − (7 − 9)  = (3.333 − 7) − (新值 − 9) = 误差_2 − 新误差

⇒       2k × (0 − 新误差) + k × (误差_2 − 新误差) = 0

墙外那缸水两次都是 10，它的误差是 10 − 10 = 0。所以左墙变成了"对面是 0"的样子，和上面 5 号盒子的右墙同一个形状。照同样的步骤展开、移项：

新误差 = (2k × 0 + k × 误差_2) / (2k + k)
       = (0 + (3.333 − 7)) / 3 = −3.667 / 3 = −1.222

直接算：新值   = (2k × 10 + k × 3.333) / 3k = 7.778
        新误差 = 7.778 − 9 = −1.222     ✓
结论

新误差 = 所有邻居误差的加权平均。钉死的墙外那缸水也是邻居，它的误差永远是 0，但它还在平均里：分子里得 2k × 0 = 0，分母里得 2k。

平均里多一个 0，会把结果往 0 拉。1 号盒子：有那缸水时是 (2/3) × 0 + (1/3) × (−3.667) = −1.222；没有它，只剩 2 号，平均就是 −3.667。

三 · 两个量：新误差，和这一遍的改动

第二节的结论是 新误差 = 邻居误差的加权平均。我常说的"邻居平均 − 自己"是另一个量：这一遍的改动。

改动 = 新误差 − 旧误差 = 邻居平均 − 自己（更新前的误差）

把每个邻居的值先换成"邻居 − 自己"的差再做加权平均，得到的也是改动，因为权重占比加起来是 1：

Σ w × (C_对面 − C_P) / Σw = Σ(w × C_对面) / Σw − C_P × Σw / Σw = 邻居平均 − 自己

例：一个盒子旧误差 0.99，左右邻居的误差是 0.91 和 0.99（等权重）：

邻居平均 = (0.91 + 0.99) / 2 = 0.95      ← 这就是它的新误差
改动     = 0.95 − 0.99       = −0.04     ← 这一遍磨掉了 0.04，只是误差本身的 4%

磨得快不快，看改动占误差的比例。这三个数取自第四节那个平缓鼓包（N = 10）顶上的盒子。

锯齿：一遍磨掉三分之二

6 个盒子，两面墙钉死 0，误差是 +1 −1 +1 −1 +1 −1。1 号和 6 号的分母是 3k，其余是 2k。前向高斯-塞德尔一遍：

1 号：( 2k × 0 + k × (−1) ) / 3k   = −0.333
2 号：( k × (−0.333) + k × 1 ) / 2k = +0.333     ← 左邻用的是刚算好的 −0.333
3 号：( 0.333 + (−1) ) / 2          = −0.333
4 号：( −0.333 + 1 ) / 2            = +0.333
5 号：( 0.333 + (−1) ) / 2          = −0.333
6 号：( k × (−0.333) + 2k × 0 ) / 3k = −0.111

最大误差从 1 变成 0.333。从 2 号起，左邻已经被磨小了，和右邻的旧值 ±1 一平均，就被拉向 0 附近。

这一点只对高斯-塞德尔成立。如果一整遍都先用旧值算、最后一起写回，一个 +1 的盒子两边都是 −1，平均正好是 −1——它从 +1 变成 −1，大小没变，只是翻了个面。你写的程序是算完立刻写回的，不受影响。

四 · 为什么是 N²：推导

第一步：把"改动"写成"落差的落差"

改动 = 邻居平均 − 自己
     = (左 + 右) / 2 − 自己
     = (左 − 2 × 自己 + 右) / 2

括号里的 C_L − 2·C_P + C_R 有个名字，叫「二阶差分」。你在砖块 4 问过的「除以 Δx²」那个式子，分子就是它；这里只用分子。它还能拆成两段落差之差：

左 − 2 × 自己 + 右 = (右 − 自己) − (自己 − 左)
                   = 右边那段的落差 − 左边那段的落差         ← 这就是"落差的落差"

第二步：拿一个具体的鼓包，直接算

鼓包取 e(x) = 4x(1 − x)：两端为 0，正中间 x = 0.5 处为 1。全长取 1，第 i 个盒子的中心在 x = (i + 0.5) / N。N 是偶数，正中间 x = 0.5 正好落在两个盒子的交界上，所以顶上是两个一样高的盒子。取左边那个和它的两个邻居，代进去：

N左自己右邻居平均改动
10e(0.35) = 0.9100e(0.45) = 0.9900e(0.55) = 0.99000.9500−0.0400
20e(0.425) = 0.9775e(0.475) = 0.9975e(0.525) = 0.99750.9875−0.0100
40e(0.4625) = 0.9944e(0.4875) = 0.9994e(0.5125) = 0.99940.9969−0.0025

比如 N = 10 那一行：e(0.35) = 4 × 0.35 × 0.65 = 0.91，e(0.45) = 4 × 0.45 × 0.55 = 0.99，邻居平均 (0.91 + 0.99) / 2 = 0.95，改动 0.95 − 0.99 = −0.04。

N 每翻一倍，改动正好变成四分之一：0.04 → 0.01 → 0.0025。

第三步：为什么正好是四分之一——代数

对这个鼓包，任意位置 x、格宽 h，把两个邻居展开：

e(x − h) = 4 (x − h)(1 − x + h) = 4 [ x − x² + 2xh − h − h² ]
e(x + h) = 4 (x + h)(1 − x − h) = 4 [ x − x² − 2xh + h − h² ]

两式相加：                       4 [ 2x − 2x² − 2h² ]  = 2 e(x) − 8h²

所以   左 − 2 × 自己 + 右 = e(x − h) + e(x + h) − 2 e(x) = −8h²
       改动 = −8h² / 2 = −4h²，   而 h = 1/N   ⇒   改动 = −4 / N²

结果里没有 x：鼓包上每个内部盒子这一遍被磨掉的量都一样，是 4 / N²。N = 10 是 4/100 = 0.04，N = 20 是 4/400 = 0.01——和上表逐位吻合。

"落差减半、落差的落差变成四分之一"在这里就是：同一个位置附近（x ≈ 0.2），相邻两盒的落差，N = 10 时是 e(0.25) − e(0.15) = 0.75 − 0.51 = 0.24，N = 20 时是 e(0.225) − e(0.175) = 0.6975 − 0.5775 = 0.12，格子窄一半，落差小一半；而落差的落差等于 −8h²，h 减半它就变成四分之一。

紧挨墙的两个盒子不算"内部"：它们有一面是边界墙（权重 2k），要按第二节的规则另算。以左端 1 号盒子为例：

自己：  e(h/2)  = 4 × (h/2)  × (1 − h/2)  = 2h − h²
右邻：  e(3h/2) = 4 × (3h/2) × (1 − 3h/2) = 6h − 9h²
左边：  钉死成 0 的墙，权重 2k；分母 = k + 2k = 3k

新误差 = (k × (6h − 9h²) + 2k × 0) / 3k = 2h − 3h²
改动   = (2h − 3h²) − (2h − h²)          = −2h²      ← 内部盒子的一半

N = 10 时代数字核对：自己 e(0.05) = 0.19，右邻 e(0.15) = 0.51，新误差 0.51 / 3 = 0.17，改动 0.17 − 0.19 = −0.02 = −2 × 0.1²。✓ 这两个盒子自己的误差本来就很小（约 2h），第四步估算遍数时，看的是误差最大的中间。

第四步：从"每遍磨掉多少"到"要扫几遍"

鼓包峰高是 1，每遍磨掉它的比例 r ≈ 4/N²。每遍都剩下 (1 − r) 倍，扫 n 遍剩下 (1 − r)ⁿ。要磨到只剩百万分之一：

(1 − r)ⁿ = 10⁻⁶
两边取 ln：  n × ln(1 − r) = ln(10⁻⁶) = −6 × ln 10 = −6 × 2.303 = −13.8
r 很小时 ln(1 − r) ≈ −r，所以  n ≈ 13.8 / r

n 跟 1/r 成正比，r 跟 1/N² 成正比，所以 n 跟 N² 成正比。每遍只能磨四分之一那么多，就要扫四倍的遍数。

（高斯-塞德尔用上了刚算好的左邻，实际每遍磨掉的比这里多一倍多，但"随 N² 变小"这一点不变。准确的系数见下面的正式公式。）

第五步：为什么实测是 3.5 倍而不是 4 倍

我们的停止规则看的是"改动"，不是"误差"。第四步说每遍剩 (1 − r) 倍，所以这一遍的改动 = r × 这一遍之前的误差。停下的那一遍：

改动 = r × 之前的误差 < 容差     ⇒  之前的误差 < 容差 / r
扫完剩 (1 − r) 倍                ⇒  停下时的误差 < 容差 × (1 − r) / r
r 很小时 1 − r ≈ 1               ⇒  停下时的误差 ≈ 容差 / r

r 越小（N 越大），停下时剩下的误差越大，也就"停得越早"，遍数比 4 倍少一点。

下表的 r 用实测的每遍比例（本节末尾的表）。比如 N = 20：每遍剩 0.97554，r = 1 − 0.97554 = 0.0245，容差 / r = 10⁻⁶ ÷ 0.0245 = 4.1 × 10⁻⁵。拿它和停下时离真答案的实测误差比：

N停下时的真实误差容差 / r 的预测
51.5e-63.0e-6

N = 5 差了一倍，逐项算得出来。① 5 个盒子实测每遍剩 0.66667，r = 1/3（公式 cos²(π/5) 给 0.65451，N 这么小时不准，原因见本节末尾）。② 这时 1 − r = 2/3，不能当成 1。③ 停下那一遍的改动是 0.763 × 10⁻⁶，比容差小一截：改动是一遍一遍跳着变小的，不会正好落在 10⁻⁶ 上。合起来：

N = 5： 0.763 × 10⁻⁶ × (2/3) ÷ (1/3)        = 1.53 × 10⁻⁶   实测 1.53 × 10⁻⁶  ✓
N = 20：0.9935 × 10⁻⁶ × 0.97554 ÷ 0.02446 = 3.96 × 10⁻⁵   实测 3.96 × 10⁻⁵  ✓

N 越大，这三项的影响越小，停下时的误差就越接近 容差 / r。

写求解器时要记住

"最大改动小于容差"不等于"误差小于容差"。N = 80 时，停下时的误差是容差的 650 倍，网格越细差得越多。换一种判停量也逃不开这个问题——平缓的误差让什么量都变化得很慢。所以验收时要拿已知答案去比（第 6 课的尺子），不能只看程序说"收敛了"。

数值分析里的正式说法

把最平缓的误差写成一段正弦：e_i = sin(θ (i + 0.5))，θ = π/N——两面墙处为 0，中间鼓一个包。用三角恒等式 sin(a − θ) + sin(a + θ) = 2 sin(a) cos(θ)：

邻居平均 = [ sin(θ(i − 0.5)) + sin(θ(i + 1.5)) ] / 2
         = sin(θ(i + 0.5)) × cos θ
         = 自己 × cos θ

也就是说：对这种误差，"取一次邻居平均"，每个盒子都乘上同一个数 cos(π/N)，整个鼓包按同一个比例缩小（两端的盒子因为边界墙是 2k，略有出入）。

高斯-塞德尔用的是刚算好的左邻，正弦形状扫一遍会变形。换一个"歪一点的正弦"就不变形。设 c = cos θ，误差 e_i = c^i × sin(θ(i + 0.5))。扫到 i 号时，左邻已经更新、右邻还是旧值；假设左邻已经变成原来的 c² 倍，看 i 号是不是也变成 c² 倍：

新值_i = [ c² × c^(i−1) sin(θ(i − 0.5)) + c^(i+1) sin(θ(i + 1.5)) ] / 2
       = c^(i+1) × [ sin(θ(i − 0.5)) + sin(θ(i + 1.5)) ] / 2
       = c^(i+1) × sin(θ(i + 0.5)) × cos θ        ← 同一个三角恒等式
       = c² × 旧值_i

从第一个盒子起一个接一个成立，所以每个盒子都乘 c² = cos²θ；最平缓的 θ = π/N，因子就是 cos²(π/N)。这个正弦越往右越矮（c^i 越来越小）：N = 5 停下时的误差是 −0.76、−1.53、−1.53、−1.02、−0.34（× 10⁻⁶），按最大值归一是 0.50、1、1、0.67、0.22；公式 c^i × sin(θ(i + 0.5)) 给 0.47、1、1、0.65、0.20。

公式和实测的差别全来自两端：推导里每个盒子都是等权的邻居平均，而紧挨墙的盒子分母是 3k（边界墙 2k）。盒子越多，两端占的比例越小：

再用近似 cos θ ≈ 1 − θ²/2（θ 很小时成立，是余弦在 0 附近的泰勒展开；比如 θ = 0.1 时，cos 0.1 = 0.99500，1 − 0.005 = 0.99500）：cos²(π/N) ≈ 1 − π²/N²。每遍磨掉的比例 ≈ π²/N²，N 翻倍它变成四分之一——和第三步手算的结论一致，而且连系数都给准了。

五 · 这对几百万网格意味着什么

二维、三维的道理一样：每遍磨掉的比例仍是 π²/N² 的量级（N 是每边的格数），所以遍数跟 N² 走。但格子总数涨得更快：

每边 20 格每边 40 格格子数遍数总工作量
二维20 × 20 = 40040 × 40 = 1600× 4× 4× 16
三维20 × 20 × 20 = 800040 × 40 × 40 = 64000× 8× 4× 32

这就是 OpenFOAM 不只靠高斯-塞德尔的原因。cavity 的速度方程用它没问题（插页 A 第五节那份 fvSolution）；同一个文件里，压力 p 用的是另一个求解器 PCG，以后讲。再看整个仓库：教程里共有 314 份 fvSolution，其中 187 份用 GAMG（多重网格）当求解器，比 smoothSolver 的 165 份、PCG 的 119 份都多。

多重网格的想法正好接着这一课：平缓的误差在细网格上磨不动，那就换到粗网格上去。在粗网格上，同一个鼓包只跨几个盒子，N 小了，每遍磨掉的比例 π²/N² 就大了。这是插页 C 的内容。

六 · 和那门图形课的对照

那门课第 2 课里，方波的锐利边缘先塌，平台的峰值纹丝不动。和这一课是同一件事：加权平均先削尖锐的，后削平缓的。

在求解器里，这一半是好事（锯齿误差一下就没了），一半是坏事（平缓误差磨不动）；在那门课的平流里，它是坏事（界面被抹糊）。（对照表第 13 行，从这一课起解锁。）

  2. 同一个 N，容差从 1e-6 收紧到 1e-12，遍数大约翻一倍。平缓误差每遍按同一个比例缩小，要多缩小一百万倍，就要再扫差不多同样多的遍数。实测：N = 20 从 480 遍变成 1038 遍，N = 40 从 1705 遍变成 3943 遍。
