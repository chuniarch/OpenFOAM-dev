插页 D · 共轭梯度预备（一）

第二次改动，
怎样保住第一次的结果？

两个盒子，各有一条“进 = 出”。先把 1 号算对，再改单独的 2 号，1 号的账又不平了。这次试着让两个数按一个比例一起改。

正文约 8–10 分钟 · 练习另算一个目标：算出两个盒子该怎样配合改动本页手算，不写程序

从同一道题的两种算法开始

摆好盒子 → 逐个算会发生什么 → 推改动比例 → 算到两条账都平 → 练习

课程顺序接在第 10C 课之后。本页用到的稳态方程会重新推一遍；水静止，只保留扩散。

先摆好两个盒子和验收尺子

水静止，没有对流，也没有墨的产生或消失
两个等宽盒子，浓度叫 C_1、C_2，单位 kg/m³
左墙浓度钉死在 10，右墙浓度钉死在 0
盒子之间的内部面权重 k = 1 m³/s
每面边界墙权重 2k = 2 m³/s
要求：稳态，每个盒子都满足“进 = 出”
开始给两个未知浓度猜值：C_1 = 0，C_2 = 0

验收尺子：最终两个浓度分别代回各自的净流入，结果都必须是 0。只让两盒净流入的总和为 0，还不够。

每个面扩散进来的墨量是 权重 ×（对面浓度 − 自己浓度）。两盒各写一条：

1 号净流入 = 2k × (10 − C_1) + k × (C_2 − C_1)
           = k × (20 − 3C_1 + C_2)
2 号净流入 = k × (C_1 − C_2) + 2k × (0 − C_2)
           = k × (C_1 − 3C_2)

稳态时两条都等于 0，除以 k 并移项：
第一条：3C_1 − C_2 = 20
第二条：−C_1 + 3C_2 = 0

最后两行的各项单位都是 kg/m³。数字 20 来自左墙的 2 × 10；数字 3 来自这个盒子相连的权重 2 + 1。

一 · 先算 1 号，再单独算 2 号

先保持 C_2 = 0，把第一条配平：

3C_1 − 0 = 20  →  C_1 = 20/3
当前猜值：(C_1, C_2) = (20/3, 0)

1 号净流入 = k × [20 − 3 × (20/3) + 0] = 0
2 号净流入 = k × [(20/3) − 3 × 0] = 20k/3

1 号已配平，2 号还没配平。照“算完一个就写回”的高斯—塞德尔做法，保持 C_1 = 20/3，重算 2 号：

−20/3 + 3C_2 = 0  →  C_2 = 20/9
当前猜值：(C_1, C_2) = (20/3, 20/9)

2 号净流入 = k × [(20/3) − 3 × (20/9)] = 0
1 号净流入 = k × [20 − 3 × (20/3) + 20/9]
           = 20k/9，不再是 0

原因在内部面上：2 号浓度升高，k × (C_2 − C_1) 便发生了变化。只改 2 号，就会改变 1 号的净流入。高斯—塞德尔会在下一遍再修正 1 号；我们现在找另一种安排改动的方法。

二 · 让两个数一起改

回到第一条刚刚配平的状态：C_1 = 20/3、C_2 = 0。第二次改动时，准备让 1 号增加 a、2 号增加 b；a、b 的单位也是 kg/m³。要保住第一条，直接把改后的数代进去：

第一条原来是：3 × (20/3) − 0 = 20
改完后必须仍是：
  3 × (20/3 + a) − (0 + b) = 20
  20 + 3a − b = 20
  3a − b = 0
  a = b/3

因此，2 号每增加 1，1 号同时增加 1/3，第一条左边的改动就是 3 × (1/3) − 1 = 0。这个比例从原方程里算出来，不需要知道最终答案。

也用两道面的流量核对一次。1 号当前为 20/3、2 号为 0；分别增加 a、b 后，1 号净流入的改动为：

左墙贡献的改动 = −2k × a
内部面贡献的改动 = k × (b − a)
合计 = −2ka + kb − ka = k × (b − 3a)

令 a = b/3：合计 = k × (b − b) = 0
这次只新增这一件事

解联立方程时，一次可以同时改多个盒子。改动的比例由方程系数决定；这道题用 (a, b) = (b/3, b)，保住了第一条已经配平的结果。

三 · 比例有了，还要算这次改多少

左墙 10、右墙 0、内部面 k、边界墙 2k。我们从 C_1 = 20/3、C_2 = 0 出发，按上面推得的比例改：

C_1 新 = 20/3 + b/3
C_2 新 = b

第一条对任意 b 都保住了。让第二条也配平，就能决定 b：

第二条：−C_1 新 + 3C_2 新 = 0
  −(20/3 + b/3) + 3b = 0
  −20/3 + (8/3)b = 0
  b = (20/3) / (8/3) = 20/8 = 5/2

1 号增加 a = b/3 = 5/6
C_1 新 = 20/3 + 5/6 = 40/6 + 5/6 = 7.5
C_2 新 = 5/2 = 2.5

把得到的浓度代回两个盒子的净流入，做最开始约定的验收：

1 号：2k × (10 − 7.5) + k × (2.5 − 7.5)
    = 5k − 5k = 0
2 号：k × (7.5 − 2.5) + 2k × (0 − 2.5)
    = 5k − 5k = 0

k = 1 m³/s，三个面从左到右传递的墨量都是 5 kg/s。两个盒子分别不再积累墨，两条账同时成立。

四 · 这怎样接到“共轭”

我们做了两次改动：

  1. 第一次只动 1 号，方向比例写成 (1, 0)：改动大小乘在这两个数上。
  2. 第二次两盒一起动，方向比例是 (1/3, 1)：2 号每增加 b，1 号增加 b/3。

这是一对相对于本题方程系数的共轭方向。Conjugate Gradient 中文叫“共轭梯度法”，缩写 CG；它利用这样的方向来安排改动。[来源] 这页先看清方向的作用，如何从残差自动生成方向和改动大小，放到下一节。

想对上教材的“共轭”记号，再展开

两条方程的系数排成一张表 A，第一次方向叫 p，第二次方向叫 q：

A = [ 3  −1 ]    p = (1, 0)    q = (1/3, 1)
    [−1   3 ]

A 作用在 q 上，就是算这次方向引起的两条左边改动：
第一条：3 × (1/3) − 1 × 1 = 0
第二条：−1 × (1/3) + 3 × 1 = 8/3

用 p 的两个数分别乘这两项，再相加：
1 × 0 + 0 × (8/3) = 0
教材把这个检查写成 pᵀ A q = 0。

本例第一次方向恰好只动 1 号，所以这个检查等价于“保住第一条”。一般 CG 不能理解成每一轮固定锁死一条盒子的方程。

与 OpenFOAM 的哪一行有关？

课程使用的 tutorials/legacy/incompressible/icoFoam/cavity/cavity/system/fvSolution 中，压力 p 的设置包含：

solver          PCG;
preconditioner  DIC;

PCG 的 CG 就是共轭梯度；P 指预处理，后面再讲。本页只演示一对共轭方向，还没有推出完整的压力求解算法。

五 · 自己算一次

下面都是解稳态方程时的猜值改动，没有推进时间。先算，再点选；每题点选后立即展开过程。

1. 两盒水静止、只有扩散；左墙浓度 10，右墙 0；内部面 k = 1 m³/s，边界墙各 2k。当前 C_1 = 20/3、C_2 = 0。只把 C_2 增加 1 kg/m³、保持 C_1 不动，1 号净流入变成多少 kg/s？

2. 两盒水静止、只有扩散；左墙浓度 10，右墙 0；内部面 k = 1 m³/s，边界墙各 2k。当前 C_1 = 20/3、C_2 = 0。准备让 C_2 增加 1 kg/m³，同时让 C_1 增加 a。要保持第一条 3C_1 − C_2 = 20，a 应是多少 kg/m³？

3. 换一道权重不同的题：水静止，左墙浓度 10、权重 3k；内部面 k；右墙浓度 0、权重 2k；k = 1 m³/s。当前 C_1 = 7.5、C_2 = 0，第一条 4C_1 − C_2 = 30 已配平。若 C_2 增加 1 kg/m³，C_1 要同时增加多少 kg/m³，才能保住第一条？

想核对出处时

首选延伸阅读：Greenshields 与 Weller · Notes on CFD §5.15，Conjugate gradient method（共轭梯度法）。本页把“相对于 A 的共轭”拆成两盒方程和具体改动；你现在只需对上两个方向和那次结果为 0 的检查。

后续才读§5.16，Preconditioning and asymmetry（预处理与非对称性）。本例两次改动解出答案，不能直接推广成实际 CFD 总能用两次求解。

读完只回我一道题：两盒水静止，左墙浓度 10、权重 3k；内部面权重 2k；右墙浓度 0、权重 2k；k = 1 m³/s。当前 C_1 = 6、C_2 = 0，第一条已经配平。若让 C_2 增加 1 kg/m³，C_1 应同时增加多少？请写出第一条左边的改动。
