第 5 课 · 砖块 5

墙外面是什么

一排盒子的最两端，墙的另一边没有盒子。这一课讲清这种墙怎么写。学完你能写出一排盒子两端那两个盒子的方程。

约 8 分钟前置：第 4 课（w = D·A/d）一个概念，两种墙

三十秒回顾

第 4 课：每道墙的权重

w = D * A / d          d = 两个盒子【中心之间】的距离

内部的每一道墙，两边都有盒子，所以这一项总能写出来：

流进 P 的墨量 = w * (C_邻居 − C_P)

这一课只处理一个问题：墙的另一边没有邻居时怎么办。

一 · 边界墙缺了什么

1 号盒子的左墙，公式里的 C_邻居 没有了着落。所以边界墙要回答两个问题：

  1. 这道墙的 d 是多少？
  2. 墙外面的浓度是多少 —— 或者，这道墙到底通不通？

二 · d 只有半格

直接用第 4 课：d 是从盒子中心量到"对面那个已知点"的距离。边界墙对面没有盒子中心，最近的已知点就是墙本身。盒子中心到自己的墙，正好半格：

w_边界 = D * A / (Δx/2)
       = 2 * (D * A / Δx)
       = 2k                       k = 内部墙的权重
结论

边界墙的权重是内部墙的两倍。这不是规定，是第 4 课的公式代入半格距离的结果。

常见错误

照抄内部墙的 k。这等于假装墙外半格处还有一个盒子 —— 相当于把墙往外推了半格。练习第 3 题会让你算出后果。

三 · 两种边界墙

钉死浓度的墙不透水的墙
现实里是什么墙外接着一大缸浓度不变的墨水，被抽走多少就补多少一块玻璃，墨水穿不过去
流进 P 的墨量2k * (C_墙 − C_P)0
OpenFOAM 里叫fixedValue（固定值）zeroGradient（零梯度）

钉死浓度的墙：和内部墙是同一个式子，只换两处 —— C_邻居 换成墙上已知的 C_墙，k 换成 2k。

不透水的墙：这一项直接是 0。写方程时，这个方向什么都不加。名字叫"零梯度"是因为：墙上浓度的坡度为零，按第 4 课，坡度为零就没有流量。

最容易搞反的地方

不透水 ≠ 把墙钉死成 0。

「钉死成 0」= 墙外是一大缸清水，拼命把墨吸走。
「不透水」= 墨根本出不去，全留在里面。

一个是无底洞，一个是玻璃。方向完全相反。

四 · 写出两端盒子的方程

一排 5 个盒子，均匀网格，稳态。左墙钉死 C = 10，右墙钉死 C = 0。内部墙权重 k，边界墙 2k。

  1. 中间三个盒子：和砖块 3 一模一样 
    C_2 = (C_1 + C_3) / 2
C_3 = (C_2 + C_4) / 2
C_4 = (C_3 + C_5) / 2
  2. 1 号盒子：左墙是边界（2k，墙上 10），右墙是内部（k，邻居 C_2） 
    2k * (10 − C_1) + k * (C_2 − C_1) = 0

展开：   20k − 2k*C_1 + k*C_2 − k*C_1 = 0
整理：   3k * C_1 = 20k + k*C_2
两边除以 k：
         C_1 = (20 + C_2) / 3
  3. 5 号盒子：同理，左墙内部（k，邻居 C_4），右墙边界（2k，墙上 0） 
    k * (C_4 − C_5) + 2k * (0 − C_5) = 0
⇒  C_5 = C_4 / 3
  4. 把答案代回去检查

    五条方程联立解出来是 9, 7, 5, 3, 1。逐条代回：

    C_1 = (20 + 7) / 3 = 27 / 3 = 9     ✓
C_2 = (9 + 5) / 2        = 7        ✓
C_3 = (7 + 3) / 2        = 5        ✓
C_4 = (5 + 1) / 2        = 3        ✓
C_5 = 3 / 3              = 1        ✓

    下一节告诉你：其实不用解方程，也能直接看出是这五个数。

注意 1 号盒子的式子：分母是 3，不是 2。边界上的盒子，不再是"两个邻居的平均" —— 墙那一侧的权重是 2，把它往墙上的值拉得更紧。

五 · 验收尺子

尺子一：直线钉在墙上，不钉在盒子上

砖块 3 说过：一维、稳态、无源 ⇒ 解是直线。现在补全这句话：这条直线的两端钉在墙上，不是钉在两端盒子的中心上。

全长 L，左墙 x = 0 处是 10，右墙 x = L 处是 0
⇒  C(x) = 10 − 10 * x / L

5 个盒子，每格宽 0.2L，中心在 (编号 − 0.5) * 0.2L：
    x = 0.1L   0.3L   0.5L   0.7L   0.9L
    C =  9      7      5      3      1

这就是第四节那五个数，不用解方程。

所以第一个盒子是 9，不是 10。10 是墙上的值，9 是半格之外那个盒子中心的值。写代码时最容易把这两个搞混。

尺子二：平场保持平

两端都钉死成 5 ⇒ 五个盒子必须全是 5。代码写好先跑这个，分母漏加、2k 写错，一跑就露馅。

尺子三：一端钉死、一端不透水 ⇒ 全场等于钉死的那个值

左墙钉死 10，右墙不透水，稳态 ⇒ 五个盒子全是 10。推理只用两条你已经会的东西：

砖块 2：一维稳态，每个盒子进 = 出 ⇒ 每道墙过的墨一样多
不透水的那道墙过的墨是 0
⇒ 每道墙过的墨都是 0
⇒ 任何两个相邻盒子之间都没有浓度差
⇒ 全场一样，等于左墙钉死的 10

如果你的程序在这个设置下算出了任何不是 10 的数，不透水的墙就写错了 —— 多半是写成了"钉死成 0"。

练习

每题只有一次机会，凭理解选，别回头翻。答错了也会告诉你为什么。

1. 均匀网格，格宽 Δx。边界墙的 d 是多少？

2. 一排盒子，左墙钉死 C = 10，右墙不透水，稳态。中间任意一个盒子的浓度是多少？

3. 5 个盒子，两端钉死 10 和 0。如果边界墙错用了 k（而不是 2k），1 号盒子算出来会怎样？（正确值是 9）

下一步：一排盒子的方程互相咬着（砖块 3），不能一个一个算。怎么真的把它们解出来？—— 迭代法。然后你就能写第一个程序了。

这一课在 cavity 里的样子：OpenFOAM 的 cavity 算例（本仓库 tutorials/legacy/incompressible/icoFoam/cavity/cavity/0/）里，压力文件 p 的四面墙全是 zeroGradient，速度文件 U 的顶盖是 fixedValue，值为 (1 0 0) —— 就是那个以 1 m/s 向右拖动的盖子。你现在认得这两个词了。

主要参考：上面那两个文件本身 —— 它们是 OpenFOAM 里边界条件最真实的样子，比任何教科书都权威。理论推导见 Jasak (1996) 第 3 章讲边界条件的部分。
