## 0. 符号与单位

```
C          浓度 = 单位体积混合液里溶的墨量                    [kg/m³]
C_P        当前盒子的浓度（未知数）                           [kg/m³]
C_n        某个邻居的浓度                                     [kg/m³]
V          盒子体积                                           [m³]
A_face     一道墙的面积                                       [m²]
Δx         两个盒子【中心之间】的距离                          [m]
D          扩散系数（介质属性，给定）                          [m²/s]
J          通量密度 = 单位时间单位面积穿过的量（矢量，逐点）     [kg/(m²·s)]
Q          流量     = 单位时间整道墙穿过的量（标量，逐面）       [kg/s]
w （= k）  面的传导权重 = 单位浓度差下每秒能送过去多少墨         [m³/s]
```

**浓度 ≠ 总量**（`总量 = C·V`）；**浓度 ≠ 密度**（密度说水本身多重，浓度说水里溶了多少墨）。
离散世界里 `C_P` 是**盒子的体积平均值**，不是中心那一点的值（二阶精度下差 `O(Δx²)`）。

## 1. 砖块 1 —— 两个盒子之间的输运

```
[1.1] 浓度定义        C = 这块体积里的墨量 / 这块体积                [kg/m³]

[1.2] 总量            总量 = C · V                                  [kg]

[1.3] 两盒流量         Q = w · (C_A − C_B)                          [kg/s]
                      从浓流向淡；C_A = C_B ⇒ Q = 0（动态平衡，双向交换相等）

[1.4] 最终平衡浓度     C_eq = (V_A·C_A + V_B·C_B) / (V_A + V_B)      [kg/m³]
                      方向由【浓度】定，终点由【总量】定
```

**物理**：大量分子的运动服从统计规律，净输运正比于两侧**局部**浓度差。
局部性（一道墙只由紧挨它两侧的状态决定）是有限体积法能成立的地基。
连续介质假设：微团大到统计涨落 ~1/√N 可忽略，小到在流场尺度上算一个点。

## 2. 通量密度 与 流量（术语，贯穿全程）

```
[2.1] 菲克定律（通量密度）  J = −D · (dC/dx)                    [kg/(m²·s)]
                            负号 = 沿浓度【下降】方向输运

[2.2] 流量 = 通量密度 × 面积  Q = J_n · A_face                   [kg/s]
                              J_n = J 在该面法向上的投影

[2.3] 由 [2.1]+[2.2] 推出权重
      J_n = D·(C_L − C_P)/Δx
      Q   = (D·A_face/Δx) · (C_L − C_P)  ⇒  w = D·A_face/Δx      [m³/s]
```

**窗户开大一倍**：`J` 不变，`Q` 翻倍。
**FVM 存 Q 不存 J**：相邻两盒共用一道墙，同一个 Q 一侧流出、另一侧流入，
相加时逐项对消（telescoping）⇒ **全局守恒是机械保证的**，与解得准不准无关。

**OpenFOAM 约定**：代码里的 `flux` 一律是**已乘面积**的量。
`Sf` = 面积矢量 [m²]；`phi` = `U·Sf` = 体积流率 [m³/s]；`fvc::flux(U)` 就是在算它。

## 3. 砖块 2 —— 一个盒子的「进 = 出」

```
[3.1] 符号约定：每一项都写成「流进 P」
      从邻居 n 流进 P 的量 = w_n · (C_n − C_P)
      括号为正 = 真的流进；为负 = 流出。一个式子兼顾两种情况。

[3.2] 稳态守恒（净流入为零）
      Σ_n  w_n · (C_n − C_P) = 0

[3.3] 稳态解 = 邻居的加权平均
                Σ_n (w_n · C_n)
      C_P  =  ───────────────────
                   Σ_n w_n

[3.4] 一维等权重退化
      C_P = (C_L + C_R) / 2

[3.5] 串联配平律（★仅当盒子只有两道墙时成立★）
      w_L · (C_L − C_P) = w_R · (C_P − C_R)
      ⇒ 权重大的一侧浓度差小；两侧浓度差之比 = 权重的【反】比
      ⇒ |C_P − C_L| : |C_P − C_R| = w_R : w_L
```

**为什么 [3.5] 只在两道墙时成立**：稳态给的是「**所有**墙的流量之和为零」。
只有两道墙时，才能由「和为零」推出「两者等大反号」。
二维四道墙时不存在两两配对的等式，只有 [3.2] 的总和为零。

**稳态 ≠ 静止**：墙上一直有流量穿堂而过，只是进出配平。

**极值原理**：稳态无源时，极大/极小只能出现在**边界**，内部不可能冒尖
（内点等于邻居的加权平均，平均值不可能严格大于所有被平均的数）。
⇒ 这是「有界」这把验收尺子的数学出处。

## 4. 砖块 3 —— 一整排盒子：联立方程组

```
[4.1] 每个盒子一条 [3.2]，但方程互相咬合成环
      ⇒ 不能按顺序逐个算（没有起点），也不能写递归（无限递归）
      ⇒ 必须联立求解

[4.2] 整理成矩阵（行 = 一个盒子的方程；列 = 一个未知数）
      对角元   = +Σ w_n        （自己的系数）
      非对角元 = −w_n          （每个邻居一个）
      右端项   = 已知量（边界固定值等）

      一维五盒等权重（w 已约去）：
        [  2  -1   0   0   0 ] [C_1]   [C_左边界]
        [ -1   2  -1   0   0 ] [C_2]   [   0    ]
        [  0  -1   2  -1   0 ] [C_3] = [   0    ]
        [  0   0  -1   2  -1 ] [C_4]   [   0    ]
        [  0   0   0  -1   2 ] [C_5]   [C_右边界]

[4.3] 稀疏性：一个盒子只连直接邻居
      每行非零个数：一维 3、二维 5、三维 7（与网格规模无关）
      ⇒ 绝不存成稠密二维数组；这就是 OpenFOAM lduMatrix
        （存一条对角线 + 每个面一对上/下三角系数）的由来
```

**矩阵不是新物理，只是记账格式**——摆成这样才能调用线性代数的现成武器。

## 5. 量纲自检（写完任何一条离散式先对一遍）

```
[5.1] [Q] = [w] · [ΔC] = (m³/s) · (kg/m³) = kg/s              ✓
[5.2] [w] = [D]·[A]/[Δx] = (m²/s)·(m²)/(m) = m³/s             ✓
[5.3] [J] = [D]·[dC/dx] = (m²/s)·(kg/m³)/(m) = kg/(m²·s)      ✓
```

对不上就一定错了。OpenFOAM 把这项检查做成了 `dimensionSet` 的自动校验。

## 6. 验收尺子（累积）

| # | 尺子 | 出自 | 怎么用 |
|---|---|---|---|
| 1 | 零差零流 | 砖块 1 | 两侧浓度相等 ⇒ 流量必须是 0 |
| 2 | 方向正确 | 砖块 1 | 必须从浓流向淡；反了就是符号错 |
| 3 | 反对称 | 砖块 1 | 两盒角色对调 ⇒ 流量等大反号 |
| 4 | 线性 | 砖块 1 | 浓度差翻倍 ⇒ 流量翻倍 |
| 5 | 平场保持平 | 砖块 2 | `C_L = C_R` ⇒ `C_P` 必须**正好**等于它（代码第一个该测的用例） |
| 6 | 有界 | 砖块 2 | 内部值必落在边界值的 [min, max] 内（极值原理） |
| 7 | 对称 | 砖块 2 | 左右对调 ⇒ 答案不变 |
| 8 | 残差归零 | 砖块 2 | 解回代进方程，两墙流量等大反号；这就是 OpenFOAM 打印的 residual |
| 9 | **1D 稳态无源 ⇒ 直线** | 砖块 3 | 每个内点 = 两邻居平均 ⟺ 等差数列 ⟺ 直线。不解方程就知道答案长什么样 |
