# 有限体积法术语表

本工作区的规范用语。所有 lesson、reference 和对话都以此为准。
只收录学习者已经能正确使用的术语 —— 它是压缩后的知识记录，不是待学清单。

## 场与状态量

**浓度**：
单位体积混合液里溶解的墨量，单位 `kg/m³`。离散世界里 `C_P` 指一个盒子的体积平均值。
_不要说_：密度（那是水本身有多重）、含量、总量

**总量**：
一块体积里墨的绝对数量，`总量 = C · V`，单位 `kg`。决定系统最终平衡到哪个浓度。
_不要说_：质量（会与水的质量混淆）

## 几何

**盒子（控制体）**：
把空间切开得到的一个有限体积块，是记账的基本单位。`P` 指当前盒子，`N` 或「邻居」指相邻盒子。
_不要说_：网格点、节点、单元格

**墙（面）**：
两个盒子之间的界面，也是流量唯一能穿过的地方。
_不要说_：边界（那专指计算域最外圈的墙）、界面

## 边界

**边界墙**：
计算区域最外圈的墙，另一侧没有盒子。盒子中心到它只有半格，所以权重是 `2k`（内部墙的两倍）。
_不要说_：边界条件（那是指给这道墙规定的规则，不是墙本身）

**钉死浓度的墙**：
墙上的浓度是给定的已知值，像墙外接着一大缸浓度不变的墨水。流进 P 的量 = `2k·(C_墙 − C_P)`。
OpenFOAM 里叫 `fixedValue`。
_不要说_：Dirichlet 边界、第一类边界条件

**不透水的墙**：
墨水穿不过去的墙，流量为 0，写方程时这个方向什么都不加。OpenFOAM 里叫 `zeroGradient`。
**不等于**把墙钉死成 0（那是墙外接一缸清水，会把墨吸走）。
_不要说_：Neumann 边界、绝热边界、零通量边界（都指同一件事，但本工作区统一用这个名字）

## 输运

**流量**：
单位时间穿过**整道墙**的墨量，单位 `kg/s`。本工作区说「流量」一律指这个已含面积的量。
_不要说_：通量（歧义）、flux

**通量密度**：
单位时间、单位面积穿过的墨量，单位 `kg/(m²·s)`。菲克定律 `J = −D·dC/dx` 给的是这个。
`流量 = 通量密度 × 面积`。
_不要说_：通量、flux

**权重 w**：
一道墙的传导能力：单位浓度差下每秒能送过去多少墨，单位 `m³/s`。
_不要说_：系数、常数 k（`k` 只在均匀网格的简写里用）

## 方法

**稳态**：
盒子里的量不再随时间变化，等价于每个盒子的净流入为零。**不等于静止** —— 墙上仍有流量穿堂而过。
_不要说_：平衡、收敛（收敛说的是迭代，不是物理状态）

**净流入**：
一个盒子所有墙上流入量的代数和。本工作区的符号约定是每一项都写成 `w·(C_邻居 − C_P)`，
括号为正即流入、为负即流出。
_不要说_：进出差、残差（残差指方程没配平的余量）

**扫一遍**：
按砖块 2 的式子，把所有盒子各重新算一次。算出一个新值就立刻写回、后面的盒子马上用上（高斯-塞德尔）。
_不要说_：迭代一步、一次松弛

**容差**：
事先定好的一个很小的数。某一遍的最大改动小于它，就认为已经算够了，停止。
_不要说_：精度、误差限

**验收尺子**：
不跑参考解也能判断结果对错的物理必要条件：守恒 / 有界 / 单调 / 对称 / 解析解。
_不要说_：验证、测试、sanity check
