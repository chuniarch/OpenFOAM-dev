## 0. 先把骨架摆出来（全篇只有这一条方程）

不管几维、不管什么边界、不管稳态还是瞬态，被解的永远是这一条：

```
Σ_faces (穿过这个面【流进】P 的量)  =  V * (C_P_new − C_P_old) / Δt
└──────────────┬──────────────┘     └──────────┬──────────┘
        所有面的净流入                      盒子里的堆积

稳态 ⇒ 右边 = 0
```

- **维度**改变的，只是左边 `Σ` 里**有几项**（1D 两项、2D 四项、3D 六项）。
- **边界条件**改变的，只是**某一项怎么写**。
- **骨架一个字都不改。** 这是整套方法最值钱的性质。

内部面那一项永远长这样（砖块 2 定下的符号约定，一律写成「流进 P」）：

```
内部面 f 的贡献 = w_f * (C_邻居 − C_P)          w_f = D * A_f / d_f
```

## 1. 维度

### 1.1 一维

每个盒子 **2 个面**（西 W、东 E）。

```
V   = Δx * A                       A = 横截面积（教学里取 Δy * depth）
w_W = D * A / d_W                  d_W = 到西邻居中心的距离
w_E = D * A / d_E

稳态内部盒子：
    w_W*(C_W − C_P) + w_E*(C_E − C_P) = 0

解出：
    C_P = (w_W*C_W + w_E*C_E) / (w_W + w_E)

均匀网格（w_W = w_E）：
    C_P = (C_W + C_E) / 2
```

**验收尺子**：稳态、无源、两端 fixedValue ⇒ 解在**物理坐标 x** 上是一条直线。

### 1.2 二维

每个盒子 **4 个面**（西 W、东 E、南 S、北 N）。

```
V    = Δx * Δy * depth             二维取 depth = 1 m
A_x  = Δy * depth                  东西墙的面积（法向沿 x）
A_y  = Δx * depth                  南北墙的面积（法向沿 y）

w_x  = D * A_x / Δx = D * Δy * depth / Δx
w_y  = D * A_y / Δy = D * Δx * depth / Δy

稳态内部盒子：
    w_x*(C_W − C_P) + w_x*(C_E − C_P) + w_y*(C_S − C_P) + w_y*(C_N − C_P) = 0

解出：
    C_P = (Σ_n w_n * C_n) / (Σ_n w_n)          n 遍历 4 个邻居

均匀网格（Δx = Δy）⇒ w_x = w_y = D*depth：
    C_P = (C_W + C_E + C_S + C_N) / 4          四邻居算术平均
```

**★易错点★：`Δx ≠ Δy` 时 `w_x ≠ w_y`，而且差得很厉害。**
例如 `Δx = 2Δy`：

```
w_x = D*Δy*1/(2Δy) = D/2
w_y = D*(2Δy)*1/Δy = 2D
                              ⇒ w_y / w_x = 4
```

格子拉长一倍，两个方向的权重差 4 倍。**绝不能图省事写一个统一的 k。**

**验收尺子**：二维一般没有"直线"可用，改用**对称性**——对称的边界条件必须给出对称的解。
另外还有一条很好用的**降维检验**：把上下设成 zeroGradient、左右设成 fixedValue，
二维解必须与一维程序**逐点吻合**，且沿 x 是直线。

### 1.3 三维

每个盒子 **6 个面**。`V = Δx*Δy*Δz`，三个方向各有自己的 `w`。结构与二维完全同构，没有新概念。

### 1.4 维度改变了什么、没改变什么

| 改变的 | 一维 | 二维 | 三维 |
|---|---|---|---|
| 每个盒子的面数 | 2 | 4 | 6 |
| 矩阵每行非零元个数 | 3 | 5 | 7 |
| 体积 V | `Δx*A` | `Δx*Δy*depth` | `Δx*Δy*Δz` |
| 显式稳定上限 `Δt ≤ V/Σw`（均匀网格） | `Δx²/(2D)` | `Δx²/(4D)` | `Δx²/(6D)` |
| 数据结构 | `[Double]` | `[[Double]]` 或展平索引 | 展平索引 |

**没改变的**：守恒律本身、加权平均的形式、边界条件的处理方式、验收尺子的逻辑、
以及「不能逐个算、必须联立」这件事。

## 2. 边界条件

### 2.0 一切的根：墙不是盒子中心

```
内部面：两侧都是盒子中心    ⇒  d = Δx（均匀网格）   ⇒  w = D*A/Δx      ≡ k
边界面：一侧是盒子中心，
        另一侧就是墙本身    ⇒  d = Δx/2            ⇒  w = D*A/(Δx/2) = 2k
```

**边界墙的权重是内部墙的两倍。** 这不是约定，是砖块 4 的 `w = D*A/d` 代入半距离的直接结果。

#### 用错会怎样（真实数字）

一维、5 个盒子、两端 fixedValue `C_left = 10`、`C_right = 0`、均匀网格：

```
边界用 2k（正确）：  9.0000  7.0000  5.0000  3.0000  1.0000     ← 与解析直线逐点相等
边界误用 k（错误）： 8.3333  6.6667  5.0000  3.3333  1.6667     ← 仍是直线，但斜率错了
```

误用 `k` 相当于把边界**往外挪了 Δx/2**，解还是直线（所以"直线"这把尺子抓不住它！），
但**取值全错**。要抓它，必须拿解析解在 `x = Δx/2` 处的值去比对第一个盒子。

### 2.1 fixedValue（Dirichlet）—— 墙上钉死浓度

**物理**：墙外是一个浓度恒定的无限大池子；或者这面墙被人为维持在某个浓度 `C_b`。

**方程**：这一项照常写成「流进 P」，只是邻居换成墙上的已知值、权重换成 `2k`：

```
流进 P 的量 = 2k * (C_b − C_P)
```

**组装时**：`C_b` 是已知数，把含它的部分挪到方程右边当源项：

```
分子 += 2k * C_b
分母 += 2k
```

**矩阵视角**：对角元 `+= 2k`，右端项 `+= 2k*C_b`，**不产生非对角元**
（因为墙上的值不是未知数）。边界条件从不增加未知数，只修改已有的那一行。

### 2.2 zeroGradient（齐次 Neumann）—— 砌死的墙

**物理**：墨水穿不过去。绝缘壁、或者对称面。

**数学**：`dC/dn = 0` ⇒ `J = 0` ⇒ 该面流量 `Q = 0`。

**方程**：

```
流进 P 的量 = 0

分子 += 0
分母 += 0        ← 也就是：什么都不加，直接跳过这个方向
```

**★最常见的错误★：把它写成「`C_b = 0` 的 fixedValue」。** 两者物理上完全相反：

| | 含义 |
|---|---|
| `zeroGradient` | 这道墙**不让墨通过**。墨被挡住、留在盒子里 |
| `fixedValue(0)` | 这道墙后面是**无限大的清水池**，拼命把墨抽走 |

判别口诀：**zeroGradient 是「没有这道墙」，fixedValue(0) 是「墙后面有个无底洞」。**

### 2.3 fixedGradient（一般 Neumann）—— 指定通量

**物理**：墙上以给定速率注入或抽出墨（一个喷嘴、一个抽吸口）。

**数学**：给定 `J_b`，或直接给定该面的流量 `Q_b`（以**流进 P** 为正）。

```
流进 P 的量 = Q_b = J_b * A_face

分子 += Q_b
分母 += 0        ← ★分母不加★
```

**为什么分母不加**：已知的是**流量本身**，它不依赖 `C_P`，所以没有任何东西可以挪到对角线上去。
这条区别在代码里很容易写错。

`zeroGradient` 就是 `Q_b = 0` 的特例——这解释了它为什么"什么都不加"。

### 2.4 symmetry（对称面）

对标量而言，数学上等价于 `zeroGradient`。物理图像是**镜子**：
镜子两侧的浓度一模一样，浓度差为零，所以净流量为零。

（到了矢量场，比如速度，symmetry 与 zeroGradient 不再等价：法向分量要翻号。这是砖块 11 的事。）

### 2.5 全 zeroGradient 的稳态是奇异的

若**所有**边界都是 `zeroGradient`（完全封闭的盒子），稳态方程组**没有唯一解**：

- 任何常数场 `C = const` 都满足「每个盒子净流入 = 0」；
- 矩阵角度：每一行的系数之和为零 ⇒ 常数向量落在零空间里 ⇒ 矩阵奇异；
- 物理角度：封闭系统最终均匀化到哪个值，取决于**初始总量**，
  而稳态方程里根本没有"总量"这个信息——这个信息在取稳态的那一刻就被丢掉了。

**解决办法**：钉一个参考点（指定某个盒子的值）。

```
OpenFOAM：  pEqn.setReference(pRefCell, pRefValue)
```

**这正是 icoFoam 里压力方程必须 setReference 的同一件事**——cavity 四壁全是墙，
压力的边界条件全是 zeroGradient，压力方程于是奇异，只能定到一个相差常数的程度。
（呼应 `context/icofoam-cavity-walkthrough.md` §4.3 的"坑 2"。）

**瞬态没有这个问题**：时间项贡献的 `a = V/Δt` 加在对角线上，矩阵严格对角占优、可逆；
而且总量由初始条件决定，信息没有丢。

### 2.6 矩阵视角总表

以「`分子 / 分母` 形式的高斯-塞德尔更新」和「矩阵元素」两种说法对照：

| 面的类型 | 分子 | 分母 | 对角元 | 非对角元 | 右端项 |
|---|---|---|---|---|---|
| 内部面 | `+= k * C_邻居` | `+= k` | `+= k` | `−k` | 不变 |
| fixedValue | `+= 2k * C_b` | `+= 2k` | `+= 2k` | 无 | `+= 2k*C_b` |
| zeroGradient | 不变 | 不变 | 不变 | 无 | 不变 |
| fixedGradient | `+= Q_b` | 不变 | 不变 | 无 | `+= Q_b` |
| （瞬态时间项） | `+= a * C_P_old` | `+= a` | `+= a` | 无 | `+= a*C_P_old` |

`a = V/Δt`。注意 `a` 与 `k` 量纲相同（都是 `m³/s`），所以能直接相加。

### 2.7 半距离不总是 Δx/2

`Δx/2` 只适用于**正交、边界面与网格线垂直**的情形。一般网格上，
`d_b` = 盒子中心到**面心**的距离（沿面法向的投影），要按实际几何算。

```
OpenFOAM：patch 上的 deltaCoeffs = 1/d_b
```

## 3. 稳态 / 显式瞬态 / 隐式瞬态：边界写法完全一样

边界条件的处理**在三种骨架里逐字相同**，只是被塞进不同的位置：

```
【稳态】
    Σ_faces (流进 P) = 0
    ⇒ C_P = 分子 / 分母
      分子 = Σ w*C_邻居 + Σ 2k*C_b + Σ Q_b
      分母 = Σ w       + Σ 2k

【显式瞬态】右边全用旧值，一遍扫描出新场，必须双缓冲
    C_P_new = C_P_old + (Δt/V) * [ Σ w*(C_n_old − C_P_old) + Σ 2k*(C_b − C_P_old) + Σ Q_b ]
    稳定条件：Δt ≤ V / Σw        （均匀网格二维即 Δx²/(4D)）

【隐式瞬态】邻居取新值 ⇒ 又是联立方程组 ⇒ 内层迭代
              a*C_P_old + Σ w*C_n_new + Σ 2k*C_b + Σ Q_b
    C_P_new = ──────────────────────────────────────────         a = V/Δt
                      a + Σ w + Σ 2k
```

**「虚拟邻居」解读**：`a*C_P_old / a` 那一对，形式上与一个 `fixedValue` 边界一模一样——
自己的旧值就像第 5 个邻居，权重 `a`，把盒子往上一刻拉。
`Δt → ∞` 时 `a → 0`，虚拟邻居消失，退回稳态；`Δt → 0` 时 `a → ∞`，`C_P_new ≈ C_P_old`。

## 4. 统一的组装伪码（维度与边界都只是分支）

```
分子 = 0
分母 = 0

若是隐式瞬态：  分子 += a * C_P_old ;  分母 += a

对 P 的每一个面 f：                      ← 维度只决定这个循环跑 2 / 4 / 6 次
    若 f 是内部面：      分子 += w_f * C_邻居 ;  分母 += w_f
    若 f 是 fixedValue： 分子 += 2k_f * C_b   ;  分母 += 2k_f
    若 f 是 zeroGradient：跳过
    若 f 是 fixedGradient：分子 += Q_b                （分母不动）

C_P = 分子 / 分母
```

**这段伪码就是 `fvm::laplacian(D, C)` 在做的全部事情**，外加边界条件由
`fvPatchField` 的各个派生类（`fixedValue` / `zeroGradient` / `fixedGradient` / `symmetry`）分别提供。

## 5. 针对边界与维度的验收尺子

| # | 尺子 | 做法 | 抓什么 bug |
|---|---|---|---|
| 1 | **平场保持平** | 全场初值 `C0`，所有边界 `fixedValue = C0` ⇒ 解必须**恰好**是 `C0` | 分母漏加、`2k` 写错、符号反了。第一个该跑的用例 |
| 2 | **半距离检验** | 一维两端 `fixedValue`，比对第一个盒子与解析直线在 `x = Δx/2` 处的值 | 边界误用 `k`（"直线"这把尺子抓不住它） |
| 3 | **封闭守恒** | 全 `zeroGradient` + 瞬态 ⇒ `Σ C*V` 必须守恒到机器精度 | 把 `zeroGradient` 写成 `fixedValue(0)`（总量会漏） |
| 4 | **降维检验** | 二维程序：左右 `fixedValue`、上下 `zeroGradient` ⇒ 必须与一维解逐点吻合、沿 x 成直线 | `w_x` / `w_y` 混用、y 方向多算了通量 |
| 5 | **对称检验** | 对称的边界条件 ⇒ 对称的解 | 四个方向处理不一致 |
| 6 | **各向异性检验** | 故意取 `Δx = 2Δy` 跑一遍 | 图省事用了统一的 `k` |
| 7 | **奇异性检验** | 全 `zeroGradient` 求**稳态** ⇒ 应当发现解不唯一/不收敛 | 说明你理解了为什么要 `setReference` |
