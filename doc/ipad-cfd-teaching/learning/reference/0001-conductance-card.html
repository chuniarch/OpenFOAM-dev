墙的权重 w

出自第 4 课回到课文

公式

w = D * A / d                          [m³/s]

D  扩散系数（材料属性，给定）           [m²/s]
A  这道墙的面积                        [m²]
d  两盒【中心之间】的实际距离            [m]

用法：  流进 P 的墨量 = w * (C_邻居 − C_P)      [kg/s]
读法：  单位浓度差下，这道墙每秒能送过去多少墨

d 怎么取

均匀网格      d = Δx
两格不等宽    d = Δx_P/2 + Δx_N/2        ← 不是任一侧的格宽
边界墙        d = Δx/2   ⇒  w = 2k       ← 砖块 5
一般网格      d = 盒心到面心沿面法向的距离
最难查的 bug

不等宽网格上拿某一侧的格宽当 d：程序不报错、不发散，只是算得不对。 而且均匀网格上三种写法给出同一个数，测试用例里必须放一个不均匀网格才抓得住。

量纲自检

[w] = (m²/s) * (m²) / (m)   = m³/s          ✓
[Q] = (m³/s) * (kg/m³)      = kg/s          ✓
[J] = (m²/s) * (kg/m³) / m  = kg/(m²·s)     ✓

验收尺子

尺子要求
量纲w 必须是 m³/s
极限D→0 或 A→0 ⇒ w→0；d→0 ⇒ w→∞
一致性均匀网格 + 均匀 D ⇒ 所有内部面的 w 完全相等
非均匀直线1D 稳态无源：即使格子宽窄不一，解在物理坐标 x 上仍是直线

标度直觉

扩散距离    L ≈ sqrt(2 * D * t)     ⇔     t ≈ L² / (2*D)

墨在水里 D ≈ 1e-9 m²/s：
    1 mm  →  约 8 分钟
    1 cm  →  约 14 小时
    10 cm →  约 58 天

距离翻倍，时间要四倍。这就是现实里必须靠搅拌（对流）的原因。

对应 OpenFOAM：fvm::laplacian(D, C) 组装的就是这些 w； deltaCoeffs = 1/d 由 surfaceInterpolation 提供。
