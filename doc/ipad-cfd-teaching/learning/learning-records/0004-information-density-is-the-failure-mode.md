# 信息密度超限会让学习者完全失去抓手

2026-09-21，应"把边界条件与维度再描述一遍"的要求，我产出了一份八页参考手册
（`bc-and-dimensions.md`），里面含四个尚未讲过的概念（fixedGradient、symmetry、矩阵奇异、
setReference）和一串没有推导过程的数字。学习者的反馈是"我已经完全看不懂你说的了"，
并逐条列出：不懂物理符号、不懂计算公式、不懂没有推导的结果、不懂英文术语。

**关键区分：参考资料不是课。** 手册按主题横切、追求完备；课按顺序纵切、追求一次一个win。
把前者当后者交付，即使内容全对也是失败。

**Implications**：
1. 任何"再讲一遍/总结一下"的请求，默认产出**课**而不是**手册**；手册要另存并明确标注"非教程"。
2. 一条消息里的新概念上限约为 1。超过就拆。
3. 提前倒出尚未走到的砖块内容 = 制造噪音，哪怕它正确。
