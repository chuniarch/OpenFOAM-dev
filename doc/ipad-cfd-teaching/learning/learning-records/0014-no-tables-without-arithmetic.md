# 「你又开始了，只写表格，根本不写计算过程」

2026-09-29，学习者读插页 C 第二节（第 2 版）后提出，全部成立：

1. 我写「残差是正的……所以 1 号现在偏淡，这和误差是负数对得上」。他指出：流入多于流出，浓度该增加，怎么是偏淡？
   两句话有什么逻辑关系？——**这是错误推理**。残差为正说明重算时会被往上改（残差 ÷ 分母 = 改动），
   推不出低于答案；1 号低于答案是碰巧，5 号（残差 0、误差 −0.722）就是反例。
2. 「用误差」那一列只给了表格，没有逐项算式：误差从哪来（1 号 6.667 − 9，2 号 3.333 − 7，墙外那缸水 10 − 10）没写。
3. 「误差的净流入」没定义、没说为什么需要，就直接拿来用。
4. 「墙外两缸水都当成 0」「按第 5 课的办法」——一个没给理由，一个没写办法是什么。
5. 他质问：我已经要求提到之前的内容要把细节写全，为什么还是不写。——我把第 15 条理解成「例子的条件写全」，
   做法和公式照样用代号引用。理解窄了。

**修正**：插页 C 第二节第 3 版（删掉错误推理，补「残差 ÷ 分母 = 改动」的推导；先定义净流入的算法、
再定义误差的净流入并说明为什么需要；三个误差逐个算出，墙外那缸水误差为 0 给出理由；五个盒子两种净流入全部写出算式；
锯齿每遍剩 1/3 的手算在第一节重写一遍；粗网格的误差更新式在引用处写出来）。NOTES 第 15 条扩大到做法和公式，新增第 16 条。

**Implications**：
1. 写「所以」之前，检查它是不是真的推得出来；只是在这个例子里碰巧成立的，要么不写，要么明说是碰巧。
2. 每引入一个新名词（「误差的净流入」），先说它是什么、怎么算、为什么需要，再用。
3. 他说一条规矩时，按最宽的意思执行。
