# 「分子里是 0，分母里怎么还有 2k」：我的记号把墙外那缸水踢出了邻居名单

插页 B 第 2 版第二节把更新式写成「内部邻居 + 边界项」，相减后说「钉死成 0 的墙，对分子贡献 0，对分母贡献 2k」。
学习者追问了两点，都成立：

1. 分子里的贡献是 0，分母里凭什么有贡献？要求从原始等式推一遍，亲眼看分母是不是 2k。
2. 加权平均应当是「所有邻居的权重 × 值」除以「所有邻居的权重和」。我的分母含边界墙的 2k，
   可我的「邻居」只列了内部盒子，那这就不是所有邻居的权重和，凭什么叫平均？

两个问题同一个根：我把钉死的墙写成「边界项」，等于把墙外那缸水从邻居名单里拿掉了。
砖块 2 的 [3.3] 本来就是对「每一面透墨的墙对面」求和，墙外那缸水（浓度 = C_墙，权重 2k）就是其中一个邻居。
把它放回名单，分母就是所有邻居的权重和，平均自然成立。

**修正**（插页 B 第二节重写为第 3 版，cheatsheet [5.5.2]、[5.6.2] 同步）：
- 从「进 = 出」出发推：`w × (C_对面 − C_P) = w × C_对面 − w × C_P`，前一股进分子，后一股进分母。
- 5 号盒子（右墙钉死 0）逐步展开、移项，看到 `2k × 0` 进分子、`−2k × C_5` 进分母；代答案核对穿过来 3k = 穿过去 3k。
- 误差由两条原始等式相减得到，墙外那缸水的误差 = 10 − 10 = 0，形状和 5 号盒子的右墙相同。
- 学习者写的「权重 × 浓度差 / 权重和」算出来的是改动，已在第三节推给他看。

**Implications**：
1. 边界不要写成「边界项」这种另起一类的记号。墙外那缸水始终列为邻居，和内部邻居写在同一个 Σ 里。
2. 「分子里是 0」和「这项不存在」是两回事：一个值为 0 的邻居仍在平均里，会把结果往 0 拉。
   这是 LR-0007（钉死 0 ≠ 不透水）在误差层面的再现，需要一道新题检验（本轮已出：N = 1，左钉死 0、右不透水）。
3. 推导要从原始等式（进 = 出）开始，不要从已经除过分母的式子开始相减，否则分母里有什么看不出来源。
