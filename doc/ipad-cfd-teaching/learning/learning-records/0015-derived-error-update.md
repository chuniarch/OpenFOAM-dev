# 学习者自己推出了误差更新式

2026-09-29。学习者不满足于课文里「残差 = 误差的净流入，再移项」的写法，自己从残差的定义出发推误差更新式。

第一版（手写）有三处问题：移项符号反了（写成 `Σ w_i C_p = R − Σ w_i C_i`）；误差写成带权重的 `Σ w_i (C_p − C_p′)`；
没用上「答案自己满足进 = 出」，结果里还留着答案。指出之后，第二版全对：

```
Σ w_i C_p = Σ w_i C_i − R
Werror = Σ w_i (C_p − C_p′) = Σ w_i C_i − R − Σ w_i C_p′
答案满足进 = 出：Σ w_i C_i′ = Σ w_i C_p′
Werror = Σ w_i (C_i − C_i′) − R = Σ w_i × (对面的误差) − R
E = [ Σ w_i × (对面的误差) − R ] / Σ w_i
```

默认没写的两步：`Werror = E × Σ w_i`（括号和 i 无关，可以提出来）；钉死的墙对面误差为 0。

**Implications**：
1. 他能独立完成「定义 → 移项 → 用另一条已知关系代换 → 化简」这种代数推导。给他关键事实（这里是「答案满足进 = 出」），比直接给结论有效。
2. 他写的记号（`Werror`、`ierror`）可以直接沿用，比我起的名字更贴他的思路。
3. 下一步用 2 号盒子那道题确认他会用，而不只是会推。
