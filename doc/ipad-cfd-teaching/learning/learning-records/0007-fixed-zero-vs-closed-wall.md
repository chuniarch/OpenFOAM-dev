# 「钉死成 0」和「不透水」被当成同一道题：课文没有并排对比

第 5 课里，第四节用「左钉死 10、右**钉死 0**」得出 `9, 7, 5, 3, 1`，尺子三用「左钉死 10、右**不透水**」得出全是 10。
学习者把两者当成同一个设定，于是看到"同一道题两个答案"。两者只差右墙一处，而这恰恰是本砖最核心的区分
（课文里也写了"不透水 ≠ 钉死成 0"），但两个设定分散在不同小节、没有并排放。

**修正**：课文加了并排对比表，逐行对照两种右墙下的 5 号方程（`C_5 = C_4/3` vs `C_5 = C_4`）、墨的状态
（穿堂而过 vs 装满不动）、每道墙流量（不为 0 vs 为 0）和答案（斜线 vs 平线）。

**Implications**：
1. 两个只差一处的设定，**必须并排呈现**，并在各自出现处标名（情形甲/情形乙）。分开讲会让学习者以为是同一题。
2. 这个区分在本学习者身上尚未确认已掌握 —— 需要他看完对比后再用一道新题检验。
3. 「稳态 ≠ 静止」（砖块 2）在这里第一次有了两个对照实例：情形甲是流动的稳态，情形乙是静止的稳态。
