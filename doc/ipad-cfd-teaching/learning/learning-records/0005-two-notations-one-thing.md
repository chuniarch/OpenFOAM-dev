# 菲克定律与盒子记账是同一个公式，必须显式演示

学习者问"为什么这两个对应不上"：一边是 `C_P = (w_W·C_W + w_E·C_E)/(w_W + w_E)`，
另一边是 `J = −D·dC/dx` 然后 `Q = J·A`。困惑的根源是我用了两套记号讲同一件事却没点破。

解法是**用同一组数字走两条路，得到同一个答案**（`3e-11 kg/s`），并指出负号在盒子记账里
被"每项都写成 `(邻居 − 自己)`"的符号约定吸收掉了。学习者接受了这个演示。

**Implications**：凡是引入教科书记号（`∇`、`∇²`、`div`、`grad`）时，都必须当场给出
"它等于你已经写过的哪个东西"的数值演示，否则会重复这次的困惑。
这条在进入砖块 11 的 `a_P`/`H(U)` 时尤其关键。
