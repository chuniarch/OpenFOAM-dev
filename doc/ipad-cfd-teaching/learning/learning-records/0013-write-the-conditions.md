# 「你凭什么觉得我能记住这个情形的具体数据」：代号不能代替条件

读插页 C 第二节时，学习者提了四点，全部成立：

1. 「又是残差又是误差」：两个概念没有先各自定义就混着用。
2. 「答案的净流入（= 0）+ 误差的净流入 = R_P」看不懂：最终答案的净流入不就该是 0 吗？
   我没说清 R_P 算的是**现在的值**的净流入，那个加法是把现在的值拆成「答案 + 误差」后分别算。
3. 「情形甲 N = 5，初值全 0」：情形的代号是我起的，条件（几个盒子、墙各是什么、权重、答案）一个没写。
4. 「五个盒子依次是 3.333k…」和「可以直接减出误差 −2.333…」两句并排，没说两者是什么关系、为什么放一起。

**修正**：
- NOTES 新增第 15 条：回头引用一个情形时，条件当场写全；两组数并排要当场说明关系。
- 插页 C 第二节重写：先写全例子的条件；再定义误差（浓度，要答案）与残差（每秒墨量，不要答案），
  两者单位不同；1 号盒子逐面墙拆成「现在的值 = 答案 + 误差」三列，净流入 3.333k = 0 + 3.333k；
  五个盒子并排五行（值、答案、误差、残差、误差的净流入），手算 3 号核对；
  说明 5 号残差为 0 而误差不为 0 的原因；最后才给从残差解误差的更新式。
- 插页 B、插页 C 里所有「情形甲」「情形乙」都改成写全的条件。

**Implications**：
1. 一个量出场前先定义，并给出它回答的问题（误差：离答案多远；残差：此刻平不平衡）和单位。
2. 等式里出现「= 0」的项时，说清楚是谁等于 0、为什么，别让读者以为整个式子该是 0。
3. 第 1–7 课、插页 A 里还有以代号引用的地方（同一页里定义过），下次回顾时按第 15 条补全。
