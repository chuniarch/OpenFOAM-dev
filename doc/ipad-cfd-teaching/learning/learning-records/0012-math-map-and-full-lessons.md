# 「r = 1 − cos²(π/N) 用到哪些数学」与「插页 C 为什么不写成一课」

学习者在插页 C 开讲前问了两件事：

1. 插页 B 的 `r = 1 − cos²(π/N)` 涉及哪些数学知识，是微积分还是数值分析里的方法。
2. 我在对话里只给了插页 C 的五步提纲，他问为什么不像插页 B 那样把具体内容写出来。

**第 1 点的回答**（对话里给出知识地图）：三角恒等式（高中）、特征向量/特征值的想法（线性代数）、
傅里叶分解（任意误差 = 不同波长的正弦之和）、泰勒展开（微积分里唯一用到的部分）、对数、
数值分析里的「定常迭代法收敛分析」（谱半径、模型问题、高斯-塞德尔因子是雅可比的平方）。

核对时发现插页 B 有两处要改，已改为第 4 版：
- 第五步把 N = 5 的偏差归因于「改动 = r × 误差是近似」，不对。实际是三项：准确的 r 是 1/3（cos² 公式给 0.345）；
  改动对应的是扫之前的误差，停下时的误差还要乘 (1 − r)；停下那一遍的改动是 0.763 × 10⁻⁶，不是正好 10⁻⁶。
  三项相乘与实测逐位吻合。
- 「高斯-塞德尔因子 cos² 的严格证明要用矩阵特征值，超出这一课」——其实用同一个三角恒等式就能推：
  误差取 `c^i × sin(θ(i + 0.5))`（c = cos θ），扫一遍每个盒子都乘 c²。已补进正式说法一节。

**第 2 点**：学习者期待的是和插页 B 同样有推导、有演算的课文，不是提纲。插页 C 已写成完整一课
（残差、残差相加、权重减半、10 → 5 的完整一个循环逐格数字、V 循环工作量推导、与高斯-塞德尔的对比表、
OpenFOAM GAMG 源码对照）。

**Implications**：
1. 学习者问「下一课是什么」时，给一句话的定位即可；要讲内容，就直接写成课文，不要在对话里给提纲。
2. 「超出这一课」是 NOTES 第 14 条的警报：先试着用已经教过的工具推，推不出来再说。这次同一个恒等式就够了。
3. 近似公式（cos²(π/N)）只在 N 大时准；拿它解释小 N 的数据之前，先用准确值核对。
