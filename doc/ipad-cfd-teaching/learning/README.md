## 砖块清单（含核心要点）

### 砖块 1 —— 两个盒子之间墨水怎么流
- **规则**：`流量 = 常数 × 浓度差`，从浓流向淡；浓度相同 → 流量为 0。
- **为什么**：分子随机乱跳（掷硬币），浓的那边分子多 → 净流量朝淡的一侧。浓度差不是"推力"，是统计结果。
- 岔话：熵增本质是数微观状态数；麦克斯韦妖不违反第二定律（兰道尔原理：擦除信息要耗散）。
- **易混**：浓度 ≠ 密度。

### 砖块 2 —— 一个盒子的「进 = 出」
- **稳态定义**：盒子里的量不再变化 ⇒ 左墙流进 = 右墙流出。**稳态 ≠ 静止**：墙上一直有流量穿堂而过，只是进出配平。
- 一般解 `C_P = Σ(w·C_邻居) / Σw` —— **邻居的加权平均**；等权重时退化成 `C_中 = 两邻居的平均`。
  这条骨架一路活到 cavity，后面每一砖都只是往里再塞一项。
- **符号约定**：每一项都写成「流进 P」的形式 `w·(C_邻居 − C_P)`，一个式子自动兼顾流进与流出。
- **串联配平律**：稳态下每道墙的 `w · ΔC` 必须相等 ⇒ **权重大的一侧浓度差小**。
  例 `w_L = 2·w_R`、`C_L=10`、`C_R=4` ⇒ `C_P = 8`（左差 2、右差 4，各乘权重都等于 4w）。
- **极值原理**：稳态无源时极大/极小只能出现在**边界**，内部不可能冒尖（内点等于邻居平均，
  平均值不可能严格大于所有被平均的数）⇒ 这是「有界」这把尺子的数学出处。
- **本砖验收尺子**：平场保持平（`C_L=C_R` ⇒ `C_P` 必等于它）／有界／左右对调答案不变／解回代后两墙流量等大反号。

### 砖块 3 —— 一整排盒子 → 联立方程组
- 每个盒子一条方程，但互相依赖成环 → **不能单独算，必须一起解**。
- 摆成矩阵只是**记账格式**（行=方程，列=未知数），为了调用线性代数武器。
- **验收尺子**：1D 无源两端定值 ⇒ 解是**直线**。

### 砖块 4 —— 把「常数」拆开
- `常数 = D · A_face / 距离`（D 扩散系数、A 面积、距离=两中心间距）。
- 梯度 = 浓度差 ÷ 距离；菲克定律 `J = D × 梯度`（与傅里叶定律同形）。
- 网格不均匀时各面常数不同，**不能简单取平均**，要按 `D·A/Δx` 加权。

### 砖块 5 —— 边界
- **墙 ≠ 盒子中心**：盒子中心到边界只有 `Δx/2` ⇒ 边界墙常数 = `2k`（内部墙的两倍）。
- `fixedValue`：分子加 `2k·C_边界`、分母加 `2k`（已知值搬到方程右边）。
- `zeroGradient`：无通量 ⇒ **什么都不加**（不是当成 C=0 的 fixedValue！）。

### 插页 A/B/C —— 迭代法与线性求解器
- **A**：误差每轮乘迭代矩阵，谱半径 <1 则收敛；「取邻居平均」= 抹平，**高频误差消得快、低频慢**。
- **B**：Gauss-Seidel 比 Jacobi 快（立刻用最新值，信息传得快）；共同硬伤是信息一格一格爬。
- **C**：CG 把解方程变成「在碗里找谷底」，用互相共轭的方向不走回头路，收敛率由 √κ 决定；预处理=把长窄山谷掰圆；多重网格专治低频误差。
- 直接法（高斯消元/LU/Thomas）vs 迭代法（Jacobi/GS/CG/GAMG）；CFD 用迭代法因为矩阵**又大又稀疏**。

### 砖块 6 —— `Diffusion1D.swift`（我打样）
- 一维稳态扩散 + 高斯-塞德尔迭代。
- Swift 要点：`let/var`、数组是**值类型**（改内容必须 var）、`Int` 和 `Double` 不自动转（要 `Double(i)`）。
- **重要澄清**：`C₀ ≠ cLeft`。`cLeft` 是墙上的值（已知），`C₀` 是第一个盒子**中心**的值（要解），二者隔 `Δx/2`。

### 砖块 7 —— `Diffusion2D.swift`（你写的）
- 二维稳态，邻居从 2 个变 4 个，结构不变。
- 你踩的坑：算出 `newValue` 却漏了 `c[j][i] = newValue`（没写回 → 永远全 0）。
- **验收尺子升级**：二维没有"直线"可用，改用**对称性**——对称的边界条件必须给出对称的解。

### 砖块 8A —— `Diffusion2DTransient.swift`（显式瞬态）
- 守恒律加「堆积」项：`V·(C_new − C_old)/Δt = 净流入`。
- 显式：右边全用**旧值** ⇒ 一遍扫描出新场，**不用迭代**。
- **必须双缓冲**（`cNew`），不能就地写回。
- 稳定条件 `Δt ≤ Δx²/(4D)`，超了就发散。
- **验收尺子**：封闭系统**总质量守恒**（最强尺子，你跑出 0.25 稳定不变）。

### 砖块 9 —— `Diffusion2DImplicit.swift`（隐式瞬态）
- 隐式：右边邻居用**新值** ⇒ 又变成联立方程组 ⇒ 要迭代解。
- 更新公式 `C_new = (a·C_old + Σw·C_邻居) / (a + Σw)`，其中 `a = V/Δt`。
- **核心解读：「虚拟邻居」**——自己的旧值像第 5 个邻居，权重 `a`，把盒子往上一刻拉。
  - Δt→∞ 时 a→0 ⇒ 退回稳态（砖块 7）；Δt→0 时 a→∞ ⇒ 几乎不变。
- **双层循环**：外层时间推进（不收敛，跑固定步数）、内层解这一帧（迭代到收敛）。
- **不能用递归**（邻居互相依赖成环 → 无限循环），必须迭代读数组当前值。
- 内层收敛到的是**下一帧**，不是稳态；每帧锚在前一帧（这一帧结果 → 下一帧的 cOld）。
- **诚实的权衡**：隐式买的是"无条件稳定/可用大 Δt"，**不等于更快**。小网格上显式更划算；细网格上显式 Δt ∝ Δx² 被压死，隐式才赢。

### 砖块 10 —— `Convection2D.swift`（对流）
- 让水流动，墨水被**整体推走**（不只是原地散开）。
- **面通量 `F = u · A_face`** —— 这就是 OpenFOAM 的 `phi`。
- 对流流量 = `F · C_face`；难点是**面上的 C 怎么取**。
- **中心差分会失败**（丢失方向性 → 震荡、出负值）；**迎风格式**：顺流向取**上游**盒子的值。
- `max(F,0)` / `max(−F,0)` 技巧把方向判断压成无分支表达式。
- **统一稳定条件**：`Δt ≤ V / (Σ扩散权重 + Σ流出通量)`，可同时推出扩散限 `Δx²/(4D)` 和 CFL 限 `Δx/u`。
- **出口边界**：迎风上游就是自己 ⇒ `−F·C_P`。**不能写成 fixedValue=0**。
- 这次**质量不守恒**（入口在加、出口在减），改用「有界 + 整体右移」当尺子。
- **代跑验收（2026-08-28）**：本仓库无 Swift 工具链，用等价逻辑复算了一遍 —— **代码是对的**。
  `Δt上限=0.02778 → Δt=0.01389，71 步，CFL=0.2778`；全程 `0 ≤ C ≤ 100`（有界 ✓）、沿 x 单调不增 ✓、
  21 行数值逐位相同（`fy=0` 且上下 zeroGradient，y 方向本就该无差别 ✓）、台阶整体右移 ✓。
- **新增一把量化尺子：半高点位置 = 起始位置 + u·t**。起始 0.35 m、u=1 m/s ⇒ t=0.333 s 半高点应在 0.68 m
  （实测落在 i=13~14 之间 = 0.68 m ✓）；t=0.5 s 应在 0.85 m（实测 i=16.5 = 0.85 m ✓）。
  它比「有界/单调」强一档：**能测出速度对不对**，而不只是「没爆炸」。
- **★迎风的代价：数值扩散（假扩散）★** —— 把 `dCoeff` 改成 0（物理扩散为零、纯对流），台阶**照样糊开**约 8 格。
  糊开的不是墨水，是**格式**。迎风的一阶截断误差等效于偷偷加了一个扩散系数
  `D_num ≈ (u·Δx/2)·(1 − CFL)`，本例 ≈ 0.018，**比物理的 D=0.01 还大**。
  记法：`迎风 = 不震荡，但会抹平`。想要锐利界面就得上高阶格式（linearUpwind / limitedLinear / TVD），
  代价是可能重新出现震荡 —— 这正是 OpenFOAM `system/fvSchemes` 的 `divSchemes` 那一行在做的选择。

### 砖块 11 —— PISO 压力-速度耦合（进行中）
- 动量方程 = 你写过的输运方程（时间+对流+扩散），**只多了 `−∇p`**。
- **核心困境：压力没有自己的方程。** 未知数 u,v,p 共 3 个，动量方程只有 2 条；第三条是 `∇·U = 0`，但里面**没有 p**。
- **破局洞察**：压力的作用就是"恰好让速度场满足 ∇·U=0 的那个量"。
- 三步推导：
  1. 离散动量：`a_P·U_P = H(U) − V·(∇p)_P`（`a_P` 就是你的 `weightTotal`，`H(U)` 就是邻居贡献）
  2. 解出：`U_P = H(U)/a_P − (V/a_P)·(∇p)_P`
  3. 代入 `∇·U=0` ⇒ `∇·[(V/a_P)∇p] = ∇·[H(U)/a_P]` ⇒ **压力方程本质是一个拉普拉斯（扩散）方程**
- 对应 icoFoam.C：`rAU=1/UEqn.A()`、`HbyA=rAU*UEqn.H()`、`pEqn: laplacian(rAU,p)==div(phiHbyA)`、`U = HbyA − rAU*grad(p)`。
- PISO = 预测 + 修正若干轮（cavity 的 `nCorrectors 2`）。

## 通用思考框架（贯穿所有砖块）

1. **四层翻译**：物理(PDE) → 数学(离散方程) → 数据结构 → 代码。不准跳级，键盘碰之前先把离散式写出来。
2. **增量思维**：守恒律是骨架，新物理只是往「净流入」里**加一项**，不重写框架。
3. **面上问三件事**：这个面有什么通量？系数是多少？**面上的值怎么取**（← 离散格式在回答这个）。
4. **先钉符号约定**：面的正方向、对上下游谁正谁负。80% 的 bug 来自符号和方向。
5. **稳定性自己推**，别背：把更新式展开，要求 `C_P_old` 的**自留系数 ≥ 0**。
6. **写代码前先定验收尺子**：守恒 / 有界 / 单调 / 对称 / 解析解。

## 验收尺子速查
1. 不爆炸（无 NaN、无极值）　2. 封闭系统总质量守恒　3. 单调性
4. 对称边界 ⇒ 对称解　5. 1D 稳态无源 ⇒ 直线　6. 有界（迎风保证不出负值）
7. 对流问题：**半高点位置 = 起始位置 + u·t**（能验速度，不只是验"没爆炸"）
8. 关掉新加的那一项，必须**退化成上一砖**（回归尺子：加 −∇p 前后要能对上）
