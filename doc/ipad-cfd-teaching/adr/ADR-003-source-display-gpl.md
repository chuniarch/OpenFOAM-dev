# ADR-003 — 源码展示 = 真实 OpenFOAM C++ 内嵌 + GPL 分期策略

- 状态：已接受（2026-06-10 评审冻结，2026-06-23 正规化为 ADR）
- 追溯：FR4、C3；architecture §0、§11

## 背景

核心差异化 = 源码入门，展示**真实源码**最具权威感。但 C3：OpenFOAM 为 GPL v3，属传染型 copyleft，且与 App Store 分发条款直接冲突（VLC 先例）。

## 决策

- **原型期**：直接内嵌真实 OpenFOAM 源码片段（保留许可头、标注来源）进行开发，不为合规分心。
- **上架前**：切换为「外链真源码 + 自写等价讲解」（architecture §11.3 方案 ①+②），并确认整个 App 的分发许可策略。
- ADR-001 默认端侧使源码默认不外发，收窄 C3 接触点。

## 后果

- ＋ 原型期保住教学保真度；合规改造仅影响"源码如何呈现"这一层，与引擎/可视化解耦，后期替换成本可控。
- 列为上架前待办：源码呈现切换 + 分发许可确认。

## 被否决的选项

- **起步即自写等价讲解**：被"失去展示真源码的权威感、拖慢原型"暂否（上架前回收）。
- **App 整体 GPL、不上架 App Store**：被商业化/分发渠道否决（保留 TestFlight/自签名为后备）。
