# ADR-005 — 联动层单一事实源

- 状态：已接受（2026-06-10 评审冻结，2026-06-23 正规化为 ADR）
- 追溯：FR4、FR5；architecture §6

## 背景

"一处操作、多处响应"的联动是教学 App 的灵魂（点源码行 → 公式高亮 + 结果闪烁 + 探针更新）。若各面板各持状态，极易不一致。

## 决策

用 `@Observable` ViewModel 持**单一事实源**：`highlightedNodeID` / `iterationState` / `probedCell`。引擎事件（ADR-009）→ 更新此单一事实源 → SwiftUI 各面板自动刷新。

## 后果

- ＋ 联动天然一致；新增面板只需读同一事实源。
- 依赖 ADR-009（事件数据源）+ ADR-010（nodeID 命名对齐）。

## 被否决的选项

- **各面板各自持有状态**：被"多视图易不一致"否决。
