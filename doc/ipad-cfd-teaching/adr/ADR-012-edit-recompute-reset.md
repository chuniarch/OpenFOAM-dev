# ADR-012 — 编辑后重算策略：重置重算（MVP）

- 状态：已接受（2026-06-23）
- 追溯：FR2、NFR4、UC2-E3；analysis-model D3
- 关系：裁定 **D3**

## 背景

D3：用户改边界/参数后的重算策略。NFR4 要求流畅；教学网格仅 20×20，重算快。analysis-model UC2-E3 已把重置重算定为 MVP 策略。

## 决策

改参确认 → **重置 → 从 t=0 重算**。运行中进入编辑则自动暂停；确认修改 = 丢弃当前进度、重置重算。

## 后果

- ＋ 确定性强、实现简单、与 UC2-E3 一致；教学网格重算快，不违 NFR4。
- － 丢失当前进度（网格小可接受）。

## 暂时否决的选项

- **从当前时刻续算**：暂否——需状态快照 + 改参后物理一致性管理，复杂度对 MVP 过度。留作发布后可选增强。
