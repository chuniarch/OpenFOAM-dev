# ADR-002 — 求解引擎语言 = Swift（真实 C++ 的忠实移植）

- 状态：已接受（2026-06-10 评审冻结，2026-06-23 正规化为 ADR）
- 追溯：C1、C2；architecture §0、§2

## 背景

C1（iOS 不能编译用户现写代码）+ C2（OpenFOAM 依赖 MPI/wmake/动态库，不可整搬，须重实现）。同时需要好调试、可单元测试、可优化、上架成熟的实现路径。

## 决策

求解引擎用 **Swift 重新实现**，作为真实 OpenFOAM C++ 的**忠实移植**，靠「函数↔源码映射表」与真实 C++ 对齐语义（`fvm` 返回矩阵、`fvc` 返回场，类型系统强制隐式/显式之分）。

## 后果

- ＋ 原生性能、调试、上架成熟度；引擎可单测、可与真 icoFoam 对拍。
- 须保证 Swift 行为与所展示 C++ 语义一致 → 映射表评审 + 对拍（验收测试 T7）。

## 被否决的选项

- **桥接/整搬真实 C++**：被 C2（依赖链不可整搬）+ C3（GPL）否决。
- **WebAssembly / 其他运行时**：被调试体验与上架成熟度否决。
