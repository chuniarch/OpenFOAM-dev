# ADR-008 — 可视化 = Metal / SwiftUI Canvas

- 状态：已接受（2026-06-10 评审冻结，2026-06-23 正规化为 ADR）
- 追溯：NFR4、FR3、NFR6；architecture §1、§6

## 背景

NFR4 要求"实时观看、随时单步"的交互性能；需渲染速度矢量/流线、压力云图、残差/Courant 曲线、随时间演化。NFR6 要求避开经典 CAE 观感。

## 决策

重场渲染（矢量场、云图、流线）走 **Metal**；轻图（残差曲线、示意）走 **SwiftUI Canvas**。

## 后果

- ＋ 教学网格（20×20）下流畅；自绘可控视觉风格（贴 NFR6 反 CAE 观感）。
- Metal shader 维护成本（网格小、案例单一，可控）。

## 被否决的选项

- **纯 SwiftUI 绘制大场**：被性能（NFR4）否决。
- **第三方图表库**：被"外部依赖 + 风格冲突（NFR6 避 CAE 观感）"否决。
