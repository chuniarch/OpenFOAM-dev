# ADR-001 — FR7 AI 答疑后端选型与「可替换 AI 提供方」接口

- 状态：已接受（2026-06-23 需求方拍板）
- 追溯：FR7、NFR1、NFR2、NFR5、C3；requirements §7、§10.2、§10.3；analysis-model UC7、D5
- 关系：本 ADR 裁定 analysis-model §6 的 **D5**

## 背景

FR7（AI 答疑）是与静态对照平权的第二根支柱，专攻静态预写内容接不住的长尾问题（读者视角、无限、因人而异）。③ 必须回答：**AI 能力从哪里来，App 与它之间的接缝长什么样。**

约束此决策的需求/事实：

- **NFR1 零环境成本**：装完即用、无配置、无账号 → 把"必须填 key/注册"压成非默认。
- **NFR5 分层可用性**：静态层离线必可用，AI 层在线可、断网优雅降级 → 把"纯云端、断网即死"压成不可作唯一形态。
- **NFR2 防挫败**：AI 答错会反噬学习。
- **C3 GPL + 隐私**：把真实源码发给第三方 AI 是 GPL 又一接触点 + 隐私披露义务（§7 次生需求）。
- **§10.3 高替代性**：用户随时能直接问通用聊天机器人，护城河 = 预载已核实的代码上下文（ContextPack）。
- **§7 答案语义一致性**：AI 答案须与所展示源码语义一致。
- **后端必要性事实（D5 辨析）**：后端本质 = 密钥保管 + 按终端用户限流 + 跨用户聚合 + 重型编排 + 审计脱敏；本 App 单用户/单模型/秒级问答/低 PII，几乎都不成立；多设备同步用 iCloud/CloudKit + SwiftData 即可，不需后端。

## 考虑过的选项

| 选项 | 形态 | 关键问题 |
|---|---|---|
| O1 云端前沿模型 + 开发者自有 key + 自建薄代理后端 | 你付费、你运维代理保管 key | 永久运维；破坏纯离线 |
| O2 云端前沿模型 · BYO-key 直连（无后端） | 用户自带 key、自付费、直连 | 上手门槛、与 NFR1 张力；key 安全 |
| O3 Apple Foundation Models（端侧系统模型） | 系统自带、离线、免费、私密 | 通用模型、设备能力受限 |
| O4 Core AI 端侧小模型 + RAG-over-MappingEntry | 自选小模型内嵌、离线、私密 | App 体积、小模型质量 |
| O5 混合（端侧优先，难题回退云端） | O3/O4 默认 + O2 兜底 | 两套路径复杂度 |

## 决策

1. 架构上立一道**可替换 AI 提供方接口 `AIProvider`** 作为边界：输入 `ContextPack`（symbol + 已核实源码段 + 公式 LaTeX + 预写解释 +（可选）当前求解状态），输出**流式**答案。所有后端实现同一接口。③ 只锁接口形状，不锁实现；选型推迟到 M5。
2. **默认实现 = 端侧（O3/O4）+ RAG**：优先 Apple Foundation Models / Core AI 小模型，RAG 锚定在已核实的 `MappingEntry` 上。最贴 NFR1/NFR5/NFR2，故为默认档。
3. **可选实现 = O2（BYO-key 直连云端）**，面向高级用户；**密钥必须存 iOS Keychain**（严禁 UserDefaults/明文/日志）。仅可选、非默认。
4. **不自建后端**；仅 O1 才需薄代理，列为不推荐。

## 后果

- ＋ 兑现 NFR1/NFR5：默认端侧 → FR7 从"在线可选"可升级为离线可用，松动 §7 开放问题①。
- ＋ 化解 C3 外发：默认档源码不出设备；仅 BYO-key 档外发，触发 UC7-E3 披露 + GPL 评估，范围收窄到单一路径。
- ＋ 把"答案语义一致性"（§7）从风险变可控工程：RAG 只就已核实内容复述/答疑，兑现 §10.2"静态层是 AI 弹药库"，缓解 NFR2 教坏风险。
- ＋ 守住护城河（§10.3）；可替换接口让选型可推迟。
- － 端侧小模型质量弱 → RAG 锚定 + 必要时 O5 回退云端。
- － BYO-key 有门槛、与 NFR1 冲突 → 仅可选、非默认。
- － Keychain 安全要求 → ④ 须明确 key 仅入 Keychain。
- － `ContextPack`/`AIProvider` 虽 M5 才实现，但 ③ 现在就要在资源层/联动层预留（见 ADR-010），否则 M5 被迫改框架。

## 被否决的选项及否决理由

- **O1 作默认**：被 NFR1（运维不属零环境）+ §10.3（单用户无需聚合/限流）否决；仅边角保留。
- **纯云端作唯一形态**：被 NFR5（离线底线）+ NFR2 + C3 否决为默认。
- **不做可替换接口、写死某后端**：被 §7 选型推迟 + "加功能不改框架"演进策略否决。
