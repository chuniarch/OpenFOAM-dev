# ADR-006 — 数据驱动可插拔案例

- 状态：已接受（2026-06-10 评审冻结，CaseData 格式已冻结于 §4.5，2026-06-23 正规化为 ADR）
- 追溯：演进策略、范围（§6）；architecture §4

## 背景

演进策略要求"加新案例 = 加数据，不改框架"；同时要防范围蔓延（3D/湍流/复杂网格）。

## 决策

案例 = 结构化数据 `CaseData`（architecture §4.4，已对照真仓库冻结于 §4.5）+ solver 标识；UI/框架不写死任何案例。MVP 仅 `icoFoam + cavity`。

## 后果

- ＋ 迭代新案例成本低（只加数据）。
- CaseData 字段覆盖 `0/`+`constant/`+`system/` 全部输入，已冻结为契约。

## 被否决的选项

- **案例写死在代码里**：被"每加案例都要改框架"否决。
