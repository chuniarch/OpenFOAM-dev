# ADR-011 — UC6 detail 呈现：固定侧栏 split

- 状态：已接受（2026-06-23）
- 追溯：NFR6、UC6；analysis-model D1
- 关系：裁定 **D1**

## 背景

UC6 是 overview（节点图）+ detail（完整源码+公式+解释）双视图；NFR6 要求适配 iPad 横屏多栏、遵 HIG、避开经典 CAE 观感。

## 决策

采 `NavigationSplitView` 式布局：**左画布（overview）+ 右侧栏（detail）同屏并列**；点节点 → 右侧栏载入其 MappingEntry（源码 + 公式 + 解释）。

## 后果

- ＋ 看细节时不丢"结构地图"上下文；贴 NFR6/HIG 原生多栏。
- － 窄屏空间紧（缓解：侧栏可折叠）。

## 暂时否决的选项（非永久，保留迭代回旋）

- **浮层 overlay**：暂否——"看细节时遮挡思维导图、丢 overview 上下文"。
- **可切换（侧栏 + 全屏）**：暂否——MVP 复杂度。

若新手可用性测试（NFR6）显示侧栏在窄屏下挤压画布，或用户需要全屏沉浸读长源码，可在发布后迭代回收这两个方案（格式与布局不堵死）。
